CSYS5030 W07：统计显著性（知识点 + 题型）

这一周考什么：统计显著性检验（重点）：零假设、p 值、surrogate 怎么生成、为什么时间序列要旋转不能打乱；样本数变多、关系变强时 p 值和零分布怎么变；KSG 和 Gaussian 零分布的区别；需要多少样本（离散启发式）；自相关和 dynamic correlation exclusion（重点）；非平稳数据；多个滞后都有 MI 时怎么用 CMI 区分。

期末题型：选择题常考「p 值的定义」「surrogate 保留什么、破坏什么」「样本多 10 倍零分布怎么变」「不显著能不能说没关系」「自相关图显著时该怎么做」。简答可能让你按 3× / 10× 启发式算最少样本数，或者解读一行显著性输出（估计值、零分布均值和标准差、p 值）。零分布的解析形式（χ²）不考。

读法：从上往下读。每节先讲它要解决什么问题，再给结论和算例。

一、为什么需要显著性检验

  • 理论上 独立。
  • 实际上有限样本几乎总是测出非零值，就像抛 10 次硬币测不出正好 1 bit。

要回答的问题：一个估计值是否与 0 一致。它可能不严格等于 0，但和「没有关系时的统计波动」分不开。这个波动的大小就是 MI 测量的噪声底（noise floor）。

二、假设检验框架

2.1 定义

  • 零假设 ： 与 独立。
  • 备择假设 ：存在依赖，MI 非零。
  • p 值：如果 为真，得到大于等于实测 MI 的概率：

  • （通常 0.05）→ 拒绝 ，关系显著。MI 值再小，只要显著就和 0 不同。

2.2 Surrogate 分布

  1. 按原配对算出实测 MI。
  2. 把 的样本打乱：保留 的边际分布，破坏 和 的联合依赖。
  3. 用 和打乱后的 算一次 MI，得到一个 surrogate 值。
  4. 重复 次，画直方图，就是经验零分布。
  5. 零分布里大于等于实测值的比例就是 p 值。

2.3 时间序列：旋转，不要打乱

  • 打乱对独立样本合理。
  • 时间序列打乱会破坏自相关，零分布里的样本和原数据统计性质不一样。
  • 时间序列用旋转（循环平移）一条序列生成 surrogate，自相关保留，配对关系被破坏。

2.4 CMI 的检验

打乱源 ，但目标 和条件变量 保持在一起不动，保留它们之间的关系。

2.5 附带用途

  • 偏差修正： 。
  • 离散归一化：因为 ，有人除以熵把 MI 缩到 。

2.6 常见考法

  • 「p 值的定义」→ 为真时得到大于等于实测值的概率，不是 为真的概率。
  • 「打乱 Y 保留什么」→ 的边际分布；破坏联合依赖。
  • 「时间序列为什么不能打乱」→ 破坏自相关。

三、两种得到零分布的方法

Bootstrap（重抽样 surrogate） 解析（χ²）
适用 任何估计器 只有 discrete（plug-in） 和 Linear-Gaussian
速度 慢 快
结果随机吗 是，每次跑 p 值会变 否
准确性 surrogate 足够多时最准 近似，样本少或时间序列时不准
  • 解析形式的具体分布不考。要记住的结论：样本多 10 倍，零分布的均值和宽度都缩到约 1/10。
  • KSG 没有解析形式，只能用 surrogate。

3.1 surrogate 数

  • 常用 100 个 surrogate 偏少，只是为了跑得快。要精确结果就加。
  • 关系强时 p 值一直是 0；关系弱时多跑几次 p 值会跳。
  • surrogate 太慢时，可以少跑一些，用正态分布拟合零分布再算 p 值。

四、样本数、关系强度和零分布

4.1 带你看一遍：造数据做实验

源是随机正态，目标 = coupling × 源 + 噪声。1000 个 surrogate：

# N coupling 估计器 零分布 实测值（约） 结论
1 100 0 Gaussian 单侧，尾到 ~0.055 ≈ 0 不显著
2 1000 0 Gaussian 单侧，尾只到 ~0.0045 ≈ 0 不显著；窄了约 10 倍
3 1000 0.01 Gaussian 单侧 0.0011，p = 0.12 不显著，但确实有关系
4 1000 0.05 Gaussian 单侧 ~0.0022 在尾部边缘，每次结果不同
5 10000 0.05 Gaussian 主体在 0–0.0005 ~0.00165 远在分布外，强显著
6 1000 0.05 KSG 以 0 为中心对称，±0.06 ~−0.017 不显著

4.2 逐条结论

  1. 样本多 → 零分布变窄：估计更准，没有关系时更贴近 0。同样的弱关系更容易冒出来。
  2. 关系变强 → 实测值变大、p 值变小；零分布不变。零分布只由 （独立）、样本数和估计器决定，和真实耦合无关。
  3. 不显著 ≠ 没有关系：第 3 组确实有耦合，只是现有样本量下无法拒绝 。
  4. 结果每次跳动，主要因为实测 MI 依赖那一批随机数据；零分布的范围基本不变。
  5. N = 10000 强显著有两个原因：实测值更稳，零分布更窄。

4.3 KSG 和 Gaussian 的零分布

Gaussian KSG
形状 单侧，从不为负 以 0 为中心，近似对称
负值 没有 常见（与 0 一致）
宽度 窄 宽得多
原因 没有偏差修正 内置偏差修正把分布移到 0；对任何关系都敏感，统计波动影响更大

结论：用 KSG 时，把一个值和噪声底分开需要更多数据，哪怕关系只是线性的。线性高斯数据上 Gaussian 估计器需要的样本少得多。

4.4 常见考法

  • 「样本数从 1000 增到 10000，零分布」→ 变窄，约缩到 1/10。
  • 「耦合变强，零分布」→ 不变；变的是实测值和 p 值。
  • 「p = 0.12 能说明独立吗」→ 不能，只是无法拒绝 。
  • 「哪个估计器的零分布有负值」→ KSG。

五、需要多少样本

5.1 问题要说清楚

真正想问的 答案
多少样本才能检测到显著关系 取决于关系强度：越强需要越少
多少样本才能避免欠采样 取决于估计器：Gaussian 是 model-based，比 KSG 需要的少

5.2 离散启发式

状态配置数 = 联合空间的格子数 = 各变量字母表大小的乘积。

前提是各配置大致等可能。分布偏斜时需要更多。

5.3 带你算一遍：Seinfeld 文本

27 个符号（26 个字母 + 空格）：

分析 状态配置数 3× 10×
前 1 个字符 → 下一个 ~2,200 ~7,300
前 2 个字符 → 下一个 ~59,000 ~197,000

往回多看一个字符，状态空间乘 27，指数增长。反过来可以算：给定数据量，最多往回看几个字符。

5.4 连续数据粗估

  • Kernel：宽度不该超过变量的标准差，超过就相当于二值化或抹平分布。
  • KSG 自动调宽度，但能力有限。
  • 常识：15 个样本用连续估计器不会好；30 个样本还做多变量更糟。

六、自相关和非平稳

6.1 自相关破坏了什么

自相关让样本不独立，而独立是估计器、尤其是显著性检验的前提。

受影响的地方 机制
Gaussian 解析检验 用 当参数，但自相关时 不再是独立样本数
KSG 估计本身 时间相邻的样本在联合空间里也挨得近 → 近邻被它们占据 → 第 近邻距离变小 → 边缘计数变少 → MI 被高估
Surrogate 生成 打乱破坏源的自相关

6.2 Dynamic correlation exclusion（Theiler window）

  • 找近邻时忽略时间上太近的样本。也叫 serial correlation exclusion。
  • 「太近」= 自相关长度：自相关衰减到不显著的位置，或第一次过零点。
  • 取两个变量里最大的自相关长度作为排除窗口。
  • 心率在 lag 约 15 前都显著自相关。神经数据、尤其 fMRI 几乎总是强自相关，一定要加。
  • 只有用 KSG（近邻类估计器）时才需要；离散和 Gaussian 估计器不找近邻。AIS 和 TE 用 KSG 时同样要加（W10、W11）。

看自相关图做判断（样卷 Q18 的考法）：

自相关图 结论
前若干个 lag 显著（超出显著性线） 要用 dynamic correlation exclusion，窗口取到自相关衰减到不显著的 lag
前几个 lag 显著 过去对下一个值有线性预测力，AIS 很可能显著（AIS 至少能抓到线性自相关）
都不显著 不需要 exclusion；但 AIS 仍可能有非线性部分，不能直接断言为 0

6.3 非平稳：exclusion 救不了

  • 平稳：这里的样本和别处的样本可比，都来自同一个底层过程。
  • 严重非平稳（比如几年的股价）不能直接分析，exclusion 窗口也没用。
  • 金融数据常用相邻两天的差值，更常用 log 差值（log returns），平稳得多。这也改变了问题：变成「每日（log）变化之间的关系」。

七、多个滞后都有 MI 怎么办

心率 → 呼吸的 KSG MI 在 lag 0–15 都不小，最大在 lag 7（约 0.144 nats）。两种可能：

  1. 只有一个真正的作用，自相关让相邻滞后也看到 MI。
  2. 有多个不同的机制。

用 CMI 区分：取 MI 最大的 lag 7 当条件，对另一个滞后 算

CMI 含义
= 0（排除偶然后） 没有新信息，和 lag 7 冗余
> 0 有 lag 7 单独给不了的信息：可能是独有的，也可能是协同的，或两者都有

只算两个心率值之间的 MI 不够，它说明两个源相关，不说明对目标的信息是否重叠。

考点小结

  1. ★★★ p 值定义：（独立）为真时得到大于等于实测值的概率； 拒绝 。
  2. ★★★ Surrogate：打乱源，保留边际、破坏联合依赖；时间序列用旋转；CMI 检验时目标和条件变量保持在一起。
  3. ★★★ 样本多 → 零分布变窄；关系变强 → 零分布不变，p 值变小；不显著 ≠ 没有关系。
  4. ★★ KSG 零分布以 0 为中心、可为负、比 Gaussian 宽 → 需要更多样本。
  5. ★★ 解析 vs surrogate：解析方法只有 discrete 和 Gaussian 有，快、确定、但近似（形式不考）；KSG 只能用 surrogate。surrogate 的 p 值是随机的；100 个 surrogate 偏少。
  6. ★★ 离散启发式： （下限）、 （像样）状态配置数；配置数随字母表和变量数指数增长。
  7. ★★★ 自相关和 dynamic correlation exclusion：KSG 近邻被时间相邻点污染，MI 被高估；排除窗口 = 最大自相关长度。会看自相关图判断要不要加。
  8. ★ 非平稳数据先取（log）差值；exclusion 救不了。
  9. ★ 多个滞后都有 MI：用 CMI 以最强滞后为条件区分；CMI > 0 可能是独有或协同。

Q21（简答·解读，自拟） 对一段 N = 1000 的数据跑 KSG 并用 1000 个 surrogate 做显著性检验，输出 MI = -0.012 nats (null: 0.000 +/- 0.030 std dev.; p(surrogate > measured)=0.64)。解释这几个数，结论是什么？

MI = −0.012 nats：KSG 带偏差修正，负值表示与 0 一致。零分布均值 0、标准差 0.03：1000 次打乱源后得到的 MI 以 0 为中心，波动约 ±0.03，这是噪声底。p = 0.64：如果独立，有 64% 的 surrogate 大于等于实测值。 ，无法拒绝独立的零假设，但不能说明一定没有关系，可能只是样本不够。

Q22（简答·概念，讲义） 解释为什么强自相关会让 KSG 高估 MI，以及 dynamic correlation exclusion 怎么修正。

KSG 在联合空间找第 近邻定盒子大小。自相关时时间上相邻的样本取值也接近，于是它们成了近邻，盒子比应有的小；盒子小，边缘空间里数到的 、 变少，代入公式 MI 变大。Dynamic correlation exclusion 在找近邻时忽略时间距离小于 Theiler window 的样本，窗口取最大自相关长度，让找到的近邻接近独立样本。
