CSYS5030 W09：信息处理与熵率（知识点 + 题型）

这一周考什么：生物计算和传统计算的区别（Mitchell 对比表）；内禀信息处理；计算三要素 ↔︎ 信息动力学三个度量（存储、传递、修改）；核心问题「下一个值的信息从哪里来」；记号 ；熵率的两种定义、平稳时相等、编码含义（重点）； 。

期末题型：选择题常考「Memory / Signalling / Processing 分别对应哪个度量」「i.i.d. 或周期过程的熵率是多少」「熵率两种定义什么时候相等」。简答可能让你算两状态马尔可夫链的熵率，或用链式法则推出块熵增量 = 条件熵。嵌入向量的细节不考。

读法：从上往下读。每节先讲它要解决什么问题，再给结论和算例。

一、生物系统在「计算」吗

1.1 Mitchell 对比表

电脑在计算，很容易指出哪里存储、哪里处理。鱼群、蚁群、大脑就难说了。

什么是信息 数字的、静态的纸带 模拟状态，时空中分布的模式，靠统计采样获得
信息怎么传递和处理 确定、串行、无差错，集中式规则 去中心、并行、局部、随机，利用随机性

二、信息动力学

2.1 计算 = 存储 + 传递 + 修改

计算的要素 信息动力学度量 哪周
Memory 信息存储（Active Information Storage） W10
Signalling 信息传递（Transfer Entropy） W11
Processing 信息修改 只提及

分布式计算的例子：大脑、元胞自动机的演化、基因调控网络、鸟群算集体朝向、蚁群算最短路线。

2.2 核心问题

复杂系统里一个变量的下一个值 是怎么算出来的？它的信息从哪里来？

把系统看成多元时间序列，对目标 问：

  1. 存储了多少：来自自己的过去。
  2. 传递了多少：来自其他源，归因于哪个源。
  3. 这些部分能否分开，会不会重叠。

接下来三周：先看目标自己的过去（W10 存储），再看其他源（W11 传递），最后在网络层面选出全部父节点（W12）。
