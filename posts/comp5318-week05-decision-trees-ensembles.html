COMP5318 W05：决策树、规则学习与集成（讲解版）

这一周考：熵和信息增益手算（PE1 第 31 题，10 分大题）；决策树的一条路径是 AND 规则；Bagging、Boosting、随机森林各自最关键的那个操作。对应 PE1 第 4、11–13、31 题，PE2 第 4、11–13 题。 读法：从头往下读，熵那一节一定要跟着算一遍。

第一部分：决策树在做什么

1.1 一个例子

你想根据天气决定今天去不去打球。你可能会这样想：

  • 先看天气（outlook）。如果是阴天（overcast），去。
  • 如果是晴天（sunny），再看湿度：湿度高就不去，湿度正常就去。
  • 如果是雨天（rainy），再看有没有风：没风就去，有风就不去。

把这个思考过程画出来，就是一棵决策树：

flowchart TD
  O{"outlook？"} -->|"sunny"| H{"humidity？"}
  O -->|"overcast"| Y1["yes"]
  O -->|"rainy"| W{"windy？"}
  H -->|"high"| N1["no"]
  H -->|"normal"| Y2["yes"]
  W -->|"false"| Y3["yes"]
  W -->|"true"| N2["no"]
  • 每个菱形是一个节点，问一个特征的问题。
  • 每条线是这个特征的一个取值，叫分支。
  • 最下面的方框是叶子，给出最终的预测。

从根走到一个叶子的一条路径，就是一条规则，路径上的各个条件是「并且（AND）」的关系。 比如最左边那条路径：

IF outlook = sunny AND humidity = high THEN no

1.2 关键问题：先问哪个特征

上面的树先问 outlook，为什么不先问 windy？

原则是：先问最能把数据分清楚的那个特征。「分清楚」的意思是，分完以后，每一组里尽量都是同一类（全是 yes，或者全是 no）。这样的组叫「纯」的。

要比较哪个特征分得更清楚，就要给「纯不纯」一个数字。这个数字就是熵。

2.2 信息增益：分完之后乱度降了多少

用某个特征把一组数据分成几个子组以后，每个子组都有自己的熵。信息增益 = 分之前的熵 − 分之后各子组熵的加权平均：

「加权」的意思是：子组越大，它的熵在平均里占的比重越大。

增益越大，说明这个特征把数据分得越清楚。每一步都选信息增益最大的特征来分。

一个推论（PE1 第 11 题）：在同一个父节点上比较不同的特征时，父节点的熵是同一个数。所以加权子熵越小，信息增益就越大。

  A --> C["按某个特征分成几个子组"]
  C --> D["算每个子组的熵"]
  D --> E["按子组大小加权，求平均"]
  B --> F["信息增益 = 父熵 − 加权子熵"]
  E --> F

第 4 步：相减。

outlook 最大，所以根节点问 outlook。然后：

  • overcast 那组已经全是 yes，直接变成叶子。
  • sunny 那 5 天，只用这 5 天重新算每个剩下特征的增益，选最大的（结果是 humidity）。
  • rainy 那 5 天同理（结果是 windy）。

这就是自顶向下、递归地建树：每个子组重复同样的过程，直到某组全是同一类，或者没有特征可用了，就建叶子，标上多数类。

第三部分：建树的其他细节

3.1 数值型特征怎么分

温度是 64、65、68……这样的数字，不能每个值一个分支。做法：

  1. 把这个特征的所有值从小到大排好。
  2. 找相邻两个样本类别发生变化的地方，取两者中点作为候选切分点。比如 71 是 no、72 是 yes，候选点就是 71.5。
  3. 每个候选点把数据分成「≤ 切分点」和「> 切分点」两组，算一次信息增益。
  4. 选增益最大的那个切分点。

3.2 信息增益偏爱取值多的特征

问题：假设有一个「ID 编号」特征，14 天每天一个不同的编号。按它分，会分成 14 组，每组只有 1 天，当然全是同一类，每组熵都是 0。增益 ，比任何特征都大。

但这个特征完全没用：来了新的一天，它的编号是新的，树根本不知道该走哪个分支。

解决办法：Gain ratio（增益率）。用增益除以一个惩罚项 SplitInfo，它衡量「这个特征把数据切得有多碎」：

  • ID 编号切成 14 组，每组 1/14，SplitInfo ，很大，增益率被压低。
  • outlook 切成 5/14、4/14、5/14，SplitInfo ，增益率 。

Gini 指数：另一种衡量纯度的方法，CART 算法用它。公式 。全是同一类时为 0，两类各一半时为 0.5。作用和熵一样。

3.3 过拟合与剪枝

如果树一直分下去，最后每片叶子可能只剩一两个样本，连错误数据都被单独分出来了。这就是过拟合：训练集上全对，新数据上很差。

两种剪枝：

  • 预剪枝：提前停止生长。比如规定树最多 5 层（max_depth），或者每片叶子至少要有 10 个样本。简单，但可能停得太早。
  • 后剪枝（更常用）：先让树长满，再从下往上检查每棵小子树：把它换成一片叶子（标上多数类）以后，在验证集上的准确率没有下降，就剪掉它。

第四部分：规则学习

4.1 1R（One Rule，一条规则）

这是最简单的分类方法，常用来当基准。

  1. 对每一个特征：它的每个取值，预测这个取值下最常见的类别；然后数一数这样会错几个。
  2. 选总错误最少的那个特征，它的这套规则就是最终模型。

例子（天气数据）：

  • outlook：sunny 时 3 no 2 yes，预测 no，错 2；overcast 时 4 yes，预测 yes，错 0；rainy 时 3 yes 2 no，预测 yes，错 2。共错 4 个。
  • humidity：high 时 4 no 3 yes，预测 no，错 3；normal 时 6 yes 1 no，预测 yes，错 1。共错 4 个。

两个都错 4 个，平局，任选一个。最终模型只用一个特征，不会把几个特征用 AND 连起来。

4.2 PRISM（覆盖算法）

PRISM 一类一类地生成规则。以 yes 类为例：

  1. 从一条空规则「IF ? THEN yes」开始。
  2. 选一个条件加进去，使这条规则覆盖的样本里 yes 的比例最高。
  3. 如果这条规则还覆盖了一些 no 的样本，就再加一个条件。条件越多，覆盖的样本越少，混进来的 no 也越少，规则就越「纯」。
  4. 规则纯了以后，把它覆盖的 yes 样本拿走，对剩下的 yes 样本重复，生成下一条规则。

和决策树的区别：决策树「分而治之」，一次划分同时影响所有类别；覆盖算法一次只照顾一类。

第五部分：集成学习

5.1 为什么一群模型比一个好

想象 25 个人各自独立地回答一道判断题，每人答错的概率是 35%。用多数投票决定最终答案：只有当 13 个或更多人同时答错，投票结果才会错。这种情况的概率只有大约 6%。

从 35% 降到 6%，这就是集成的威力。但有两个前提：

  1. 每个模型都要比瞎猜好。二分类时错误率要低于 50%。如果每人都有 60% 的概率答错，投票反而更差。
  2. 模型之间要不一样（独立、多样）。如果 25 个人是同一个人的复制品，他们会一起对、一起错，投票结果还是 35% 的错误率。

所以集成方法的核心问题是：怎样造出一批各不相同的模型。下面的方法就是不同的「造法」。

flowchart LR
  subgraph Bagging["Bagging / 随机森林：同时训练"]
    D1["训练集"] --> s1["抽样 1 → 模型 1"]
    D1 --> s2["抽样 2 → 模型 2"]
    D1 --> s3["抽样 M → 模型 M"]
    s1 --> v1["平等投票"]
    s2 --> v1
    s3 --> v1
  end
  subgraph Boosting["Boosting：一个接一个训练"]
    c1["模型 1"] -->|"关注它做错的"| c2["模型 2"]
    c2 -->|"再关注剩下的错误"| c3["模型 3"]
    c3 --> v2["加权投票 / 预测相加"]
  end

5.2 Bagging：用不同的数据训练

Bagging 的全称是 bootstrap aggregating。

Bootstrap 抽样：训练集有 个样本。从中有放回地随机抽 次，得到一个新的训练集。「有放回」的意思是抽到一个以后放回去，下次还可能再抽到它。所以新训练集里有的样本出现好几次，有的一次都没出现。

每个原样本至少被抽到一次的概率约是 63.2%。（推导：一次抽不到某个样本的概率是 ， 次都抽不到是 ， 很大时约等于 ，所以至少抽到一次的概率是 。）

Bagging 的步骤：

  1. 做 次 bootstrap 抽样，得到 个不同的训练集。
  2. 每个训练集训练一个模型。这些模型可以同时（并行）训练。
  3. 预测时，分类就让 个模型平等投票，回归就取平均。

什么时候效果最好：对不稳定的模型最有效。不稳定的意思是训练数据稍微变一点，模型就变很多，比如很深的决策树、神经网络。多个这样的模型一平均，波动就被抵消了。kNN 这种稳定的模型，bagging 帮助不大。

5.3 随机森林：数据随机，特征也随机

随机森林 = Bagging + 每次分裂时只看一部分特征。

  1. 每棵树用一个 bootstrap 样本训练（和 bagging 一样）。
  2. 每次要在一个节点上选特征来分裂时，只从随机挑出的 个特征里选最好的，而不是从全部特征里选。
  3. 树长满，不剪枝。
  4. 所有树多数投票。

为什么要第 2 步：如果数据里有一两个特别强的特征，普通 bagging 的每棵树都会在根节点选它，所有树长得都很像，违反了「模型要不一样」的前提。随机限制可选的特征，就能让树之间差别更大。

越大，单棵树越强，但树之间越像，要取个平衡。随机森林的缺点是：几百棵树没法像一棵树那样直观解释，计算量也大。

5.4 AdaBoost：后面的模型专门对付前面做错的

Boosting 的思路和 bagging 完全不同：模型一个接一个训练，每个新模型都重点关注前面的模型做错的样本。

AdaBoost 的步骤：

  1. 一开始，每个训练样本的权重都一样。
  2. 训练一个弱分类器（比如只分一次的小树），算它的加权错误率 。
  3. 把分对的样本的权重乘以 。因为 ，这个数小于 1，分对的样本权重变小了。然后把所有权重重新调整，让它们加起来等于 1（归一化）。
  4. 结果是：分错的样本的相对权重变大了。下一个分类器训练时就会更重视这些难样本。
  5. 重复第 2 到 4 步。最后所有分类器加权投票，准确率高的分类器话语权更大。

带你算一遍：4 个样本，权重各 0.25。第一个分类器分错了 1 个，所以 。

  • 分对的 3 个：权重乘 ，变成 。
  • 分错的 1 个：权重不变，还是 0.25。
  • 现在总和 。
  • 归一化（每个都除以 0.5）：分对的各 1/6 ≈ 0.167，分错的 1/2 = 0.5。

分错的那个样本，权重从 0.25 涨到了 0.5。

5.5 Gradient Boosting：后面的模型去拟合残差

也是一个接一个训练，但做法不同：每棵新树学习的目标，是当前所有树加起来还没预测准的那部分，也就是残差 。

例子：某个样本真实值是 10。

  • 前几棵树加起来预测 7，残差 。
  • 下一棵树就以 3 为目标去学。
  • 学好后加上去，预测变成接近 。

（用平方损失时，残差正好就是损失的负梯度方向，所以叫「梯度」提升。）

Boosting 的特点：能把很弱的模型（比如只有一次划分的 decision stump）组合成很强的模型；但必须一个接一个训练，不能并行；也更容易去拟合噪声。

5.6 四种方法对比（必考）

方法 最关键的操作 怎么组合
Bagging 在有放回抽样得到的不同数据上训练，可以同时训练 平等投票（回归取平均）
随机森林 Bagging + 每次分裂只在随机的一部分特征里选 多数投票
AdaBoost 一个接一个训练，提高分错样本的权重 按准确率加权投票
Gradient Boosting 一个接一个训练，新树拟合残差 所有树的预测相加

考点小结

  1. ★★★ 信息增益手算：父熵 → 每个子组的熵 → 按子组大小加权平均 → 相减。
  2. ★★★ 集成方法的定义：Bagging 是有放回抽样；AdaBoost 是提高分错样本的相对权重；Gradient Boosting 是拟合「真实值 − 当前预测」；随机森林是每次分裂随机选一部分特征。
  3. ★★ 决策树路径是 AND；1R 只用一个特征；PRISM 加条件是为了让规则更纯。
  4. ★★ 剪枝看验证集；信息增益偏爱取值多的特征，用增益率修正。

题目

Q1（PE1 Q31，10 分大题） 一个节点有 4 正 4 负。划分后，L = 3 正 1 负，R = 1 正 3 负。 (a) 求父节点和两个子节点的熵；(b) 求加权子熵和信息增益（保留三位小数）。

  1. 父节点各一半， 1。 L 和 R 的比例都是 3/4 和 1/4： 0.811。
  2. L、R 各占一半，加权子熵 0.811。 信息增益 0.189 bits。

Q2（PE1 Q11） 在同一个父节点上，划分 X 的加权子熵比划分 Y 低，能得出什么？

X 的信息增益更高。 父节点熵相同，减去的数越小，剩下的增益越大。

Q3（PE2 Q11） 决策树中有一条路径，只有当 Colour = green 并且 Size = small 时才到达 Yes 叶子。对应的规则是什么？

IF Colour = green AND Size = small THEN Yes。 如果写成 OR，会把不在这条路径上的样本也包进来。

Q4（PE1 Q12） Bagging 最关键的训练数据操作是什么？

在有放回抽样得到的 bootstrap 样本上分别训练各个模型。 「只用上一个模型分错的样本训练」是 boosting 的思路，不是 bagging。

Q5（PE1 Q13） 用平方损失时，后一棵回归树要纠正当前集成还没解释的部分。它的训练目标是什么？

真实值 − 当前集成的预测值（残差）。 如果反过来用「预测 − 真实」，会把误差越放越大。

Q6（PE2 Q12） 随机森林除了 bootstrap 抽样，还常用什么随机化来让树之间更不一样？

每次分裂时，只在随机挑出的一部分特征里找最好的划分，防止几个强特征主导所有的树。

Q7（PE2 Q13） AdaBoost 训练完一个弱分类器后，下一轮的样本权重怎么调整？

分错的样本相对权重变大，让下一个分类器更关注这些难样本。

Q8（PE1 Q4） PRISM 在为 Yes 类生成规则。当前规则同时覆盖了 Yes 和 No 样本，再加一个条件的目的是什么？

缩小覆盖范围，让规则覆盖的样本更纯地属于 Yes 类（把混进来的 No 排除出去）。

Q9（PE2 Q4） 1R 分类器的最终模型有什么特点？

只用一个特征的一套规则（选错误最少的那个特征），不会把多个特征用 AND 连起来。

Q10（自拟） 8 个样本，整体 5 正 3 负（熵 0.954）。按 shape 划分：circle 3 正 0 负，square 2 正 2 负，triangle 0 正 1 负。求 Gain(shape)。

各子组的熵：circle 全是正，0；square 各一半，1；triangle 全是负，0。 加权子熵 。 Gain 0.454。

Q11（自拟） 为什么随机森林用不剪枝的树也不太容易过拟合？Bagging 和 Boosting 哪个可以并行训练？

很多棵互相不太像的树投票，把单棵树的波动平均掉了。Bagging（和随机森林）可以并行；Boosting 后一个模型要等前一个训练完，只能一个接一个。
