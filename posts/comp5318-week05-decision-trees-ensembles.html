第一部分：决策树

一、什么是决策树

  • 最流行、研究最充分的 ML/DM 方法之一，机器学习和统计两条线并行发展：
    • ML：Ross Quinlan（悉尼大学）——ID3（1986）、C4.5（1993）；最流行的版本是 C4.5
    • 统计：Breiman 等人——CART（1984）
  • 结构：
组成 含义
非叶节点 对某个属性取值的测试
分支 该属性的一个取值
叶节点 给出一个类别

预测：从根开始，按样本的属性值一路往下走，直到叶节点，返回叶节点的类别。

一条从根到叶的路径 = 一条规则，路径上的所有测试是合取（AND）关系。PE2 Q11 就考这个：用 OR 会把不在这条路径上的样本也包进来。

二、构建：自顶向下的递归分治

  1. 选最佳属性作为根节点，为它的每个可能取值建一条分支；
  2. 把样本按分支拆成子集；
  3. 对每个分支递归，只用到达该分支的样本；
  4. 停止条件：某分支所有样本同属一类 → 建叶节点。

小例子：录取决策

name Uni degree work exp. >3y sex class
David yes no M reject
Anna no yes F reject
Simon yes yes M accept
Kate yes yes F accept
  • 根选 Uni degree：no 分支只有 Anna（reject）→ 纯，建叶；yes 分支 {David, Simon, Kate} 不纯，继续。
  • yes 分支选 work exp.：yes → {Simon, Kate} 全 accept；no → {David} reject。

注意 sex 完全没用上——决策树天然带有特征选择的效果。

三、选哪个属性：熵与信息增益

直觉：纯度

  • 只含一个类的节点不必再分，递归立即结束；我们想要小树，所以希望这件事尽早发生。
  • 因此选能产生最纯子集的属性。例：5 yes/0 no 很纯；3 yes/2 no 不太纯；5 yes/5 no 很不纯。

熵（Entropy）

= 属于第 类的样本比例；约定 。

二分类：

情形 熵 含义
10 yes / 0 no 0 完全纯（最大纯度）
5 yes / 5 no 1 完全混杂（最小纯度）

信息增益（Information Gain）

信息增益 = 用某属性划分后熵的减少量：

逻辑链：信息增益大 → 熵减少多 → 子节点更纯 → 划分更好。

PE1 Q11：父节点熵固定，被减去的加权子熵越小，增益越大。

五、剪枝：防止过拟合

为什么会过拟合

把树长到完美分类训练集，树会变得过于具体——在记忆数据，而不是提取规律：训练准确率高、新数据准确率低。常见诱因：

  • 训练数据太少——没有足够有代表性的样本；
  • 训练数据有噪声（如标错的样本）——树会为它们添加新分支，变得过于具体。

两种策略

策略 做法
预剪枝（pre-pruning） 提前停止生长，在完美拟合训练集之前就停；例：限制 max_depth
后剪枝（post-pruning） 先长满，再往回剪；实践中更常用

后剪枝方法：子树替换（sub-tree replacement）、子树提升（sub-tree raising）、转成规则后剪规则。

剪多少？用验证集决定 ⇒ 数据分三份：训练集（建树）、验证集（评估剪枝效果、决定何时停）、测试集（评估最终的树）。

子树替换

  • 自底向上（从叶往根）；每个非叶节点都是候选；
  • 对每个候选：删掉以它为根的子树，换成一个叶节点，类别 = 到达该节点样本的多数类；
  • 在验证集上比较新旧两棵树的准确率：新树准确率 ≥ 旧树 ⇒ 保留剪枝。

Lab 问答：剪枝除了防过拟合还有什么好处？树更小 → 更易可视化和理解（可解释性更好）。

六、数值属性：离散化

  • 数值属性需要转成名义属性；标准做法是二元划分，如 temp < 45。
  • 与名义属性不同，数值属性有很多个可能的划分点。

步骤： 1. 按该属性值排序； 2. 候选划分点 = 类别发生变化的位置，取两值中点； 3. 对每个候选点算信息增益，选最好的； 4. 最佳划分点的增益 = 该属性的增益。

七、高分支属性与增益率

问题：取值很多的属性（如 ID code，每条样本一个值）会把数据切成单样本子集，每个子集熵都是 0 ⇒ 信息增益达到最大值（天气数据中为 0.940），会被选中——但这显然过拟合、毫无泛化能力。

信息增益偏向取值多的属性，因为取值多更容易产生纯子集。

解决：增益率（Gain Ratio）——考虑分支数量，惩罚高分支属性。讲义只给了思想；C4.5 中的标准定义（补充）：

ID code 有 14 个取值，SplitInfo ，增益率被大幅压低。

第二部分：集成学习

九、什么是集成

  • 集成 = 组合多个分类器的预测；被组合的叫基分类器（base classifiers）。
  • 组合方式：多数投票、加权投票等。
  • 例：NB → Yes、逻辑回归 → No、决策树 → Yes ⇒ 多数投票 Yes。
  • 集成通常比单个基分类器更好；机器学习竞赛的冠军方案常常是集成。

十、为什么集成有效：25 个分类器的算例

25 个二分类器，每个错误率 ，多数投票。

情形 1：基分类器完全相同（犯同样的错）⇒ 集成错误率 = 0.35，没有任何收益。

情形 2：基分类器相互独立（错误不相关）⇒ 只有超过半数（≥13 个）同时出错时集成才出错：

0.06 ≪ 0.35。

什么时候集成反而更差？ 画 对 的曲线：

基分类器错误率 含义 集成效果
比随机猜好 集成更好
相当于随机 无差别
比随机还差 集成更差（多数投票放大错误）

两个条件： 1. 基分类器足够好（二分类 ）； 2. 基分类器相互独立。

实践中不可能完全独立；轻微相关也能取得好结果——可以经常意见一致，但不应总在同一批样本上出错。

十一、制造多样性的四种途径

途径 例子
操纵训练数据（重采样） Bagging、Boosting
操纵属性（用特征子集） Random Forest、Random Subspace
操纵学习算法（不同参数） 同一算法不同超参数
操纵类标签 纠错输出编码（本课不讲）

Bagging 的多样性主要来自随机重采样；Boosting 的多样性来自让后续模型专注于之前的错误。

  • 通常显著优于单个分类器，且从不明显更差；

十三、Boosting

核心思想

让分类器互补：下一个分类器重点学习之前分类器难以分对的样本。

最流行的两种：AdaBoost 和 Gradient Boosting。

AdaBoost（Freund & Schapire, 1996）

加权训练集：每个样本有权重 ，权重越高说明越难分，被抽进下一个训练集的概率越大。

为什么这样就「提高了错分样本的权重」： 时 ，分对的样本权重变小；归一化后，分错的样本相对权重变大。

补充（Witten 中的常见设定）：模型投票权重为 ，错误率越低权重越大；若 或 通常终止。

整体循环：训练模型 → 找错误 → 提高其相对重要性 → 训练下一个。

AdaBoost 定理：若基学习器是弱学习器（仅略好于随机猜，二分类 >50%），迭代足够多次后 AdaBoost 能完美分类训练集 ⇒ 把弱学习器提升（boost）成强学习器，基学习器可以简单到单层决策树（decision stump）。条件：基分类器不太复杂、错误率不随迭代过快变大。

Gradient Boosting（Breiman 1997；Friedman 1999）

  • 基学习器通常是浅层（弱）决策树；
  • 和 AdaBoost 一样顺序添加模型；
  • 区别：AdaBoost 改样本权重；Gradient Boosting 让新模型直接拟合前面模型的误差（残差）。

回归例子（Géron p.203）：

树越多，集成拟合越好。

PE1 Q13：平方误差的梯度提升中，新学习器的目标是观测值减当前预测（残差）——即纠正剩下的误差。

Bagging vs Boosting

Bagging Boosting
相同点 分类用投票、回归用平均；通常组合同类型模型（决策树/stump） 同左
基分类器生成 相互独立、可并行 迭代、顺序——新模型成为前面模型错分样本的「专家」
组合方式 等权投票 加权投票（按训练集表现，AdaBoost）
多样性来源 随机重采样 关注之前的错误
最适合 不稳定、方差大的模型（深树） 弱学习器（stump）

十四、Random Forest

通过操纵属性造集成

个特征，每个基分类器只用 个随机选取的特征 → 多个数据版本 → 各自建模 → 多数投票。

Random Forest = Bagging + 随机特征子集

个样本，共 个特征，每次分裂只看 个， 棵树：

注意随机特征选择发生在每个节点分裂时，而不是每棵树只选一次。PE2 Q12：每次分裂的随机特征子集减少了同几个强特征主导所有树的倾向。

性能取决于两点

  1. 单棵树的准确率（strength）；
  2. 树之间的相关性——不应都犯同样的错。

理想：单棵树准、但彼此相关性低。

的权衡： 增大 ⇒ 强度和相关性同时增大（如 100 个特征里选 5 个 vs 选 80 个）。sklearn 中对应 max_features，分类默认 。

优点 缺点（Lab 问答）
通常优于单棵决策树 失去可解释性——几百棵（且不剪枝的大）树无法解读
相比单棵树更不易过拟合 计算代价大，大数据集上尤甚

十六、本周考点速记 / 易错点

决策树

  1. 熵 ；二分类范围 [0,1]；0 = 纯，1 = 最不纯；不关心哪类占多数。
  2. 信息增益 = 父熵 − 子节点加权熵，权重 = 子集样本占比。选增益最大的属性。
  3. 天气数据： ，Gain(outlook)=0.247 最大 → 根；sunny 分支选 humidity（0.971）。
  4. Tutorial： ，Gain(shape)=0.45 > Gain(color)=0.34。
  5. PE1 Q31 型题：父节点 4/4 → ；两个子节点各 3/1 → ；IG = 1 − 0.811 = 0.189。
  6. 路径上的测试是 AND。
  7. 过拟合原因：数据太少、噪声；预剪枝 vs 后剪枝，后剪枝更常用；子树替换自底向上、换成多数类叶、验证集准确率不降就剪。
  8. 数值属性：排序 → 类别变化处取中点 → 逐点算增益 → 取最好。
  9. 信息增益偏向高分支属性（ID code）→ 增益率；CART 用 Gini。

集成

  1. 两个条件：基分类器 + 相互独立（多样）；25 个 的独立分类器 → 0.06；相同分类器 → 0.35； 时集成更差。
  2. 自助采样：有放回抽 条，约 63.2% 的原样本出现。
  3. Bagging：并行、等权投票，对不稳定模型（树、神经网络）有效；回归取平均。
  4. AdaBoost：分对样本权重乘 再归一化 → 错分样本相对权重变大；加权投票；弱学习器 → 强学习器。
  5. Gradient Boosting：新树拟合残差 ；最终预测 = 各树预测之和。
  6. Random Forest = Bagging + 每次分裂随机选 个特征，树不剪枝； 大 → 强度和相关性都增大。
  7. Bagging 并行等权 / Boosting 顺序加权——对比表要会默写。
