Posted on 2026-06-03 Edited on 2026-06-13 In 科技速递 Word count in article: 2.5k Reading time ≈ 9 mins.
微软发布 MAI-Code-1-Flash（5B）和 MAI-Thinking-1（35B）两款小型模型，Vitalik 提出基于期权的合成资产方案，Coinbase 投资 Ethena 面向 1 亿用户推储蓄产品。

🚀 每日科技速递 - 2026-06-03

过去 24 小时，三条叙事线交织运行：① Microsoft Build 2026 Day 1 的重磅之外，微软还低调发布了 MAI-Code-1-Flash（5B 参数）和 MAI-Thinking-1（35B），以极小参数量挑战高质量代码生成——在大模型 Token 成本高企的当下，这可能比 Agent 平台本身更具战略意义；② Vitalik Buterin 提出了一个可能重塑 DeFi 安全模型的方案——基于期权的合成资产，从根本上消除链上清算风险；③ Coinbase 战略投资 Ethena，准备面向 1 亿用户推出链上储蓄产品——在加密市场整体失血的背景下，这是一个逆势信号。

🧠 LLM / Large Models

• 🔥15 | 微软发布 MAI-Code-1-Flash（5B）和 MAI-Thinking-1（35B）：小参数模型的杀伤力 — 在 Build 2026 首日的喧嚣之外，微软凌晨发布了两款全新模型：MAI-Code-1-Flash（5B 参数，专为 GitHub Copilot 和 VS Code 打造，已向 Copilot 个人用户推送）和 MAI-Thinking-1（35B 参数，推理专用，面向「特定早期合作伙伴」）。5B 参数挑战代码生成市场是一个极为激进的信号——微软正在用极低成本的专用模型取代通用大模型在特定场景（Copilot 代码补全）中的角色。Simon Willison 对此评价道：「在大模型 Token 成本持续高企的当下，微软向市场传递的信息是：你不一定需要 400B 参数的模型来完成代码。」 Microsoft's New Models [Simon Willison]

• 🔥7 | NVIDIA NemoClaw：工业级安全自主 AI 工程师 — NVIDIA 推出 NemoClaw 平台，让工业企业构建安全、自主的 AI 工程师，安川电机、西门子等工业软件巨头已采用该方案。NemoClaw 的定位与微软的 Agent Framework 形成互补——一个面向工业控制系统，一个面向 Windows 应用生态。 NVIDIA NemoClaw [NVIDIA Blog]

• 🔥7 | NVIDIA × 微软联合推出统一 Agentic AI 部署栈 — 在 Build 大会上宣布从 Windows 设备到云端到本地的全栈统一方案，让 Agentic AI 工作负载可在任意环境下无缝运行。这补齐了 Build 2026 的基础设施拼图——Agent 不仅需要框架（MS）和硬件加速（NVIDIA），还需要两者之间的无缝桥接。 Unified Agentic AI Deployment Stack [NVIDIA Blog]

• 🔥7 | 金融机构齐聚「交易基础模型」赛道 — NVIDIA 观察发现银行、保险、支付等金融机构正加速构建专属 TFMs（Transaction Foundation Models），利用大规模交易数据训练领域专用 AI 以取代传统规则引擎。这是 LLM 垂直化落地的一个重要信号：金融行业正在从「调用通用模型 API」转向「训练自有领域模型」。 Transaction Foundation Models [NVIDIA Blog]

🤖 AI Agent

• 🔥10 | Holo3.1 发布：本地化的计算机操控 Agent 首次支持 FP8/Q4/NVFP4 量化 — HCompany 发布 Holo3.1 系列，相比前代在三大维度上有重大提升：多环境支持（Web/桌面/移动端）、多 Agent 框架兼容性、以及部署灵活性——首次发布 FP8、Q4 GGUF 和 NVFP4 三种量化检查点，支持从云端到终端设备的全本地推理。这使「通用计算机操控 Agent」向实用化迈出了重要一步——在本机运行一个能操控你桌面环境的 Agent，不再需要依赖云端推理。 Holo3.1 [Hugging Face Blog]

• 🔥7 | OpenAI Codex 通用化：面向全角色、全工具、全工作流 — OpenAI 宣布将 Codex 从代码助手扩展为企业级 AI 代理平台，覆盖研发、运维、安全、产品等全角色，支持 VS Code、JetBrains、终端等全工具链。这一定位转变与 Microsoft 的 Agent Framework 形成有趣对比——一个从代码场景向上扩展，一个从操作系统层面向下铺展。 Codex for Every Role, Tool, Workflow [OpenAI Blog]

• 🔥7 | Travelers 保险全国范围部署 OpenAI 智能理赔系统 — 美国保险巨头 Travelers 与 OpenAI 合作，在全国部署 AI 驱动的理赔处理系统。这是 AI Agent 在企业级关键业务流程中的又一重大案例——保险理赔是传统上最依赖人工判断的环节之一。 Travelers [OpenAI Blog]

• 🔥7 | MIT Technology Review：AI 可以接管你的行政部门了 — MIT 科技评论深度分析 AI Agent 正从执行重复任务进化到管理整个行政工作流，企业后台运营的范式转换正在加速。这印证了 Build 2026 和 Agent 框架工程的宏观趋势：Agent 正在从「开发者工具」变成「企业基础设施」。 AI Can Run Your Admin Department Now [MIT Technology Review]

💰 Cryptocurrency

• 🔥12 | Vitalik Buterin 提议基于期权的合成资产方案，消除链上清算风险 — 以太坊创始人提出通过期权机制构建合成资产，从根本上避免链上清算风险，同时大幅降低对实时价格预言机的依赖。该方案如果实施，将直接挑战当前 DeFi 借贷协议依赖清算价格机制的安全模型——被清算的恐惧一直是 DeFi 杠杆用户最大的心理负担。在 Aave 遭遇 $230M rsETH 漏洞的同一周，Vitalik 提出去清算化的替代方案，颇有「当前系统存在根本缺陷」的指向意味。 Vitalik Proposes Options-Based Synthetic Assets [The Block, 🔥12]

• 🔥7 | Coinbase 战略投资 Ethena，1 亿用户储蓄产品下周上线 — Coinbase Ventures 在公开市场购入 ENA 代币，Ethena 与 Coinbase 深度合作推出链上储蓄产品，Coinbase 已成为 Ethena 的主托管方、钱包提供商和永续合约场所。这是 Ethena 首次面向 Coinbase 超 1 亿用户提供服务——在比特币 ETF 连续流出 $3.4B、加密市场普遍失血的背景下，这是一个值得关注的逆势信号。 Coinbase Backs Ethena Ahead of Savings Product Launch [CoinDesk, 🔥7]

• 🔥7 | 美国制裁伊朗加密货币交易所 Nobitex — 美国财政部在「Economic Fury」行动框架下对 Nobitex 等多家伊朗加密交易所实施制裁，指控其为恐怖主义融资提供渠道。加密合规压力已从「交易所 KYC」蔓延至「国家级制裁执法」，全球性交易所的合规成本可能进一步上升。 US Sanctions Nobitex Iranian Crypto Exchanges [The Block, 🔥7]

• 🔥7 | 英国上议院委员会要求央行重新考虑稳定币限制 — 英国上议院特别委员会公开呼吁英格兰银行重新评估拟议的稳定币监管框架，认为过于严格的限制可能削弱英国在全球数字资产领域的竞争力。这延续了全球稳定币监管的「平衡木」式讨论——限制太严则流失创新，太松则风险失控。 UK House of Lords Calls to Reconsider Stablecoin Restrictions [CoinDesk]

• 🔥7 | 加密衍生品交易量跌至 2023 年底水平，美国永续合约市场机遇显现 — 全球加密衍生品活跃度大幅回落至近两年半低点，与 ETF 持续流出趋势一致。不过市场观察人士指出，随着美国监管环境温和化，美国本土永续合约市场（此前因监管几乎不开放）正在打开新窗口。 Crypto Derivatives Activity Slumps to Late 2023 Levels [The Block]

🔬 Frontier Tech

• 🔥10 | Microsoft Build 2026 Day 1 完整回顾：从 Agent Framework 到 MAI 模型的全栈交付 — 将 Build 2026 首日信息整合来看，微软交付了 Agent 时代的第一套完整栈：SDK 层（Windows Agent Framework MIT 开源）、模型层（MAI-Code-1-Flash 5B + MAI-Thinking-1 35B + Project Polaris）、编排层（Azure Agent Mesh Q4 GA）、分发层（Windows Agent Store）、以及基础设施层（WSL 3 + DirectML 2.0 + NVIDIA 联合部署栈）。如果说 2025 年的 Build 是「Agent 概念验证」，2026 年就是「Agent 基础设施的落地元年」。 Build 2026 Recap [Chatforest / 多家媒体]

• 🔥7 | RSS 正在复兴——因为 AI Agent 在阅读它 — 随着 AI Agent 对结构化信息的需求激增，曾被社交媒体边缘化的 RSS 协议重新回到技术前沿。多篇独立博客指出，Agent 友好型内容分发正在重塑信息消费格局——RSS 的标准化、去平台化特性恰恰满足了 Agent 对信息源的需求。这可能是 RSS 自 Google Reader 关闭后第一次真正的复兴。 [Simon Willison / 多家独立博客]
