COMP5318 Week 10 Transformer 基础讲课总结

Posted on 2026-11-03 In Course Notes , COMP5318 Word count in article: 6.2k Reading time ≈ 22 mins.
COMP5318 Week 10 讲课总结，按讲义的六个主题整理 Transformer：分词、词表与嵌入、位置信息，与 MLP / CNN / RNN 的信息组合方式对比； 自注意力的 query / key / value、打分、softmax 份额与加权求和（river bank 算例）、多头注意力；Transformer 块中的残差连接、层归一化与逐位置 MLP； 编码器、因果掩码、交叉注意力与编码器-解码器；输出头、贪心与采样、教师强制、自回归生成；BERT / GPT、预训练、微调与提示、上下文窗口； ViT 与局限。并附本周 Tutorial 的 K-means 与单链/全链层次聚类手算题。

COMP5318 Week 10 讲课总结：Transformer 基础

课程：COMP5318/COMP4318 — Machine Learning and Data Mining，Semester 2 2026 讲师：William Zhi（材料改编自 A/Prof. Nguyen Tran 和 Chuyang Zhou 的 COMP5318 课件） 来源：讲义 PDF（transformer_w10.pdf，Transformer fundamentals）+ Tutorial（t10-solutions (1).pdf）；本周没有转录稿，以讲义为准。

⚠️ 考试范围提示：讲义第 1 页明确写着 Transformer 是新内容，要求熟悉其基本思想和优点；详细架构和计算不在考试范围内（"The detailed architecture and calculations are not examinable"）。两份 Practice Exam 都没有 Transformer 题。所以本篇第一到六部分以理解为目标，算例只用来帮助理解。

本周 Tutorial（t10）的内容其实是聚类手算练习（K-means 与层次聚类），是 Week 9 的巩固，放在本文第七部分——这部分是考点。

〇、总览：Transformer 的好处

讲义贯穿全程的例子：输入前缀 "river bank"，跟踪 bank 这个位置的向量，最终预测下一个词可能是 "erosion"。

好处 说明
随输入变化的上下文 注意力用允许位置上的上下文更新每个 token 的向量
一层内连接远距离上下文 全注意力直接连接相距很远的允许位置（RNN 要一步步传，CNN 要堆很多层）
训练时可并行 已知序列的所有位置可以一起处理；但生成新 token 仍是逐个的
可复用的核心 换合适的输入向量和输出层，同一设计可用于文本、图像和不同任务

流水线：输入向量（token 身份 + 位置）→ 重复的块（注意力收集上下文、MLP 变换特征）→ 上下文向量 → 输出层变成任务预测。

第一部分：序列与表示

一、和之前学过的网络的联系

  • 之前的神经网络已经在从数据中学习数值表示；Transformer 同样处理向量，改变的是序列各位置之间如何交换信息。
  • 全连接层（Week 7）：用学到的权重组合输入向量的各个特征；激活函数让 MLP 学到非线性变换。Transformer 里注意力用线性层、特征处理用 MLP，且 MLP 对每个位置分别作用。
  • RNN（Week 8）：从左到右逐 token 更新，隐藏状态是「滚动的数值摘要」；远处信息要经过一连串状态更新才能传到。
  • CNN（Week 8）：卷积组合局部邻域，同一滤波器在不同位置复用；堆叠层数才能扩大感受野。
结构 组合哪些信息 共享 / 学到的操作
全连接层 输入向量自身的特征 学到的稠密权重
局部卷积 邻近的输入位置 同一个学到的局部滤波器
标准循环层 当前输入 + 上一状态 同一组循环权重
全自注意力 所有允许的序列位置 共享的投影 + 依赖输入的权重

最后一列是关键差别：注意力的「混合权重」（注意力份额）是根据当前输入算出来的，而 CNN/RNN 的组合权重训练后就固定了。

二、架构 vs 参数

架构（architecture） 参数（parameters）
是什么 层与连接的设计 学到的权重和偏置
何时确定 设计模型时选定 训练中调整
训练时 通常固定 改变
推理（inference）时 固定 通常固定

同一架构经不同训练可以表现不同；推理 = 用训练好的、存储的参数做预测。

三、为什么需要上下文

"bank" 在 river bank（河岸）和 central bank（央行）中 token 相同，但含义不同。注意力让 bank 位置能从其他位置收集信息，形成依赖上下文的描述。

四、分词、词表与嵌入

分词（Tokenisation）

  • 把文本切成模型能处理的单元，token 可以是词、词片段或其他符号；
  • 子词分词：常见词一个 token，其他词用多个片段拼成（play / play+ing / un+help+ful）——能表示生僻词而不必为每个整词设词表项；token 数可能多于词数；实际切法取决于分词器。

词表与 token ID

  • 词表：模型能识别或生成的所有 token；每个 token 有一个整数 ID（如 river=17，bank=42，erosion=83，<eos>=0，均为示意）；
  • ID 只是索引，其数值大小没有语义；
  • 特殊 token 标记边界、填充、输出结束（<eos> = 停止生成）。

嵌入查找（Embedding lookup）

  • 嵌入表为每个词表项存一个学到的起始向量；token ID 选出表中的一行；
  • 同一个 bank ID 每次取到的起始嵌入相同；之后位置信息和 Transformer 块让工作向量依赖上下文；
  • 训练可以更新嵌入表，普通推理只读取。
  • ID 选条目，向量提供可计算的数值特征；Transformer 更新的是向量，token 身份不变。

（Week 8 Lab 的 Embedding(NUM_WORDS, 64) 就是这个嵌入表。）

位置信息

  • 同样的词换个顺序意思可能变；RNN 通过链式结构编码顺序，CNN 通过邻域位置；注意力本身不看顺序，所以要显式加入位置信息；
  • 原始 Transformer：把位置向量加到 token 嵌入上：输入向量 = token 嵌入 + 位置向量；
  • 后来的设计可以用位置之间的相对关系表示顺序；
  • 位置信息让排列可用，但它本身不决定词义。

第二部分：注意力与上下文

五、自注意力（Self-Attention）

  • 自注意力：输入都来自同一个序列。接收位置（bank）把自己与所有可用位置比较，river 和 bank 自己都可以贡献信息（一个位置可以关注自己）；
  • 每个位置都会得到更新；在因果（causal）模型中，river 只能用 river，bank 可以用 river 和 bank——因果掩码只允许当前及更早的 token。

Query、Key、Value

学到的线性变换为每个位置产生三种向量：

角色 在例子中 作用
Query（查询） bank 的 query 代表接收信息的位置，拿去比较
Key（键） river 和 bank 的 key 与 query 比较，决定匹配分数
Value（值） river 和 bank 的 value 提供被混合的信息

这些是从数据中学到的数值角色，不是人写的描述。同一组 Q/K/V 变换作用于每个输入位置；把各位置的向量按行叠成矩阵 、、，每行仍对应一个位置。

三步计算（toy 算例）

① 打分：bank 的 query 与 river、bank 的 key 做缩放点积。示意分数（已含缩放）：river 2，bank 1。分数不是概率，也不是词义。

② Softmax 变成份额：

份额为正、和为 1；分数大的份额大，但两者都有贡献。

③ 加权混合 value：

来源 份额 value 向量
river 0.731 [1, 0, 1]
bank 0.269 [0, 1, 1]
混合结果 和为 1 [0.731, 0.269, 1.000]

这就是 bank 位置的一个注意力头的输出——一个上下文更新向量，还没有选出任何 token。

份额 vs 参数

存储的参数（训练学到，推理固定） 针对当前输入计算出来的
嵌入表、Q/K/V 投影权重、MLP 权重 query、key、value、工作向量、分数和注意力份额
  • 73.1% 这个份额只属于这个输入、这个头、这一层；换个输入，同样的参数会给出不同份额；
  • 高份额表示对这次混合贡献大，但不是对预测的完整解释。

六、多头注意力

  • 一个块里并行运行多个注意力头；原始设计中每个头有自己的 Q/K/V 变换；
  • 同一个 bank 位置可通过不同的头收集不同的混合（不同的「视角」）；
  • 把各头输出拼接，再经一个学到的输出投影 → 每个位置一个合并后的注意力更新；
  • 各头的角色不是事先指定的，是学出来的。

第三部分：Transformer 块与堆叠

七、一个 Transformer 块

组件 对 bank 向量的作用
注意力 收集允许位置的上下文
残差连接 把输入向量本身加回来
层归一化 调整特征尺度
前馈网络（MLP） 变换该位置向量内部的特征
下一个块 从更新后的向量继续

原始（post-norm）顺序：

逐位置 MLP

  • 由稠密层 + 激活组成（Week 7 的 MLP）；同一个 MLP 分别作用于 river 和 bank（权重跨位置共享）；
  • MLP 本身不混合位置，但 bank 向量里已经含有注意力收集的上下文，所以 MLP 也能处理上下文信息。

残差连接

  • 一条捷径把输入向量绕过组件直接加到输出上——新描述 = 原向量 + 组件的更新；
  • 注意：残差加的是输入的 bank 向量，不是投影后的 bank value 向量；
  • 也给训练信号提供穿过块的直接通路（缓解深层网络的梯度问题，联系 Week 7 梯度消失）。

层归一化（Layer normalisation）

  • 在单个位置的向量内部调整数值尺度：减去特征均值（中心化）、再缩放控制离散程度；之后学到的缩放和偏移参数可再调整；
  • 帮助重复堆叠的块稳定训练；不会混合不同位置。

八、堆叠与模型规模

  • 更新后的 bank 向量作为下一块的输入；下一块从中重新算 Q/K/V，而这些向量已带有之前块收集的上下文；
  • 不同块通常有不同的参数；
  • 整个堆栈每个 token 位置始终一个向量——加深层数是重复计算，不增加序列长度；最终向量送入任务输出层。
选择 增长的是
深度（更多块） 表示更新的阶段数
宽度（更宽向量） 每个位置携带的特征数
更多头 块内并行注意力操作的数量
更大词表 嵌入条目和可能输出的 token

这些都影响内存和计算；数据、训练和任务设计同样影响性能。

九、编码器、因果掩码与编码器-解码器

完整输入 vs 未完成的前缀

用途 可用文本 bank 能用的上下文
表示一个完整源文本 river bank erosion river、bank、erosion（两侧）
预测下一个 token river bank 只有 river、bank
下一个 token 的目标 erosion 对 bank 的预测隐藏
  • 编码器（encoder）：接收完整源文本，自注意力让 bank 能用两侧上下文；输出每个源位置的上下文向量，供任务头或解码器使用。

因果掩码（必懂的一张表）

query 行  key 列 river bank erosion
river 用 ✗ ✗
bank 用 用 ✗
erosion 用 用 用

每行只能用当前及之前的 token（下三角）。训练时可以提供完整参考 "river bank erosion"，但掩码仍对每一行隐藏它的未来目标。

编码器-解码器与交叉注意力

例：把源文本 "river bank erosion" 改写成 "erosion of the river bank"。当前输出前缀为 "erosion of the"，下一个可能是 "river"。

原始解码器有两个上下文来源： - 因果自注意力：在已生成的输出前缀内部组合信息； - 交叉注意力（cross-attention）：从另一个序列（编码后的源）引入信息——query 来自解码器当前位置（"the"），key 和 value 来自编码器输出。

三种注意力模式

模式 Query 来自 Key/Value 来自 可见范围
编码器自注意力 源位置 同一源序列 完整源
因果自注意力 前缀位置 同一前缀 当前及更早位置
交叉注意力 解码器位置 编码后的源 允许的源位置

原始架构：左边编码器、右边解码器；解码器输入是右移一位（shifted right）的已知输出前缀，让每个前缀位置对齐它的下一个目标 token；顶部线性层 + softmax 把解码器向量变成下一个 token 的概率。仅解码器（decoder-only）模型只用因果自注意力，没有单独的源编码器。

第四部分：预测、训练与生成

十、词表输出头

最终的 bank 向量 → 学到的输出层 → 每个词表项一个 logit → softmax → 下一个 token 的概率：

候选 logit（示意） 概率
erosion 2 60.0%
policy 0 8.1%
river −1 3.0%
其余所有 token 许多 logit 合计 28.9%

两种 softmax 别搞混

用途 在什么上做 softmax 接下来
注意力内部 允许的输入位置 混合它们的 value 向量
输出头 词表项 选出可能的下一个 token

例：注意力里 river 占 73.1%，不代表下一个 token 一定是 river——输出头最终给 erosion 60%。

十一、选择下一个 token

方式 效果
贪心解码（greedy） 选概率最高的 token
采样（sampling） 按分布抽取，可能选到别的 token，输出更多样
低温度 采样概率更集中
高温度 采样概率更分散

温度只影响采样的随机性；正的温度缩放不改变贪心选择（最高分的 token 不变）。

十二、训练

  • 训练参考如 "river bank erosion <eos>"：对 bank 位置，可见前缀是 river bank，目标是 erosion；
  • 模型给出整个词表上的分布，交叉熵损失惩罚给已知目标的概率太低（Week 7）；
  • 反向传播算梯度，优化器更新参数；按批（batch）重复。
组成 作用
数据 样本和目标
目标（objective） 定义预测任务
损失 预测误差的度量
梯度 参数微小变化如何影响损失
优化器 决定参数更新

教师强制（Teacher forcing）

  • 训练时：每个位置接收的是已知的参考前缀（river bank → 目标 erosion；river bank erosion → 目标 <eos>）；
  • 生成时：前缀是模型自己实际选出的 token（可能是 erosion，也可能是 policy，后续就从不同前缀继续）。

自回归生成

步 输入前缀 选出的下一个 token
1 river bank erosion
2 river bank erosion <eos>
结果 river bank erosion 遇到结束符停止

自回归 = 每个生成的 token 都以前面的 token 为条件。

并行训练 vs 顺序生成

  • 训练：已知序列提供所有参考输入，因果掩码保证每个预测合法 ⇒ 各位置的预测可以并行计算（块之间仍按顺序通过堆栈）——这是相对 RNN 的主要优势；
  • 生成：必须先选出新 token 才能把它放进下一步前缀 ⇒ 顺序进行。

第五部分：模型家族与适配

十三、三大家族

家族 可用上下文 典型用途 代表
仅编码器 完整输入序列（双向） 分类、输入表示 BERT
仅解码器 已有前缀（因果） 续写、生成 GPT
编码器-解码器 源输入 + 输出前缀 翻译、摘要 原始 Transformer

用途会重叠，家族不唯一决定任务。

任务输出头：词表头（生成）、分类头（用选定或池化的表示）、逐位置标注、检索用向量。

BERT

  • 编码器堆栈，位置能用两侧信息；
  • 掩码语言建模（MLM）：把部分 token 换成 [MASK]，预测原 token。例：river [MASK] erosion → bank；
  • 加任务头 + 微调用于下游任务。（原版 BERT 还用随机替换和保持不变的选中 token。）

GPT

  • 仅解码器的因果堆栈，每个位置只用当前及之前 token；下一个 token 预测训练；
  • 生成时 river bank 的最终 bank 向量给出下一个 token 的分布，选中的 token 扩展前缀；没有交叉注意力。
任务 可见输入 目标 上下文规则
掩码 token 预测 river [MASK] erosion bank 两侧
下一个 token 预测 river bank erosion 只有前缀

十四、预训练、微调与提示

  • 预训练：在大范围数据上学习；自监督——目标从文本本身得来（不需要人工逐 token 标注）；更新嵌入、注意力投影等所有参数；结果是可复用的起点。数据覆盖面和质量很重要。
  • 微调（fine-tuning）：从预训练参数出发（不是从随机值重来），用任务数据继续训练；可更新全部或部分参数，架构通常不变。
  • 指令微调：用「请求–理想回复」对训练，回复 token 作为目标，让模型学会遵循类似请求。
  • 提示（prompting）：提供当前预测所需的指令和上下文，使用现有参数，不更新参数；不同提示改变输入向量和注意力计算，从而改变输出。
方式 用什么 改变什么
预训练 大范围训练数据 学到初始参数
微调 某任务/行为的样本 更新已有参数
提示 指令和当前上下文 只改变输入

上下文窗口

  • 限制一次计算能用的 token 数；生成时包括提示和已输出的 token；加入指令或文档会占用预算；
  • 窗口外的信息不能直接影响注意力；
  • 窗口是可用输入的上限，不保证模型能有效利用其中信息。

第六部分：应用与局限

十五、视觉 Transformer（ViT）与多模态

  • ViT：把图像切成小块（patch）组成序列，每块变成一个向量（相当于文本中的 token 向量），加上位置信息；注意力关联不同区域，MLP 变换每块特征，输出头预测类别。
方面 局部 CNN 标准 ViT
输入表示 空间特征网格 patch 向量序列
信息交换 局部滤波器邻域 跨所有 patch 的注意力
位置结构 网格与滤波器偏移 patch 位置信息
参数复用 共享卷积滤波器 共享投影和 MLP
  • 多模态：视觉编码器把图像变成特征 → 投影成语言模型能用的向量 → 与文本指令结合生成回复。
  • 应用系统：Transformer 嵌在更大的应用里——检索（找相关文档加入上下文，RAG）、输入准备、工具调用（结果作为额外上下文）、输出处理；普通推理时这些只改变上下文，不改参数。

十六、局限与评估

局限 说明
计算随长度平方增长 稠密无掩码自注意力比较每对 query–key 位置：序列长度翻倍 → 位置对变 4 倍（4 倍长度 → 16 倍）
上下文窗口 限制可用信息，长上下文也增加注意力计算量
训练数据 缺口和错误会影响学到的行为
流畅但错误 下一个 token 预测可能生成流畅却不正确的说法

评估要针对预期用途：测试样本与训练样本分开（Week 4）；分类看标签、标注看逐 token 正确性、检索看相关结果是否排前、生成看相关性和事实正确性；还要看在不同输入条件下的稳健性；公平比较需相同任务、数据和条件。

十七、Transformer 小结（对应六个主题）

主题 用 river bank 例子串起来
1. 表示 river bank 变成带位置的向量
2. 注意力 bank 得到 river 和 bank 的 value 的混合
3. 块 重复更新精炼 bank 向量
4. 预测 最终的因果 bank 向量可以预测 erosion
5. 家族与适配 上下文规则、训练、提示塑造行为
6. 应用与局限 输入准备和评估决定应用效果

与 RNN 对比（可能以概念题出现）：

RNN / LSTM Transformer
远距离信息 逐步经过状态更新传递 一层注意力直接连接
训练 必须按时间顺序 已知序列可并行
生成 顺序 仍然顺序（自回归）
顺序信息 链式结构天然具备 需要位置向量
代价 随长度线性 稠密注意力随长度平方

二十二、本周考点速记

Transformer（只考基本思想与好处） 1. 好处：上下文随输入变化；一层注意力直接连接远距离位置；训练可并行（生成仍顺序）；可复用于文本、图像等。 2. token → ID → 嵌入 + 位置向量；ID 无语义，注意力本身不知道顺序。 3. 自注意力：query 与 key 比较 → softmax 得份额 → 加权混合 value；份额依赖输入、参数固定。 4. 多头、残差、层归一化、逐位置共享 MLP。 5. 因果掩码只看当前和之前；编码器看两侧；交叉注意力 query 来自解码器、key/value 来自编码器。 6. BERT = 编码器 + 掩码语言建模；GPT = 仅解码器 + 下一个 token 预测。 7. 预训练 / 微调（改参数）vs 提示（不改参数）。 8. 局限：注意力计算随长度平方增长、上下文窗口、流畅但错误。

聚类（Tutorial，必考手算） 9. K-means：用初始质心分配完全部点再更新；比较平方距离即可。 10. 单链取 min、全链取 max；每步写出更新矩阵；单链易成链、全链偏紧凑。
