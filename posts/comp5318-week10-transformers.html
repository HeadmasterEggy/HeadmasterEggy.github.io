COMP5318 W10：聚类手算练习（Transformer 不考）（讲解版）

本周讲义的 Transformer 整周不考（Ed 帖 187、212）。这里只保留 Tutorial 10 的聚类手算，是 W09 聚类的配套练习。 读法：概念先看 W09。这里只讲每种手算题的固定步骤，然后带你做 Tutorial 的题。

第一部分：三种手算题的固定步骤

1.1 K-means 一轮

  1. 画一张表：每一行是一个点，每一列是一个当前质心，格子里填这个点到这个质心的距离平方。（比较远近不需要开方，开方不改变大小顺序。）
  2. 每一行找最小的那一格，这个点就分给那一列的质心。所有点都分配完，才做下一步。
  3. 每个簇求平均：横坐标加起来除以点数，纵坐标加起来除以点数，得到新质心。

特殊情况：如果题目只给了距离表，没有给坐标，就只能做第 1、2 步（没有坐标就算不出平均值）。题目也只会问分配结果。

1.2 凝聚层次聚类

  1. 在当前距离表里找最小值，把这两个簇合并。记下这个最小值，就是合并高度。
  2. 算新簇到其他每个簇的距离：
    • Single link：取所有跨簇原始点对距离的最小值；
    • Complete link：取最大值；
    • Average link：取平均值。
  3. 划掉旧的两行两列，写上新的一行一列，回到第 1 步。直到只剩一个簇。

1.3 为什么可以「递推」着更新

例如 {A, E} 合并后，{A, E} 到 B 的 single-link 距离 。

之后 {A, E, B} 到 C 的距离 。这等于 ，所以可以直接用上一步表里的数。

Single link 和 complete link 都可以这样递推。Average link 不行：不能对两个平均数再直接取平均，要按点对的个数加权。

1.4 两种链接为什么结果不同

  • Single link 只要两个簇里有一对点很近，就会合并。所以一个大簇会把附近的点一个一个「链」进来，最后常常得到一个很大的簇加几个零散的点（大小不平衡）。
  • Complete link 要求两个簇里最远的一对点也不太远，才会合并。所以簇都比较紧凑，大小也比较平均。

下图是同一张距离表（见下面题目）用两种链接得到的树状图，括号里是合并高度：

Single link 的树像一条链，每次只多加一个点。Complete link 先各自形成两个小簇，最后才合并。

考点小结

  • ★★★ 写出每一步的合并和更新后的距离表（大题按步骤给分）。
  • ★★ 同一张距离表，single 和 complete 的合并顺序可能完全不同。
  • ★ 最小值有两个（平局）时，按题目给的规则选（通常按字母顺序）。

题目

下面 Q2、Q4 用同一张距离表：

A B C D E
A 0 2 7 10 1
B 2 0 3 4 6
C 7 3 0 5 9
D 10 4 5 0 8
E 1 6 9 8 0

Q1（T10 Ex.1） 和上表一样，只是 D–E = 1。初始质心是 A 和 B，K-means 第一轮怎么分配？

每个点比较到 A 和到 B 的距离： C：7 和 3，分给 B。D：10 和 4，分给 B。E：1 和 6，分给 A。 结果：{A, E} 和 {B, C, D}。 只有距离表、没有坐标，算不出平均值，所以不更新质心。

Q2（T10 Ex.2） 用 single link 做凝聚聚类，写出每一步的合并和高度。

第 1 步：表里最小的是 A–E = 1。合并 {A, E}，高度 1。 更新（取最小值）：{A,E} 到 B ；到 C ；到 D 。

第 2 步：现在最小的是 {A,E}–B = 2。合并 {A, E, B}，高度 2。 更新：到 C ；到 D 。

第 3 步：剩下 {A,B,E}–C = 3，{A,B,E}–D = 4，C–D = 5。最小是 3，合并 {A, B, C, E}，高度 3。 更新：到 D 。

第 4 步：合并全部，高度 4。

Q3（T10 Ex.3） 五个点 A(1,1)、B(1,3)、C(4,2)、D(8,6)、E(10,6)，初始质心 A 和 D。做一轮 K-means。

分配：算到 A(1,1) 和 D(8,6) 的平方距离。

点 到 A(1,1) 到 D(8,6) 分给
A(1,1) 0 A
B(1,3) A
C(4,2) A
D(8,6) 74 0 D
E(10,6) D

结果 {A, B, C} 和 {D, E}。

更新： (2, 2)； (9, 6)。

Q4（T10 Ex.4） 用同一张距离表做 complete link，写出每一步的合并和高度。

第 1 步：最小 A–E = 1。合并 {A, E}，高度 1。 更新（取最大值）：{A,E} 到 B ；到 C ；到 D 。

第 2 步：现在表里有 {A,E}–B = 6、{A,E}–C = 9、{A,E}–D = 10、B–C = 3、B–D = 4、C–D = 5。最小是 B–C = 3。合并 {B, C}，高度 3。 更新：{A,E} 到 {B,C} ；{B,C} 到 D 。

第 3 步：剩下 {A,E}–{B,C} = 9，{A,E}–D = 10，{B,C}–D = 5。最小是 5，合并 {B, C, D}，高度 5。 更新：{A,E} 到 {B,C,D} 。

第 4 步：合并全部，高度 10。

Q5（对比） Q2 和 Q4 最后剩下的两个大簇分别是什么？

Single link：{A, B, C, E} 和 {D}，最后在高度 4 合并。 Complete link：{A, E} 和 {B, C, D}，最后在高度 10 合并。 这正好体现了 single link 容易形成一个大簇，complete link 的簇更平均。

Q6（自拟） 用 Q3 算出的新质心 (2,2) 和 (9,6) 做第二轮，分配会变吗？

点 到 (2,2) 到 (9,6)
A(1,1)
B(1,3)
C(4,2)
D(8,6)
E(10,6)

仍然是 {A, B, C} 和 {D, E}，分配没变，收敛了。
