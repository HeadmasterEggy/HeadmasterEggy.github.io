COMP5416 W12：5G、移动性与 QUIC（知识点 + 题型）

这一周考什么：5G 架构（RAN、核心网、CUPS、UPF / AMF / SMF 等功能）；GTP-U 隧道；加入 5G 网络的两个阶段；5G 切换的七步；蓝牙 piconet 和跳频；GEO vs LEO 卫星；IoT 的需求；QUIC：为什么跑在 UDP 上、多流解决队头阻塞、Connection ID 支持迁移、包号单调、超时公式。Sample exam Q2 就是「哪个协议有队头阻塞」，答 TCP。 另外 W12 tutorial 的 LTE 时隙分配和 Mobile IP 转交地址题也在这一篇。

期末题型：全是选择题，有单选也有多选，多选题勾错一个会抵消勾对的一个。计算题主要是 LTE 的公平分配。

读法：从上往下读。每节先讲它要解决什么问题，再给结论。

一、5G 架构

1.1 两大部分

RAN（无线接入网）：把设备连到基站的边缘网络。

  • 提供链路层服务，是设备到更大网络的第一跳。
  • 地理范围有限，由一个运营商控制，有点像 Wi-Fi 局域网。
  • 组成：很多设备（UE，User Equipment）+ 无线信道（NR，New Radio）+ 一个基站（gNodeB / gNB）。

5G 核心网：

  • 在 RAN 和外面（别的核心网、互联网）之间；一个核心，多个 RAN。
  • 全 IP，但提供的服务和普通互联网应用很不一样。
  • 关键设计：控制面和用户面清楚地分开，叫 CUPS（Control-Plane and User-Plane Separation）。
  • 5G 核心主要是控制面的服务。

1.2 核心网的功能

用户面只有一个：UPF（User Plane Function）

  • 每个设备分到一个 UPF，在 UE 和互联网之间中继流量。
  • 负责策略执行、合法监听、流量计量、QoS 监管。
  • 负责和基站之间的隧道（封装 / 解封装，N3 接口）。

控制面：

功能 管什么
AMF（Access and Mobility Management） 接入和移动：连接和可达性管理、移动性管理、接入授权、位置服务
SMF（Session Management） 会话：分配 IP 地址、选 UPF、QoS 控制、用户面路由控制
AUSF（Authentication Server） 认证设备
UDM（Unified Data Management） 用户身份，包括生成认证凭据
UDR（Unified Data Repository） 用户的静态签约信息
UDSF（Unstructured Data Storage） 非结构化数据，类似键值存储
PCF、NEF、NRF、AF、SEPP 策略、对外开放能力、功能注册发现、应用功能、与其他运营商之间的安全边界

记法：AMF 管接入和移动，SMF 管会话；AUSF 认证、UDM 身份；UDR、UDSF 存数据；UPF 是唯一的用户面。

1.3 接口和隧道

  • 控制面：强调功能和服务，服务之间有定义好的接口（N1、N2、N4…）。
  • 数据面：五层互联网数据面，大量用隧道。
接口 两端
N1 UE ↔︎ AMF
N2 基站 ↔︎ AMF
N3 基站 ↔︎ UPF（用户面隧道）
N4 SMF ↔︎ UPF（SMF 控制 UPF）
N6 UPF ↔︎ 互联网

GTP-U 隧道（基站和 UPF 之间）：协议栈从上到下是 用户 IP 数据报 / GTP-U / UDP / 外层 IP / 链路层。

例子：设备地址 z，基站 y，UPF x，互联网上的发送方 w。

段 外层 源 → 目的 内层 源 → 目的
互联网 → UPF w → z
UPF → 基站（隧道） x → y w → z
基站 → 设备 w → z

和 W11 Mobile IP 的「分组套分组」是同一个思路：设备移动时只改隧道端点，设备的 IP 地址 z 不变。

二、加入 5G 网络

2.1 身份

4G / 5G 互联网
你是某个运营商（归属网络）的客户 你是一个名字 + 密码（每个应用一套）
你有 SIM 卡（或 vSIM），它向全世界的蜂窝网络标识你和你的归属网络 或者名字 + 公钥证书
SIM 里有归属网络也知道的密钥

2.2 两个阶段

阶段 内容
1. 注册（Registration） 设备向网络认证自己，网络也向设备认证自己（双向）
2. PDU 会话建立 核心网给设备分配 IP 地址，建立设备到它的 UPF 的数据面路径

AMF 在新设备入网时起关键作用。 大致步骤：设备和基站建立 RRC 连接 → 向 AMF 发注册请求 → AMF 通过 AUSF 认证（可能要找归属网络）→ AMF 更新 UDM → 注册接受 → 设备发 PDU 会话请求 → AMF 找 SMF → SMF 查 UDM 签约、让 UPF 建会话 → 把 IP 地址和隧道信息给设备和基站 → 第一个上行数据报进入数据面。

三、移动性

3.1 移动性的谱

无移动 高移动
换网络时关机 同一个 WLAN / RAN 内移动 同一运营商的多个 WLAN / RAN 之间移动 在多个运营商之间移动，保持连接

讲义说我们关心中间两档（同一运营商内）。

3.2 Wi-Fi 里的移动

  • 802.11 是链路层标准，用链路层方法处理移动。
  • ESS（扩展服务集）：多个 BSS，在同一个三层子网，SSID 相同。
  • ESS 内换 BSS：快速重新认证；AP 可以给设备推荐新 AP。
  • 同一子网里移动，IP 地址不变，只需要交换机（自学习）更新「这个 MAC 在哪个端口」，不需要 Mobile IP。

3.3 5G 切换（handover）

切换：移动设备换一个接入点，发往设备的数据从源基站改走目标基站。

为什么：目标基站信号更强；目标基站设备少、流量少（负载均衡）。

步 动作
1 源基站选目标基站，发 Handover Request
2 目标基站预分配无线时隙，回 HR ACK，附上给设备的信息
3 源基站把新基站的信息告诉设备 → 设备现在可以经新基站发送，对设备来说切换像已经完成了
4 源基站不再发给设备，而是把数据报转发给新基站（新基站再转给设备）
5 目标基站通知 AMF、SMF 自己是新基站；SMF 让 UPF 把隧道端点改到目标基站
6 目标基站向源基站确认切换完成，源基站释放资源
7 设备的数据报经新隧道在目标基站和 UPF 之间走
  • 第 4 步的转发是为了不丢包：UPF 改隧道（第 5 步）之前，下行数据还发到源基站，源基站把它们转给目标基站，目标基站先缓存。
  • end marker：UPF 在旧隧道上发最后一个标记包，告诉「后面不会再有了」，目标基站据此按序交付缓存的数据。
  • UPF 是固定锚点，和 W11 的锚点外地代理、GSM 的锚点 MSC 一个思路。

四、蓝牙、卫星、IoT

4.1 蓝牙

无线 ad hoc 网络：没有 AP 或基站，设备要从零开始互相发现、组网（信道分配、地址、服务发现、应用通信、安全），所以需要一套和互联网不同的架构和协议栈。

piconet：

要点 说明
范围 直径一般 < 10 m
设备数 最多 8 个：先组网的是 central，最多再 7 个 peripheral
通信 只在 central 和 peripheral 之间，peripheral 之间不能直接通信
地址 每个设备一个唯一的 48 位地址
频段 免许可的 2.4 GHz ISM

信道：

经典蓝牙 BLE
每信道带宽 1 MHz 2 MHz
信道数 79 40（3 个广播 + 37 个数据）
最大速率 2.1 Mbps
  • TDM，时隙 625 μs。
  • 信道访问靠轮询（polling）：central 授予 peripheral 发送权。
  • 跳频（frequency hopping）：每个时隙换一个频率，在 79 个信道之间跳；同一 piconet 的设备都知道跳频序列；跳频序列不同的 piconet 可以在同一空间共存。
  • 为什么跳频：减少干扰的影响。某个干扰设备占着信道 x，x 在跳频序列里只偶尔出现；在 x 上发的帧丢了，下一个时隙换频率重传。

协议栈：和互联网完全不同。没有网络层、传输层（经典蓝牙不做路由）；分层不如互联网清晰，host / controller 结构深嵌在架构里。L2CAP 管两设备间的端到端信道，提供可靠性、流量控制、分段；信道类型有面向连接异步、无连接异步、同步（eSCO，如周期性音频）。

4.2 卫星：GEO vs LEO（常考对比）

GEO（地球同步） LEO（低轨）
相对地面 静止 移动，约 27 000 km/h
高度 约 36 000 km（讲义写 35 768 km） 550–1200 km
RTT 约 800 ms 约 30 ms
每颗覆盖 大 小，要很多颗组成星座
可见时间 一直 在地面站视线内只有 5–15 分钟
星间链路 ISL
  • GEO 的 RTT 太大，不适合 VoIP（W08：> 400 ms 体验差）。
  • LEO 星座：Starlink（有 ISL）、OneWeb、Kuiper、Telesat。卫星信道下行广播 / 多播，上行单播。
  • 天上的链路（bent pipe）：基站之间只经过一颗卫星，卫星只做转发。天上的网络：基站之间经过多颗卫星，卫星之间要路由。
  • 卫星应用：感知（天气、土地利用）、广播（直播电视、GPS）、互联网（覆盖没有服务的地区、长距离低时延、飞机上网）。

4.3 IoT

维度 需求
无线 必须
距离 几米到几公里
速率 活跃时几百 bps（抄表）到约 1 Mbps（视频监控）
能耗 一直要考虑：没有外部电源要工作约 10 年；本地能量收集
类型 技术
短距离 Wi-Fi、BLE、Zigbee
低功耗广域 LoRaWAN、LTE-M
传统广域 蜂窝 4G / 5G

五、QUIC

5.1 为什么要改传输层

TCP、UDP 用了 40 年。不同场景下有各种 TCP 变体：

场景 难点
长肥管道 很多分组在路上，一个丢包就让流水线停下
无线网络 噪声链路和移动造成的丢包，TCP 当成拥塞
长时延链路 RTT 极长
数据中心 对时延敏感
后台流量 低优先级的后台流

趋势：把传输层功能搬到应用层，跑在 UDP 上。HTTP/3 用的就是 QUIC。

5.2 QUIC 是什么

  • 应用层协议，跑在 UDP 之上（RFC 9000），目的是提升 HTTP 性能。
  • Google 很多服务和应用在用（Chrome、移动版 YouTube）。
层 HTTP/2 over TCP HTTP/3
应用 HTTP/2 HTTP/2（精简）= HTTP/3
TLS QUIC（加密 + 可靠传输 + 拥塞控制）
传输 TCP UDP
网络 IP IP

QUIC 用的是传输层学过的方法：

  • 差错和拥塞控制：规范原话的意思是熟悉 TCP 的人会觉得这些算法很像 TCP。
  • 连接建立：可靠性、拥塞控制、认证、加密、状态在 1 个 RTT 内建好（连过的服务器可以 0-RTT）。TCP + TLS 要 TCP 握手 1 RTT 再加 TLS 握手。
  • 一个 QUIC 连接上复用多个应用层流：每个流有独立的可靠传输和安全，共用一个拥塞控制。

5.3 多个流：没有队头阻塞（Sample exam Q2）

HTTP/1.1 HTTP/2 over TCP HTTP/2 over QUIC（HTTP/3）
每个 GET 一条 TLS + TCP 连接 多个 GET 复用一条 TCP 连接 每个 GET 一个 QUIC 流，各自可靠传输，共享拥塞控制，跑在 UDP 上
一个分组丢了 → TCP 按序交付 → 所有流都被卡住（HOL 阻塞） 一个流丢包只影响那个流

队头阻塞（head-of-line blocking）：TCP 只有一条按序交付的字节流。中间丢一个段，后面所有字节（哪怕属于别的 HTTP 请求）都得在缓冲区里等它重传。HTTP/2 把多个请求复用在一条 TCP 上，正好把问题放大。QUIC 每个流单独做可靠传输，一个流丢包不影响别的流。

Sample exam 问哪个协议有 HOL，选项里有 TCP、QUIC、HTTP 等，官方只认 TCP。HTTP/1.1 在应用层也有一种 HOL（W03：小对象排在大对象后面），但题目问的是协议层面因丢包重传造成的 HOL。

5.4 QUIC 分组和 Connection ID

QUIC 分组 = QUIC 首部（含 Connection ID、Packet number）+ 若干帧（Stream 帧带 Offset、Length；ACK 帧；其他）。

协议 用什么标识连接
TCP 四元组
UDP 二元组
QUIC Connection ID

设备从 4G 换到 Wi-Fi 时：TCP 的 IP 变了，四元组就变了，连接断开；QUIC 的 Connection ID 不变，连接平滑迁移。

5.5 包号和偏移

字段 作用
Packet number 单调递增、永不重复，重传也用新包号
Stream 帧的 Offset + Length 保证流内数据的顺序
  • 丢包检测和丢包恢复分开：包号负责发现丢包，offset 负责重组。
  • 对比 TCP：TCP 的序号既管检测又管排序，重传段和原段序号一样，收到 ACK 时分不清是对哪一次的确认（RTT 测量歧义），所以 TCP 不测重传段的 RTT（W06）。QUIC 用新包号重传，没有这种歧义。
  • 分组丢了，由应用决定要不要重传丢的帧。

5.6 其他帧

帧 作用
MAX_DATA、MAX_STREAM_DATA 两层流量控制：连接级和流级（TCP 只有一个 rwnd）
PING 检查对方是否还在
CONNECTION_CLOSE 连接正在关闭

注意：讲义 p50 把这两个写反了（写成 MAX_STREAM_DATA 是连接级、MAX_DATA 是流级）。按 RFC 9000 和名字，带 STREAM 的是流级。考题如果直接问这两个帧，留意选项是照讲义还是照 RFC 写的；要点是 QUIC 有连接级和流级两层流控。

5.7 拥塞控制

和 TCP 相似但更先进；包号单调，丢包时没有 RTT 估计歧义。

超时（PTO）：

符号 意思
smoothed_rtt 平滑 RTT（≈ TCP 的 EstimatedRTT）
rttvar RTT 偏差（≈ TCP 的 DevRTT）
kGranularity 定时器粒度，1 ms
max_ack_delay 接收方打算延迟发 ACK 的最长时间

对照 TCP 的 EstimatedRTT + 4·DevRTT，QUIC 多了两项：粒度下限（rttvar 太小时超时不会过短）和对方的最大延迟 ACK。

QUIC 机制 对应 TCP
慢启动 一样
拥塞避免（线性增） 一样
恢复期（窗口减半） ≈ 快速恢复
靠 ACK 发现丢包 ≈ 3 个重复 ACK 快速重传
靠超时发现丢包 一样
持续拥塞 → 回到慢启动 ≈ TCP 超时 cwnd 回 1

持续拥塞：发送方确认足够长一段时间内发出的所有在途分组都丢了。

5.8 历史

2014 年 Google 开始在自家服务和 Chrome 之间部署实验版（改善页面加载时延和视频重新缓冲）；约占 Google 出口流量 35%、互联网流量 7%；2016 年 Akamai 部署、IETF 成立 QUIC 工作组；2021 年 5 月 RFC 9000。

六、W12 Tutorial（官方答案）

6.1 4G LTE 下行时隙分配

下行信道按时隙分、跨 F 个频率（W11 的 OFDM 网格）。四个节点 A、B、C、D，如果基站把全部资源给一个节点，速率分别是 10、5、2.5、1 Mbps。基站对每个节点都有无限数据，每个时隙的每个频率可以给任意一个节点。

Q1：最大发送速率？公平吗？

10 Mbps，全给 A。不公平，只有 A 被服务。（这里「公平」指每个节点分到一样多的时隙。）

Q2：每个节点每秒收到一样多的数据，平均速率是多少？

每个节点只拿到 10/17 ≈ 0.59 Mbps，最慢的 D 占了 10/17 的时隙。速算：每节点速率 = ，总共 4 / 1.7 = 40/17。

Q3：A 最多可以拿到其他任一节点的两倍数据，平均速率？

取 A 正好是其他节点的 2 倍，B、C、D 彼此相等：

公平要求 平均速率
不要求（全给 A） 10 Mbps
时隙相等（自己算的对照） (10 + 5 + 2.5 + 1) / 4 = 4.625 Mbps
A ≤ 2 × 其他 25/9 ≈ 2.78 Mbps
数据量完全相等 40/17 ≈ 2.35 Mbps

公平要求越严格，总吞吐越低。

6.2 Mobile IP：两个移动设备能用同一个转交地址吗？

能。 如果转交地址就是外地代理的地址，两台设备的 COA 自然一样。外地代理解封装后看内层数据报的目的地址（各自的永久地址），就能分别交给不同的设备。

外层目的 = COA（共享），内层目的 = 永久地址（各不相同）。（如果是设备自己在访问网络拿到的「同址转交地址」，就不能共享。）

考点小结

  1. ★★★ QUIC 解决 TCP 的队头阻塞：每个流独立可靠传输；有 HOL 的是 TCP（sample exam）。
  2. ★★★ QUIC 跑在 UDP 上、是应用层协议；1-RTT（0-RTT）建连；Connection ID 支持迁移；包号单调不重复，没有 RTT 歧义。
  3. ★★ QUIC 超时 = srtt + max(4·rttvar, 1 ms) + max_ack_delay；持续拥塞回到慢启动。
  4. ★★★ 5G 核心：CUPS；UPF 唯一的用户面；AMF 管接入和移动；SMF 管会话、分 IP、选 UPF；AUSF 认证；UDM 身份。
  5. ★★ 入网两阶段：注册（双向认证）+ PDU 会话建立（分 IP、建数据路径）。
  6. ★★ 5G 切换：源基站选目标发请求 → 目标预分配 → 设备切过去 → 源基站转发数据 → SMF 让 UPF 改隧道端点 → 释放源资源；设备 IP 不变。
  7. ★★ GTP-U 隧道（N3，GTP-U / UDP / IP）。
  8. ★★ 蓝牙：piconet ≤ 8（1 central + 7 peripheral），peripheral 之间不能直接通信；79 信道、625 μs 时隙、跳频抗干扰。
  9. ★★ GEO vs LEO：高度、RTT（800 ms vs 30 ms）、星座、可见时间。
  10. ★★ LTE 公平分配：数据量相等 40/17 ≈ 2.35 Mbps；A ≤ 2× 其他 25/9 ≈ 2.78 Mbps。
  11. ★ ESS：多个 BSS、同一子网、同一 SSID；IoT 低功耗广域 LoRaWAN、LTE-M；两台设备可以共享外地代理的 COA。

题目

格式照期末：选择题，标「（多选）」的可能不止一个对，但勾错会扣掉勾对的分。

Q1（Sample Exam） 下面哪个协议存在队头阻塞（head-of-line blocking）问题？ A. UDP　B. TCP　C. QUIC　D. HTTP

B。TCP 只有一条按序字节流；QUIC 每个流独立。HTTP/1.1 的应用层 HOL 不是这题要的答案。

Q2（讲义） 关于 QUIC，正确的是？（多选） A. 跑在 UDP 之上 B. 多个流复用在一个连接上，每个流有独立的可靠传输 C. 每个流有自己独立的拥塞控制 D. 可以在 1 个 RTT 内建立可靠性、拥塞控制、认证和加密的状态

A、B、D。拥塞控制是所有流共用的。

Q3（讲义） 手机从 4G 切到 Wi-Fi，IP 地址变了。哪种连接能平滑迁移，为什么？ A. TCP，因为有序号　B. QUIC，因为连接由 Connection ID 标识　C. UDP，因为无连接　D. 都会断

B。TCP 的四元组变了就断。

Q4（讲义） QUIC 重传丢失的数据时，包号怎么处理？ A. 用原来的包号　B. 用新的、更大的包号　C. 包号清零　D. 不带包号

B。所以没有 RTT 测量歧义。

Q5（讲义） QUIC 的超时公式比 TCP 的 EstimatedRTT + 4·DevRTT 多考虑了什么？（多选） A. 定时器粒度下限 kGranularity B. 接收方的最大延迟 ACK 时间 max_ack_delay C. 链路带宽 D. 分组大小

A、B。

Q6（讲义） QUIC 判定持续拥塞（persistent congestion）后会？ A. 窗口减半　B. 回到慢启动　C. 关闭连接　D. 换 Connection ID

B。

Q7（讲义） 关于 HTTP/3 的协议栈，正确的是？（多选） A. 加密由 QUIC 提供 B. 传输层是 UDP C. 传输层是 TCP D. HTTP/3 ≈ 精简的 HTTP/2 跑在 QUIC 上

A、B、D。

Q8（讲义） 5G 核心网里唯一属于用户面的功能是？ A. AMF　B. SMF　C. UPF　D. AUSF

C。

Q9（讲义） 5G 核心网中负责给设备分配 IP 地址、选择 UPF 的是？ A. AMF　B. SMF　C. UDM　D. UDR

B。AMF 管接入和移动。

Q10（讲义） 关于 5G 核心网功能，正确的是？（多选） A. AMF 负责移动性管理和接入授权 B. AUSF 负责认证设备 C. UDM 管理用户身份，生成认证凭据 D. UPF 负责会话管理和 IP 分配

A、B、C。D 是 SMF。

Q11（讲义） CUPS 指的是？ A. 核心网和 RAN 分离　B. 控制面和用户面分离　C. 上行和下行分离　D. 语音和数据分离

B。

Q12（讲义） 基站和 UPF 之间的用户面隧道用的是什么？ A. IP-in-IP　B. GTP-U over UDP/IP　C. TCP　D. RTP

B。N3 接口。

Q13（讲义） 加入 5G 网络的两个阶段是？（多选） A. 注册：设备和网络双向认证 B. PDU 会话建立：分配 IP，建立到 UPF 的数据路径 C. DNS 查询 D. TCP 三次握手

A、B。

Q14（讲义） 关于 5G 切换，正确的是？（多选） A. 由源基站选择目标基站并发出切换请求 B. 切换期间源基站把收到的数据报转发给目标基站 C. SMF 指示 UPF 把隧道端点改为目标基站 D. 切换后设备要换一个新的 IP 地址

A、B、C。设备 IP 不变，变的是隧道端点。

Q15（讲义） 关于 802.11 的 ESS，正确的是？（多选） A. 由多个 BSS 组成 B. 各 BSS 在同一个三层子网 C. 各 BSS 的 SSID 相同 D. 在 ESS 内移动需要 Mobile IP

A、B、C。同一子网内 IP 不变。

Q16（讲义） 关于蓝牙 piconet，正确的是？（多选） A. 最多 8 个设备：1 个 central 和最多 7 个 peripheral B. peripheral 之间可以直接通信 C. 每个设备有唯一的 48 位地址 D. 工作在 2.4 GHz ISM 频段

A、C、D。只有 central 和 peripheral 之间通信。

Q17（讲义） 蓝牙为什么用跳频？ A. 提高速率　B. 减少干扰的影响　C. 加密　D. 省电

B。

Q18（讲义） 关于 GEO 和 LEO 卫星，正确的是？（多选） A. GEO 相对地面静止 B. GEO 的 RTT 约 800 ms C. LEO 单颗覆盖范围大，不需要星座 D. LEO 卫星在地面站视线内只有 5–15 分钟

A、B、D。

Q19（讲义） 适合低功耗广域 IoT 的技术是？（多选） A. LoRaWAN　B. LTE-M　C. BLE　D. Zigbee

A、B。BLE、Zigbee 是短距离。

Q20（Tutorial） LTE 下行，A、B、C、D 独占信道时速率分别为 10、5、2.5、1 Mbps。要求每个节点收到的数据量相等，平均发送速率约为？ A. 1 Mbps　B. 2.35 Mbps　C. 2.78 Mbps　D. 4.625 Mbps

Q21（Tutorial） 同上，改为 A 最多拿到其他任一节点的 2 倍数据，平均速率约为？ A. 2.35 Mbps　B. 2.78 Mbps　C. 4.625 Mbps　D. 10 Mbps

B。25/9。

Q22（Tutorial） 同上，数据量相等时，D 占了多少比例的时隙？ A. 1/17　B. 4/17　C. 10/17　D. 1/4

C。

Q23（Tutorial） 两台移动设备在同一个访问网络里，能不能用同一个转交地址？ A. 不能，转交地址必须唯一 B. 能，如果转交地址是外地代理的地址，外地代理靠内层目的地址区分 C. 能，靠端口号区分 D. 只有在归属网络里才能
