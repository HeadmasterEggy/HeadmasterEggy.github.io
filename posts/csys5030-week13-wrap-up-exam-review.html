一、Wrap-up 讲义

1.1 课程学习目标（6 条）

  1. 理解基本的信息论度量，以及面向时间序列的高级度量，并用它们分析和剖析复杂系统的本质、结构、功能与演化；
  2. 培养可用于复杂系统分析与设计的科学编程能力；
  3. 能理解并扩展一个软件的设计（课上技术 + 自己的阅读）；
  4. 能在选择和使用信息论度量与软件工具分析复杂系统时做出有依据的决定；
  5. 能对真实数据集——尤其是自己专业领域的数据——建立信息论分析；
  6. 能批判性地评估用信息论研究自组织和复杂系统关系的工作及其洞见。

1.3 收尾观点：语境与视角

  • 信息论有很多视角；老师给的是他自己的——聚焦复杂系统的经验分析。
  • 必然略去了很多：
    • 传统的信息论与编码：信道容量（有噪信道编码定理）、信道容量与信噪比的关系、编码等；
    • 在复杂系统中的其他用法：最大熵方法、信息瓶颈、传感器-执行器回路、相变（见 Bossomaier et al. 2016）；
    • 研究前沿：信息论与热力学、部分信息分解（PID，仍在发展）。

1.4 信息论 = 问题与答案

你的估计器总会给你一个答案。但它回答的，是你以为自己在问的那个问题吗？

  • 认真思考你想问数据什么问题，以及信息论是否能、又如何帮你得到答案。
  • 这句话可以串起整门课的「坑」：
    • 用 Gaussian 估计器得到 ≈0，问的其实是「有没有线性关系」（W6–W7）；
    • 滞后 MI 大，可能只是自相关或存储，而不是传递（W7、W11）；
    • 成对 TE 显著，可能来自共同驱动（W11–W12）；
    • 偏差修正后的 AIS 变负，说的是「数据不够证实」，不是「没有影响」（W10）。

1.5 信息论与复杂系统

  • 信息论是研究复杂系统动态与关系的非常强大的方法：
    • 优点：与数据类型无关、能捕获非线性、数学上严格；
    • 复杂系统中我们关心的许多特征（如信息处理）可以直接用信息论度量/建模。
  • 但 Shannon 本人在《The Bandwagon》（1956）中著名地主张：应把信息论的应用限制在通信工程里。
  • 讲义留下的问题：你怎么看？（这门课的立场显然是：只要清楚自己在问什么问题，信息论在复杂系统中大有可为。）

二、考试形式（样卷封面 + Week 8 答疑）

项目 内容
时长 答题 1.5 小时 + 阅读 10 分钟
条件 闭卷；可带双语词典、非编程计算器；无其他电子设备
Section A 20 道选择题，每题 1 分，共 20 分，填在 Gradescope 答题卡上
Section B 3 道简答题，共 20 分，写在试卷上（可用附加页）
提供 公式表（、、 、、 的定义）+ 样例信息论库的函数说明

样例库（Python 或 Matlab；都是 plug-in 估计，离散变量）：

  • 参数是样本数组，xn[i] 是第 i 个样本；多维变量用二维数组（行 = 样本，列 = 维度）；
  • 多个参数时，相同下标的样本是对应样本。

老师在 Week 8 说过的要点：

  • 单位必须写（bits / nats），四舍五入不在意；
  • 代码题看逻辑流程，要写真代码但语法小错不扣分；不会写某个语法可以用注释描述拿部分分；
  • 也可能给 AutoAnalyser 输出让你修改；不需要记方法名、属性名；
  • 考的概念和 Calculation exercises 相同，但更简单。

W5–W6：JIDT 与估计器

  • JIDT 流程：构造 → 设属性 → initialise() → setObservations/addObservations → computeAverageLocalOfObservations()；局部值 computeLocalOfPreviousObservations()。
  • 估计器：Discrete（plug-in）、Gaussian（只看线性，model-based，样本需求少）、Kernel（box 宽度 ≈ 不超过标准差）、KSG（近邻、自适应、非线性、内置偏差修正、可为负）。
  • 有限样本：偏差与方差；离散 plug-in MI 有正偏差。

W7：统计显著性

  • ：独立；surrogate：打乱（独立样本）或旋转（时间序列）源，保留边际、破坏联合；CMI 检验时保持目标与条件变量在一起。
  • p 值 = surrogate ≥ 测量值的比例；默认 100 个 surrogate 太少；bootstrap p 值是随机的。
  • 解析 χ²：Discrete、Gaussian 有，KSG 没有；快、确定但近似。
  • 偏差修正： 。样本量启发式： 状态配置数（最好 ）。
  • 自相关 → DYN_CORR_EXCL（Theiler window）；非平稳数据取（log）差分。
  • 不显著 ≠ 没有关系。

  • 条件于过去：与存储对照、状态转移、协同；PID：AIS = 独有M + 冗余，TE = 独有Y + 协同。

W12：有效网络推断

  • 功能（无向）/ 结构（因果）/ 有效（有向最小解释模型）。
  • 成对 TE + p 值 + 多重比较（Bonferroni α/[G(G−1)]、FDR）；成对方法不处理冗余/协同。
  • 贪心算法：嵌入目标 → 空集 → 条件于 P 选最大显著 CTE → 循环 → 剪枝 → 整体检验；IDTxl（max statistics、非均匀嵌入）。

五、常见陷阱清单

  1. 漏写单位，或 bits/nats 混用（KSG/Gaussian 在 JIDT 默认 nats，Discrete 默认 bits）。
  2. 把 pointwise 量当平均量（或反之）——看题目说的是变量还是取值。
  3. 「严格小于」时忘了排除等号情形（独立）。
  4. 约束题忘了概率表合法性给出的另一侧界。
  5. 「完全基于」只写了一个条件——需要 MI > 0 且条件熵 = 0。
  6. 时滞 MI/TE 样本没对齐（源去尾、目标去头）。
  7. 联合熵用「各自熵相加」代替（只有独立时才成立）。
  8. 认为 CMI 总是 ≤ MI（协同时会更大）。
  9. 认为 KSG 结果为负是 bug（只是「与 0 一致」）。
  10. 认为 Gaussian 估计 ≈ 0 就是「没有关系」（只是没有线性关系）。
  11. 认为不显著 = 没有关系（可能只是样本不够）。
  12. 认为 TE 显著 = 因果（可能是共同驱动；因果源也可能只贡献存储）。
  13. 认为条件 TE 一定比成对 TE「更正确」（两者都需要）。
  14. 混淆有效网络与有向功能网络、结构网络。
  15. 用很大的 k 却只有很少样本（欠采样；偏差修正 AIS 会变小甚至为负）。
  16. 忘记在扫描多个延迟/源对时做多重比较校正。
