Part A：选择题

Q1 按购买特征把无标签客户分组 → D 无监督聚类

Original question (English) · [2 marks] An analyst groups unlabelled customer records by similarities in their purchasing features. Which task best describes this?

  • A. Reinforcement learning.
  • B. Supervised classification.
  • C. Supervised regression.
  • D. Unsupervised clustering.

没有目标标签，目的是发现分组。A 需要奖励信号；B、C 需要标签。

知识点：W01 任务分类、W09 什么是聚类

English answer (Official): D — Learning tasks. There is no supplied target label. The objective is to discover groups from the input features.

Q2 kNN 的预测代价 → B

Original question (English) · [2 marks] A standard k-NN classifier stores its training observations. Which statement about prediction is most appropriate?

  • A. Training removes the need to store any examples or index.
  • B. Prediction may require many distance calculations because the stored observations are consulted.
  • C. Increasing the training set always reduces prediction cost.
  • D. Prediction uses only one fitted intercept and slope.
  • 答案 B：kNN 是基于实例的「懒惰」学习器，预测时要查询存储的样本，可能需要大量距离计算（索引结构如 KD 树可缓解）。
  • A 恰恰相反，必须保存样本；C 训练集越大预测越贵；D 是线性回归。
  • 知识点：W02 kNN 计算复杂度

English answer (Official): B — k-NN complexity. k-NN is an instance-based method. Prediction searches stored examples, so its cost can be substantial; indexing methods can help.

Q3 曼哈顿与欧氏距离 → D（7 和 5）

Original question (English) · [2 marks] For x = (1, 4) and y = (4, 0), what are their Manhattan and Euclidean distances, respectively?

  • A. 7 and 25.
  • B. 25 and 7.
  • C. 5 and 7.
  • D. 7 and 5.

， ，坐标差绝对值为 3 和 4：曼哈顿 ，欧氏 。

  • A 的 25 是没开方的平方欧氏距离；B 顺序反了。
  • 知识点：W02 数值属性的距离

English answer (Official): D — Distance measures. Absolute coordinate differences are 3 and 4. Manhattan distance is 3+4 = 7, and Euclidean distance is √(3²+4²) = 5.

Q4 1R 的最终模型 → B

Original question (English) · [2 marks] A 1R classifier is fitted using several candidate categorical attributes. What distinguishes its final model?

  • A. It combines all attributes into a deep decision tree.
  • B. It uses one selected attribute to form a set of simple prediction rules.
  • C. It predicts a separate class for every distinct full feature vector.
  • D. It requires exactly one training observation per class.
  • 答案 B：1R 对每个属性各建一套「一个取值 → 一个类」的规则，选错误率最低的那一个属性的规则集。
  • A 是决策树；C 是查表/记忆；D 无此要求。
  • 知识点：规则学习（1R / PRISM），周总结里没有单独成节，可对照 W05 决策树（1R 相当于深度为 1 的树）。

English answer (Official): B — 1R. 1R evaluates simple rules based on individual attributes and selects one attribute’s rule set, rather than building conjunctions across many attributes.

Q5 逻辑回归输出 0.83 → A

Original question (English) · [2 marks] A logistic-regression model returns 0.83 for an observation. Under a threshold of 0.5, what is the appropriate interpretation?

  • A. It predicts the positive class and estimates its probability as 0.83.
  • B. It predicts the negative class because the probability is below one.
  • C. It predicts a numeric target of exactly 0.83 using ordinary least squares.
  • D. It guarantees the observation is positive.
  • 答案 A：输出是正类的估计概率；0.83 ≥ 0.5 → 预测正类。
  • B 阈值是 0.5 不是 1；C 逻辑回归用最大似然，不是 OLS，输出也不是数值目标；D 概率 ≠ 保证。
  • 知识点：W03 逻辑回归

English answer (Official): A — Logistic regression. The output is an estimated probability for the positive class. Because 0.83 exceeds 0.5, the assigned label is positive; this is not a guarantee of correctness.

Q6 Ridge 增大惩罚强度 → C 对大系数惩罚更重

Original question (English) · [2 marks] In ridge regression, the penalty strength is increased while the input features and training data stay fixed. What is the direct effect on the optimisation objective?

  • A. The training set automatically receives additional examples.
  • B. Validation labels are added to the training loss.
  • C. Large coefficient magnitudes receive a stronger penalty.
  • D. The intercept must become equal to the number of features.

Ridge 目标 ，λ 变大，系数被压向 0。A、B、D 都与目标函数无关。

知识点：W03 正则化

English answer (Official): C — Ridge regularisation. Ridge adds a scaled sum of squared coefficients to the loss. Increasing that scale strengthens the pressure toward smaller coefficients.

Q7 MAE 与 MSE → B（4/3 和 2）

Original question (English) · [2 marks] For three observations, the true targets are (2, 4, 8) and the predictions are (1, 6, 7). What are MAE and MSE, respectively?

  • A. MAE = 0; MSE = 0.
  • B. MAE = 4/3; MSE = 2.
  • C. MAE = 4; MSE = 6.
  • D. MAE = 2; MSE = 4/3.

残差 ：

  • C 是没除以 n 的总和；D 两者颠倒。
  • 知识点：W03 三类误差

English answer (Official): B — Regression error. Residuals are (1,-2,1). The absolute-error sum is 4 and squared-error sum is 6, giving MAE = 4/3 and MSE = 2.

Q8 朴素贝叶斯的分解假设 → D 给定类别时各特征似然相乘

Original question (English) · [2 marks] Which factorisation is assumed by Naive Bayes when scoring an observation with multiple input features?

  • A. The input features must have equal numeric values.
  • B. The class posterior is identical to the class prior for every observation.
  • C. The features must be independent of the class itself.
  • D. The feature likelihoods multiply conditional on the class.

（条件独立）。

  • C 是常见陷阱：假设的是给定类别下特征之间独立，不是特征与类别独立（那样分类器就没用了）；B 同理。
  • 知识点：W04 朴素贝叶斯的两条假设

English answer (Official): D — Naive Bayes assumption. Naive Bayes assumes conditional independence of features given the class, so the joint class-conditional likelihood is written as a product.

Q9 五折交叉验证中标准化在哪拟合 → D

Original question (English) · [2 marks] During five-fold cross-validation for choosing hyperparameters, where should a standard scaler be fitted for a particular fold?

  • A. On all five folds together before any split.
  • B. Only on that fold’s validation portion.
  • C. On the reserved final test set.
  • D. Only on that fold’s training portion, before transforming its validation portion.
  • 答案 D：只在该折的训练部分上拟合，再变换该折的验证部分。用 Pipeline 可以自动保证。
  • A 在切分前用全部数据拟合 → 验证折信息泄漏；B、C 同样泄漏。
  • 知识点：W04 评估流程、W02 标准化

English answer (Official): D — Cross-validation. Each fold must reproduce the full training procedure without using its validation data to fit preprocessing. A pipeline keeps this separation clear.

Q10 Recall 与 F1 → C

Original question (English) · [2 marks] For the positive class, TP = 18, FN = 6 and FP = 12. What are recall and F1, respectively?

  • A. Recall 0.60; F1 approximately 0.667.
  • B. Recall 0.75; F1 0.750.
  • C. Recall 0.75; F1 approximately 0.667.
  • D. Recall 0.60; F1 0.750.

  • A、D 把 recall 算成了 precision 的 0.60；B 的 F1 = 0.75 是误把 F1 当成 recall。
  • 知识点：W04 性能度量

English answer (Official): C — Classification metrics. Recall = 18/24 = 0.75. F1 = 2×18/(36+12+6) = 36/54 = 2/3 ≈ 0.667.

Q11 树路径对应的规则 → A（AND）

Original question (English) · [2 marks] A tree path goes to the Yes leaf only when Colour = green and Size = small. Which rule expresses that path?

  • A. If Colour = green AND Size = small, predict Yes.
  • B. If Size = small, predict Yes regardless of Colour.
  • C. If Colour is not green AND Size = small, predict Yes.
  • D. If Colour = green OR Size = small, predict Yes.

一条根到叶的路径上所有测试都要满足 → 合取。D 的 OR 会把路径之外的样本也包进来。

知识点：W05 决策树

English answer (Official): A — Decision-tree rules. All tests along one root-to-leaf path must be satisfied, so they form a conjunction. An OR would incorrectly include observations outside the path.

Q12 随机森林额外的随机化 → A 每次分裂只在随机特征子集里搜索

Original question (English) · [2 marks] A random forest uses bootstrap samples. What additional randomisation commonly helps reduce similarity between its trees?

  • A. Search a random subset of candidate features at each split.
  • B. Restrict every tree to a single identical feature chosen once for the whole forest.
  • C. Choose the final prediction using the training labels of the test observations.
  • D. Give all trees identical fixed splits.

降低树之间的相关性，避免强特征主导每棵树。B、D 让树更相似；C 是泄漏。

知识点：W05 Random Forest

图解

flowchart LR
  T["训练集"] --> b1["bootstrap 样本 1"] --> t1["树 1：每次分裂只看随机 k 个特征"]
  T --> b2["bootstrap 样本 2"] --> t2["树 2：每次分裂只看随机 k 个特征"]
  T --> b3["bootstrap 样本 M"] --> t3["树 M：每次分裂只看随机 k 个特征"]
  t1 --> V["多数投票"]
  t2 --> V
  t3 --> V

English answer (Official): A — Random forests. Random feature subsets at each split reduce the tendency for the same strong predictors to dominate every tree.

Q13 AdaBoost 权重调整 → C 被错分样本的相对权重增大

Original question (English) · [2 marks] After a weak classifier is trained in AdaBoost, how are the relative example weights adjusted for the next stage?

  • A. Only correctly classified examples remain eligible for training.
  • B. All example weights are permanently set to zero.
  • C. Misclassified examples gain influence relative to correctly classified examples.
  • D. Weights are determined by input magnitude without reference to errors.

A 正确样本仍参与训练，只是权重降低；B 不会清零；D 权重由错误决定。

知识点：W05 Boosting

图解

flowchart LR
  C1["弱分类器 1"] --> E["分对样本权重 × e/(1−e)，再归一化"]
  E --> W["错分样本相对权重 ↑"]
  W --> C2["弱分类器 2 更关注难样本"]
  C2 --> F["最终：按准确率加权投票"]

English answer (Official): C — AdaBoost. AdaBoost increases relative emphasis on mistakes, encouraging the next learner to address observations the current ensemble finds difficult.

Q14 多项式核 → C 49

Original question (English) · [2 marks] For x = (1, 2) and y = (3, 1), calculate K(x,y) for the kernel K(x,y) = (xᵀy + 2)².

  • A. 29.
  • B. 7.
  • C. 49.
  • D. 25.

， 。B 的 7 是忘了平方；D 的 25 是忘了 +2。

知识点：W06 核技巧

English answer (Official): C — SVM kernels. The dot product is 1×3 + 2×1 = 5. Therefore K = (5+2)² = 49.

Q15 软间隔 SVM 的 C 变大 → B 对间隔违例惩罚更重

Original question (English) · [2 marks] A soft-margin SVM uses a larger value of C, with the same training data and kernel. What changes in the objective?

  • A. The kernel degree automatically increases.
  • B. Margin violations are penalised more strongly relative to the preference for a wide margin.
  • C. Margin violations are no longer allowed under any circumstances.
  • D. The training data are standardised automatically.

C 权衡「宽间隔」与「违例惩罚」。C 很大时接近硬间隔，但只要 C 有限就不是绝对禁止违例（所以 C 选项错）。A、D 无关。

知识点：W06 软间隔 SVM

English answer (Official): B — Soft-margin SVM. C controls the trade-off between margin size and violation penalties. A larger finite C increases the penalty but does not generally prohibit all violations.

Q16 「PCA 就是挑几列原始特征」的纠正 → C

Original question (English) · [2 marks] A student says that PCA simply chooses a subset of the original feature columns. What is the most accurate correction?

  • A. PCA deletes observations while preserving every original coordinate.
  • B. Each component must equal one original feature without scaling.
  • C. Principal components generally define new coordinates formed from linear combinations of the features.
  • D. PCA uses the supplied class labels to rank original columns.

主成分是原始特征的线性组合，定义了新坐标；降维是在新坐标系里保留前几个方向。A 不删样本；B 一般不等于单个原始特征；D PCA 不用标签。

知识点：W06 PCA 的核心思想

English answer (Official): C — PCA coordinates. PCA performs a linear change of coordinates. Dimensionality reduction then retains selected directions in that transformed coordinate system.

Q17 保留至少 90% 方差 → D（两个，90%）

Original question (English) · [2 marks] A dataset has exactly three principal components, with variances 12, 6 and 2. What is the smallest number of leading components that retain at least 90% of the total variance?

  • A. Two components, retaining 80%.
  • B. One component, retaining 60%.
  • C. Three components, retaining 100%.
  • D. Two components, retaining 90%.

总和 20；一个 60%，两个 恰好达标（「至少」包含等于）。A 的 80% 算错；C 不是最少。

知识点：W06 选几个主成分

English answer (Official): D — PCA retained variance. The total is 20. One component retains 12/20 = 60%; two retain 18/20 = 90%, which meets the threshold exactly.

Q18 小批量梯度下降为什么更「吵」 → B 每次只用一部分样本估计梯度

Original question (English) · [2 marks] Why can minibatch gradient descent have noisier updates than full-batch gradient descent?

  • A. It guarantees larger generalisation error on every possible dataset.
  • B. Each update estimates the gradient using only a subset of training examples.
  • C. It has no objective function to minimise.
  • D. It changes the labels randomly before every update.

A 不保证；C 有目标函数；D 不改标签。

知识点：W07 反向传播与训练

English answer (Official): B — Gradient methods. A minibatch gradient varies with the sampled examples. Full-batch descent uses the gradient averaged over the complete training set.

Q19 梯度下降一步 → B (0.2, −0.8)

Original question (English) · [2 marks] At w = (0.5, -1.0), the loss gradient is (3, -2). A gradient-descent step uses learning rate 0.1. What is the new w?

  • A. (0.8, -1.2).
  • B. (0.2, -0.8).
  • C. (0.2, -1.2).
  • D. (-2.5, 1.0).

  • A 是加梯度（往上爬）；C 第二维符号弄错；D 用了学习率 1。
  • 知识点：W07 梯度下降

English answer (Official): B — Gradient descent. Subtract 0.1 times the gradient: (0.5,-1) - (0.3,-0.2) = (0.2,-0.8).

Q20 2×2 最大池化输出 → C 窗口内的最大激活

Original question (English) · [2 marks] For standard 2 × 2 max pooling, what value is passed on from each pooling window?

  • A. The smallest activation in the complete image.
  • B. A newly learned bias independent of the input.
  • C. The largest activation in that window.
  • D. The sum of all learned convolution weights.

池化本身没有可训练权重（B、D 错）；A 是整幅图的最小值，不对。

知识点：W08 池化层

English answer (Official): C — CNN pooling. Max pooling selects the maximum within each spatial window. The standard pooling operation itself has no trainable weights.

Q21 为什么用 LSTM → D 门控状态更新有助于长时间保持信息与梯度传递

Original question (English) · [2 marks] Which property motivates the use of LSTMs rather than a simple RNN for some long-sequence tasks?

  • A. LSTMs require a different unshared recurrent matrix at every time step.
  • B. LSTMs make the ordering of all inputs irrelevant.
  • C. LSTMs eliminate the need to train any weights.
  • D. Gated state updates can help retain information and support gradient flow over longer intervals.

A 循环权重仍共享；B 顺序依然重要；C 当然要训练。门控有助于但不保证完美记忆。

知识点：W08 LSTM

English answer (Official): D — LSTM motivation. LSTM gates regulate what is stored, retained and exposed. They can help with long-range dependencies, although they do not guarantee perfect memory.

Q22 卷积 + 池化后的空间尺寸 → A 8×8

Original question (English) · [2 marks] An 18 × 18 input passes through a 3 × 3 convolution with stride 1 and no padding, then 2 × 2 max pooling with stride 2 and no padding. What is the final spatial size?

  • A. 8 × 8.
  • B. 9 × 9.
  • C. 7 × 7.
  • D. 16 × 16.

B 的 9 是用 18/2；D 只算了卷积那一步。

知识点：W08 卷积层与池化层

图解

flowchart LR
  I["18×18"] -->|"3×3 卷积, s=1, p=0<br/>(18−3)/1+1"| C["16×16"]
  C -->|"2×2 池化, s=2<br/>(16−2)/2+1"| P["8×8"]

English answer (Official): A — CNN output size. The convolution gives (18-3)/1 + 1 = 16 per dimension. Pooling gives (16-2)/2 + 1 = 8 per dimension.

Q23 Dropout 推断 → A 用全部单元，缩放与训练约定一致

Original question (English) · [2 marks] A network was trained using dropout. Which statement about standard inference is appropriate?

  • A. Use all units, with scaling handled consistently with the dropout training convention.
  • B. Continue disabling units without accounting for the training convention.
  • C. Delete every unit that was ever dropped during training.
  • D. Reset all weights to their initial random values.
  • 「inverted dropout」在训练时已除以保留率，推断时不需再缩放；原始约定则在推断时把权重乘以保留率。
  • B 推断时不再随机丢弃；C、D 荒谬。
  • 知识点：W07 Dropout

English answer (Official): A — Dropout at inference. Standard inference uses the full network. With inverted dropout, scaling is already applied during training; under the original convention, it is applied at inference.

Original question (English) · [2 marks] At time 1, V₁(A) = 0.3 and V₁(B) = 0.2. Transitions into B are P(B|A) = 0.4 and P(B|B) = 0.7. The next observation has emission probability 0.5 in B. What is V₂(B)?

  • A. 0.070.
  • B. 0.130.
  • C. 0.060.
  • D. 0.140.

  • B 0.130 是把两条路径相加再乘 0.5（那是 Forward 的做法）；C 0.060 取了较小的那条；D 0.140 忘了乘发射概率。

图解

flowchart LR
  A1["V₁(A) = 0.3"] -->|"×0.4 = 0.12"| B2["V₂(B) = 0.5 × max(0.12, 0.14) = 0.070"]

English answer (Official): A — Viterbi update. Candidate predecessor scores are 0.3×0.4 = 0.12 and 0.2×0.7 = 0.14. Viterbi takes the maximum, then multiplies by 0.5: 0.070.

Q28 减小折扣因子 → A 远期奖励相对即时奖励的权重下降

Original question (English) · [2 marks] In an RL return, the discount factor is reduced while rewards and transitions stay the same. What is the direct effect?

  • A. Later rewards receive less weight relative to immediate rewards.
  • B. Every possible action acquires the same value.
  • C. The environment becomes deterministic.
  • D. Observed immediate rewards change their numerical values.

γ 只改变回报中各期奖励的加权，不改变环境的奖励值或转移（C、D 错），也不会让动作价值都相等（B 错）。

知识点：W12 折扣回报

English answer (Official): A — Discounting. Discounting changes the weighting of future rewards in the return, not the environment’s rewards or transition probabilities.

Q29 为什么图像状态用 DQN 而非 Q 表 → D 共享参数的函数可以在巨大输入空间上近似价值
