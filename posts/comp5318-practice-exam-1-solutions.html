Part A：选择题

Q1 学习任务类型 → A

Original question (English) · [2 marks] A property service uses past sales with known prices to predict the sale price of a new home. Which learning task is this?

  • A. Supervised regression.
  • B. Supervised classification.
  • C. Reinforcement learning.
  • D. Unsupervised clustering.

题干：用已知成交价的历史房屋数据预测新房价格。

  • 答案 A 监督回归：有标签（价格已知）→ 监督；目标是连续数值 → 回归。
  • B 分类要求离散类别；C 强化学习没有「带标签样本」，靠奖励交互；D 聚类没有目标标签。
  • 知识点：W01 机器学习任务分类

English answer (Official): A — Learning tasks. The target is a known numeric price. Learning from labelled examples to predict a continuous target is supervised regression.

Q2 kNN 流水线里标准化参数从哪来 → C

Original question (English) · [2 marks] A k-NN pipeline uses a standard scaler. When evaluating the pipeline on a held-out test set, how should the scaling parameters be obtained?

  • A. Estimate them from the combined training and test sets.
  • B. Standardise each test example separately using its own feature values.
  • C. Estimate means and standard deviations from the training set, then apply them to both sets.
  • D. Estimate them from the test set, then apply them to the training set.
  • 答案 C：在训练集上估计均值和标准差，再用同一组参数变换训练集和测试集。
  • A、D 用到了测试集统计量 → 数据泄漏；B 每个测试样本用自己的值标准化，变换后特征没有意义（单个样本的「标准差」无从谈起），而且与训练集尺度不一致。
  • 知识点：W02 标准化与 kNN、W04 评估流程

English answer (Official): C — k-NN preprocessing. Preprocessing must be fitted using training data only. Test-set statistics would leak information into model development.

Q3 不加权 vs 反距离平方加权投票 → A

Original question (English) · [2 marks] The three selected neighbours have (class, distance) pairs (Red, 2), (Blue, 3) and (Blue, 4). What do unweighted voting and inverse-square weighted voting predict, respectively?

  • A. Unweighted Blue; weighted Red.
  • B. Both Blue.
  • C. Unweighted Red; weighted Blue.
  • D. Both Red.

三个近邻 (Red, 2)、(Blue, 3)、(Blue, 4)。

  • 不加权：Red 1 票，Blue 2 票 → Blue。
  • 加权（权重 ）：Red ；Blue → Red。
  • 所以「不加权 Blue、加权 Red」= A。离得最近的那个点在加权后权重翻盘，这是题目的设计点。
  • 知识点：W02 Weighted Nearest Neighbour

图解

flowchart LR
  N(("新样本"))
  N -->|"d=2, w=1/4=0.25"| R1["Red"]
  N -->|"d=3, w=1/9≈0.111"| B1["Blue"]
  N -->|"d=4, w=1/16≈0.063"| B2["Blue"]
  R1 --> V1["不加权: Red 1 票, Blue 2 票 → Blue"]
  B1 --> V1
  B2 --> V1
  R1 --> V2["加权: Red 0.25 > Blue 0.174 → Red"]
  B1 --> V2
  B2 --> V2

English answer (Official): A — Weighted k-NN. Unweighted votes are Red = 1 and Blue = 2. Weighted votes are Red = 1/4 = 0.25 and Blue = 1/9 + 1/16 ≈ 0.174, so the weighted prediction is Red.

Q4 PRISM 为规则再加一个条件的目的 → B

Original question (English) · [2 marks] While growing a PRISM rule for class Yes, the current rule covers both Yes and No examples. What is the purpose of adding a further condition?

  • A. Make the rule cover every training example.
  • B. Restrict the covered set to improve its purity for class Yes.
  • C. Force the rule to include every available attribute.
  • D. Turn each Yes example into a separate output class.
  • 答案 B：每加一个条件就是在合取式上多一个限制，缩小覆盖集，提高对 Yes 类的纯度（把混进来的 No 排除掉）。
  • A 正好相反（加条件只会让覆盖变少）；C PRISM 不要求用上所有属性，纯了就停；D 胡扯。
  • 知识点：规则学习（1R / PRISM）。周总结里没有单独成节，最接近的是 W05 决策树（树的每条路径就是一条合取规则）。

English answer (Official): B — PRISM. A conjunction adds a restriction. PRISM seeks a rule whose covered examples are pure for the target class; adding conditions can remove covered negatives.

Q5 降低单个大残差影响 → D

Original question (English) · [2 marks] A regression model has one unusually large residual. Which change would reduce the relative influence of that residual on the reported loss?

  • A. Use MSE instead of MAE.
  • B. Square the residuals twice before averaging.
  • C. Report the largest squared residual as the loss.
  • D. Use MAE instead of MSE.
  • 答案 D 用 MAE 代替 MSE：MAE 随残差线性增长，MSE 平方增长，离群点在 MSE 里被放大。
  • A 方向反了；B 四次方更放大；C 只看最大残差，离群点直接决定整个损失。
  • 知识点：W03 三类误差

English answer (Official): D — Regression losses. MAE grows linearly with residual magnitude, whereas MSE grows quadratically. The outlier therefore has less relative influence under MAE.

Q6 L1 让多个系数恰好为 0 → C

Original question (English) · [2 marks] Two otherwise comparable linear models are fitted. One uses an L1 penalty and gives several coefficients exactly equal to zero. What property does this illustrate?

  • A. L1 regularisation requires all features to remain in the fitted model.
  • B. L1 regularisation always improves test accuracy.
  • C. L1 regularisation can produce sparse coefficient vectors.
  • D. L1 regularisation removes the need for choosing a penalty strength.
  • 答案 C：L1（Lasso）能产生稀疏系数向量，相当于自动做特征选择。
  • A 反了；B 正则化不保证提高测试精度；D 惩罚强度 λ 仍需调（交叉验证）。
  • 知识点：W03 正则化

English answer (Official): C — Regularisation. The L1 penalty can set coefficients exactly to zero. Its strength still needs to be selected, and better test performance is not guaranteed.

Q7 最小二乘截距与预测 → C

Original question (English) · [2 marks] For a simple least-squares fit, the mean of x is 3, the mean of y is 7, Sxy = 10 and Sxx = 5. What are the intercept and the prediction at x = 5?

  • A. Intercept 1; prediction 9.
  • B. Intercept 7; prediction 17.
  • C. Intercept 1; prediction 11.
  • D. Intercept 2; prediction 12.

  • 答案 C（截距 1，预测 11）。A 的 9 是算成了 之类；B、D 截距错。
  • 知识点：W03 最小二乘

English answer (Official): C — Least squares. The slope is 10/5 = 2. The intercept is 7 - 2×3 = 1. At x = 5, the prediction is 1 + 2×5 = 11.

Q8 Laplace 平滑解决什么 → B

Original question (English) · [2 marks] A binary feature combination never occurs with class No in a small training sample. Without smoothing, one estimated likelihood is zero. What problem can Laplace smoothing address?

  • A. The classifier otherwise cannot accept categorical features.
  • B. A single unseen feature value otherwise makes the product likelihood zero for that class.
  • C. The class priors must otherwise sum to more than one.
  • D. Smoothing otherwise has to delete every correlated feature.
  • 答案 B：朴素贝叶斯把各特征似然相乘，只要一个似然为 0，整类得分就是 0（零频问题）。平滑给未见取值一个非零估计。
  • A 朴素贝叶斯本来就能处理类别特征；C 先验之和永远是 1；D 平滑与删特征无关。
  • 知识点：W04 零频问题

English answer (Official): B — Naive Bayes. Naive Bayes multiplies feature likelihoods. A zero factor makes the class score zero; smoothing supplies nonzero estimates for unseen categorical values.

Q9 调树深度同时保留独立的性能估计 → D

Original question (English) · [2 marks] A team wants to choose the maximum depth of a decision tree while retaining an independent estimate of final performance. Which procedure is appropriate?

  • A. Choose the depth that maximises test accuracy, and report that same accuracy.
  • B. Use the deepest tree because training accuracy is the final performance estimate.
  • C. Merge test labels into the training set before selecting depth.
  • D. Tune depth on validation data or training-set cross-validation, then evaluate once on the reserved test set.
  • 答案 D：用验证集或训练集上的交叉验证选深度，最后在保留的测试集上只评估一次。
  • A 用测试集调参再报告同一个分数 → 乐观偏差；B 训练精度不是泛化估计；C 把测试标签并入训练，测试集就不独立了。
  • 知识点：W04 评估流程

English answer (Official): D — Evaluation. Validation or training-set cross-validation supports model selection. An untouched test set is used once to estimate the selected model’s performance.

Q10 精确率与召回率 → A

Original question (English) · [2 marks] A binary classifier has TP = 12, FP = 4, FN = 8 and TN = 26. What are positive-class precision and recall?

  • A. Precision 0.75; recall 0.60.
  • B. Precision 0.24; recall 0.76.
  • C. Precision 0.60; recall 0.75.
  • D. Precision 0.75; recall 0.68.

  • 答案 A。C 把两者颠倒了；TN 不进入这两个指标。
  • 知识点：W04 性能度量

English answer (Official): A — Classification metrics. Precision = 12/(12+4) = 0.75. Recall = 12/(12+8) = 0.60. True negatives do not enter these two positive-class measures.

Q11 两个划分比较 → A

Original question (English) · [2 marks] Two candidate splits are applied to the same decision-tree parent node. Split X has lower size-weighted child entropy than split Y. What follows?

  • A. Split X has higher information gain.
  • B. The two splits must have equal information gain.
  • C. Split Y has higher information gain.
  • D. The parent entropy must be zero.
  • ，父节点熵固定。加权子节点熵越小，减掉的越少，增益越大 → X 的 IG 更高，A。
  • B、C 与推理矛盾；D 父熵是否为 0 无法推出（为 0 时两个划分都没有增益）。
  • 知识点：W05 熵与信息增益

English answer (Official): A — Decision trees. Information gain subtracts weighted child entropy from a fixed parent entropy. A smaller subtracted quantity gives a larger gain.

Q12 Bagging 的定义性操作 → B

Original question (English) · [2 marks] What is the defining training-data operation used in bagging?

  • A. Use the test set as an additional bootstrap training sample.
  • B. Fit base learners on bootstrap samples drawn with replacement.
  • C. Partition the features once and assign exactly one feature to each learner.
  • D. Fit each learner only on the examples misclassified by the previous learner.
  • 答案 B：在有放回抽样的 bootstrap 样本上训练各个基学习器。
  • A 用测试集训练是泄漏；C 是一种（不常见的）随机子空间变体，不是 bagging 的定义；D 是 boosting 的思路。
  • 知识点：W05 Bagging

English answer (Official): B — Bagging. Bagging trains base learners on bootstrap samples of the training observations. Sampling with replacement creates varied datasets.

Q13 平方损失下梯度提升树的训练目标 → C

Original question (English) · [2 marks] Under squared-error loss, a later regression tree is trained to correct what the current ensemble has not explained. What are the appropriate training targets for this later tree?

  • A. Current ensemble predictions minus the observed targets.
  • B. The current ensemble predictions themselves.
  • C. Observed targets minus the current ensemble predictions.
  • D. The original targets without accounting for current predictions.
  • 答案 C 残差 ：平方损失的负梯度正好是「观测值 − 当前预测」，新树去拟合还没解释的部分。
  • A 符号反了（拟合它再相加会把误差放大）；B、D 没有利用当前误差。
  • 知识点：W05 Boosting

English answer (Official): C — Gradient boosting. For squared-error gradient boosting, the residual target is observed value minus current prediction, so the learner aims to correct the remaining error.

Q14 两个支持平面之间的距离 → D

Original question (English) · [2 marks] A hard-margin SVM uses support planes wᵀx + b = +1 and wᵀx + b = -1, with w = (3, 4). What is the full distance between the planes?

  • A. 0.20.
  • B. 2.50.
  • C. 5.00.
  • D. 0.40.

  • 答案 D。A 的 0.20 是决策面到一侧支持平面的距离 ，题目问的是两平面之间的全宽。B、C 是把 放到分子上了。
  • 知识点：W06 间隔与支持向量

图解

flowchart LR
  H1["支持平面 w·x+b=+1"] ---|"1/‖w‖ = 0.2"| H["决策面 w·x+b=0"]
  H ---|"1/‖w‖ = 0.2"| H2["支持平面 w·x+b=−1"]
  H1 -.->|"全宽 2/‖w‖ = 0.4（答案）"| H2

English answer (Official): D — SVM margin. The norm is √(3²+4²) = 5. The full margin width is 2/5 = 0.40; 1/5 is the distance from the decision plane to one support plane.

Q15 核 SVM 为什么不必显式存储映射后的向量 → D

Original question (English) · [2 marks] Why can a kernel SVM operate without explicitly storing each transformed feature vector?

  • A. Every nonlinear kernel creates a linear boundary in the original input space.
  • B. The kernel replaces the class labels with distances.
  • C. The kernel removes all dependence on training observations.
  • D. Its optimisation and predictions can use inner products supplied by the kernel.
  • 答案 D：对偶形式的优化和预测只用到内积，核函数直接给出 （核技巧）。
  • A 错：非线性核在原空间里给的是非线性边界；B 核不替换标签；C 预测仍依赖支持向量（训练样本）。
  • 知识点：W06 核技巧

English answer (Official): D — Kernel methods. A kernel computes the inner product of implicit feature mappings. The SVM can use these values without forming the mapped vectors explicitly.

Q16 PCA 前缩放会改变第一主成分 → B

Original question (English) · [2 marks] PCA is applied to two measurements recorded in very different units. Why might scaling the measurements before PCA change the first component?

  • A. PCA uses class labels to choose which unit should dominate.
  • B. PCA is driven by variance, and changing units changes relative feature variances.
  • C. Scaling converts PCA from an unsupervised method into a supervised method.
  • D. PCA always gives the same direction under arbitrary feature rescaling.
  • 答案 B：PCA 由方差驱动，换单位就改变各特征的相对方差，数值大的特征会主导第一主成分。
  • A、C PCA 是无监督的，不用标签；D 正好是错的。
  • 知识点：W06 PCA

English answer (Official): B — PCA. Feature-wise rescaling changes the covariance structure. A large numerical scale can dominate a covariance-based PCA unless scaling is handled deliberately.

Q17 保留至少 85% 方差 → A

Original question (English) · [2 marks] There are exactly four principal components with variances 9, 5, 4 and 2, in descending order. What is the smallest number of leading components needed to retain at least 85% of total variance?

  • A. Three components, retaining 90%.
  • B. Four components, retaining 100%.
  • C. Three components, retaining 85%.
  • D. Two components, retaining 70%.

总方差 。前两个 ，前三个 → 三个，保留 90%（A）。

  • C 的「85%」数字算错；B 不是最少；D 不达标。
  • 知识点：W06 选几个主成分

English answer (Official): A — PCA retained variance. Total variance is 20. Two components retain 14/20 = 70%, whereas three retain 18/20 = 90%. Three is therefore the smallest qualifying number.

Q18 ReLU 负输入 → D 0

Original question (English) · [2 marks] A ReLU unit has a negative pre-activation. What is its output?

  • A. One.
  • B. The unchanged negative pre-activation.
  • C. A probability strictly between zero and one.
  • D. Zero.

。B 是恒等激活；C 是 sigmoid 的性质。

  • 知识点：W07 激活函数

English answer (Official): D — Neural activations. ReLU(u) = max(0,u), so negative pre-activations produce zero. ReLU does not itself return a probability.

Q19 感知机更新 → C

Original question (English) · [2 marks] A perceptron has w = (0.4, -0.2), b = 0.1 and learning rate 0.2. For x = (2, 1), the supplied actual output is a = 1 and target is t = 0. What are the updated weights and bias?

  • A. w = (0.0, -0.4); b = 0.1.
  • B. w = (0.8, 0.0); b = 0.3.
  • C. w = (0.0, -0.4); b = -0.1.
  • D. w = (0.4, -0.2); b = -0.1.

：

  • 答案 C。A 忘了更新偏置（偏置的「输入」恒为 1）；B 符号反了；D 只更新了偏置。
  • 知识点：W07 感知机学习规则

English answer (Official): C — Perceptron update. The correction is η(t-a) = -0.2. Thus wnew = (0.4,-0.2) - 0.2(2,1) = (0,-0.4), and bnew = 0.1 - 0.2 = -0.1.

Q20 同一个边缘检测器用在整张图上 → B 权重共享

Original question (English) · [2 marks] A learned convolutional filter detects the same edge pattern at many image locations. Which design feature enables this with a small number of parameters?

  • A. Discarding the spatial arrangement before convolution.
  • B. Sharing the filter weights across spatial locations.
  • C. Using an independent parameter vector for every pixel location.
  • D. Fixing every convolution weight to the same constant.
  • A 卷积恰恰保留空间结构；C 每个位置独立参数就是全连接，参数量爆炸；D 权重是学出来的。
  • 知识点：W08 卷积层

English answer (Official): B — CNNs. Weight sharing reuses one detector across the image. Each spatial position does not need its own independently learned filter.

Q21 RNN 中把信息带到下一步的是 → A 循环隐状态

Original question (English) · [2 marks] In a simple recurrent neural network, what carries information from an earlier time step into the next one?

  • A. The recurrent hidden state.
  • B. A distinct set of unshared recurrent weights for every sequence position.
  • C. A new independent label for each hidden unit.
  • D. A separate test set at every time step.
  • B 错：循环权重在各时间步共享；C、D 无关。
  • 知识点：W08 简单 RNN

Q23 Dropout 的目的 → D

(b) 加权子熵与信息增益（5 分）
