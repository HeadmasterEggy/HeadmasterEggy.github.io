CSYS5030 Module 5 讲课总结。这周是入门模块与应用模块的分水岭:第一小时回顾 Week 1-4 的答疑(一比特信息拆一半概率空间的直觉、Rényi 熵等其他信息度量家族、entropy/mutual information 的记号规则、plug-in estimator 与最大似然估计、偏差与方差的预告、Guess Who 例子里 pointwise mutual information 的手算),第二小时是 JIDT(Java Information Dynamics Toolkit)的介绍、安装排坑与 Auto Analyser 代码生成工具的实操演示。

CSYS5030 W05：JIDT 和 W01–W04 复习（知识点 + 题型）

这一周考什么：1 bit 和「概率比为 2」的关系；记号规则（逗号、分号、竖线）；从列联表手算 pointwise MI；plug-in = 最大似然估计，以及 bias 和 variance；JIDT 代码的固定五步，会读、会改 AutoAnalyser 生成的代码。

期末题型：简答第 3 题是代码分析，常给一段 JIDT 代码让你读懂、改参数或解释输出。不用背 JIDT 的方法名和属性名。 选择题可能考记号是否合法、1 bit 意味着什么。

读法：从上往下读。每节先讲它要解决什么问题，再给结论和算例。

一、1 bit 到底是什么意思

1.1 结论

从 pointwise MI 看：

1 bit 信息 = 知道 后，实际发生的 的概率翻倍。

1.2 带你算一遍：轮盘

理想化轮盘有 36 个数，一半黑一半红。

  • 不知道颜色： 。
  • 知道是黑色（4 是黑的）： 。
  • bit。「是黑色」排除了一半的数。

注意：一般情况下 1 bit 信息不一定真的「排除一半选项」，可能只是重新分配概率。但只要算出来是 1 bit，在信息量上就等价于排除一半。

换底数：推导里没有用到字母表大小 36，只和 log 的底有关。用 时 1 个单位对应概率比 4。

1.3 熵越大，平均要问的问题越多

熵 4 bits 的变量，每次问最优的 50/50 问题，平均要问 4 次。单个取值可能多也可能少：赛马例子里 50% 赢的那匹 1 个问题就够。

二、记号规则

量 逗号（联合） 分号 条件竖线
熵 任意多个 0 个 最多 1 个
MI 分号两边各任意多个 恰好 1 个 最多 1 个
  • 竖线右边可以有多个变量（用逗号），但竖线只能出现一次。
  • 分号只出现在竖线左边。
  • 三个以上变量的「共享信息」没有公认的定义，本课不深入。

只用 Shannon 这一家族：熵、条件熵、MI、条件 MI 都建立在 上；后面的传递熵也只是条件 MI 用在时间序列上。Rényi 熵等满足不同公理，回答不同问题，不考。

三、带你算一遍：从列联表算 pointwise MI

Guess Who 的 24 个角色，是否有角 × 是否有眉毛：

眉毛 = 有 眉毛 = 无 合计
角 = 有 3 2 5
角 = 无 8 11 19
合计 11 13 24

问：一个角色有角也有眉毛，「有角」给了多少关于「有眉毛」的信息？

  • ：只看「角 = 有」那一行，5 个里 3 个。
  • ：全表 24 个里 11 个。
  • 读法：知道有角后，有眉毛的概率变成原来的 1.31 倍；或者「看到有眉毛的惊讶」减去「已知有角后看到有眉毛的惊讶」。

换一格：有角但没眉毛， bits，是 misinformation。

四、估计：plug-in = 最大似然

4.1 计算 vs 估计

知道什么 得到什么
计算 真实概率分布 熵、MI 的真值
估计 只有有限样本 估计值，本身是随机变量

到目前为止用的都是 plug-in 估计：数频率、当概率、代公式。它等于最大似然估计（MLE）：在这批数据下最可能的值。

4.2 Bias 和 variance

意思 希望
Bias 估计值平均偏离真值多少 小
Variance 换一批同样大小的样本，估计值波动多大 小

公平硬币只抛 10 次，很可能不是 5:5，算出的熵偏离 1 bit。小样本下 plug-in 有系统性偏差，W06 讲怎么修正。

五、JIDT 怎么用

5.1 是什么

  • JIDT（Java Information Dynamics Toolkit）：实现了本课所有信息论度量（包括后面的 AIS、TE），离散和连续数据都支持，每种数据有不同的估计器。
  • 用 Java 写，Python 通过 JPype 调用。
  • 接口统一，换估计器（比如离散换成 KSG）只要换 calculator 类。
  • 离散 calculator 只接受整数，取值必须在 0 到 base-1 之间。
  • AutoAnalyser：GUI，选度量、估计器、数据文件和参数，自动生成 Java / Python / MATLAB 代码。

5.2 代码的固定五步

步骤 做什么
1 用 JPype 启动 JVM，加载 infodynamics.jar
2 读数据（CSV：行是样本，列是变量，% 开头是注释）
3 构造 calculator，传参数（如 base=4）
4 initialise()：准备计算；同一个对象可以重新 initialise 来复用
5 addObservations() 加数据（可多次调用，比如每场比赛加一次），再 computeAverageLocalOfObservations() 得到平均值

默认算平均值。要每个样本的 pointwise 值，用 computeLocalFromPreviousObservations(...)。

5.3 改代码的方法

不用背参数名。在 GUI 里把某个参数改成显眼的值（比如 k 改成 16），重新生成，看代码里哪一行变了。

5.4 带你看一遍：同一份数据，两种配对

样例数据 2coupledDiscreteCols（10000 行，base 4）：

怎么配对 MI
同一行对同一行 0.0007 bits，几乎没关系
打开 time difference = 1（ 对 ） 1.0002 bits

两列真正的耦合在滞后一步。样本怎么配对会彻底改变结论。

常见报错：数据是 0–3（base 4），参数却填 base = 2，会报数据超出范围。

5.5 常见考法

  • 给一段 JIDT 代码，问 base 应该填多少、addObservations 调用几次、输出的是平均还是 pointwise。
  • 给两个 MI 结果（time difference 0 和 1），解释为什么差那么多。
  • 问「要换成连续数据该改哪里」→ 换 calculator 类（比如 KSG），改相应参数。

考点小结

  1. ★★★ 从列联表算 pointwise MI：，读对行和总数，判断正负。
  2. ★★★ JIDT 五步：启动 JVM → 读数据 → 构造 calculator → initialise → addObservations + compute。会读会改，不用背方法名。
  3. ★★ 1 bit ⟺ 概率比为 2；换 log 底数只换单位。
  4. ★★ plug-in = MLE，是估计不是计算；bias（平均偏离）和 variance（批与批之间的波动）。
  5. ★★ 记号：熵没有分号、最多一个竖线；MI 恰好一个分号、最多一个竖线。
  6. ★ 离散 calculator 只收 0 到 base-1 的整数。
  7. ★ 样本配对（time difference）会彻底改变 MI 结果。

Q18（简答·概念，讲义） 为什么说 plug-in 估计出的熵是一个随机变量？这对解读结果有什么影响？

样本本身是随机抽到的，换一批样本，数出来的频率就不同，算出的熵也不同。所以一个估计值不能直接当真值，要考虑它的偏差和波动，判断是不是真有关系还要做显著性检验（W07）。
