第一部分：线性回归

1.1 它要解决什么问题

你有一些麦片的数据：每种麦片的含糖量 和营养评分 。你发现糖越多，评分好像越低。你想用一条直线来描述这个关系，以后来了一种新麦片，只要知道它的含糖量，就能估计它的评分。

这条直线写成：

  • （读作 y-hat）是预测值。头上加个帽子，是为了和真实值 区分开。
  • 是截距：当 时，直线的高度。
  • 是斜率： 每增加 1，预测值平均变化多少。

例如拟合出 ：不含糖时评分约 59.4；每多 1 克糖，评分平均降低 2.42 分。斜率是负数，说明糖越多评分越低。

1.2 哪条直线最好

能画的直线有无数条。直觉上，离所有数据点都最近的那条最好。怎么衡量「近」？

对每个数据点，算它的残差：

残差就是「真实值减预测值」，也就是这个点在竖直方向上离直线有多远。点在线上方，残差为正；在线下方，残差为负。

把所有残差平方后加起来，得到 SSE（残差平方和）：

让 SSE 最小的那条直线，就是最好的直线。这个方法叫最小二乘法（least squares）。

如果把 SSE 再除以样本数 ，就是平均平方误差 MSE：

  • 是样本个数（1.4 节的例子里是 3）。
  • SSE 是「总量」：样本越多它越大，所以不同数据集之间没法直接比。
  • MSE 是「平均每个点错多少」，单位是 的平方，可以跨数据集比较，也方便拿来做最小化的目标。

为什么要平方，而不是直接加起来？

  1. 正的残差和负的残差直接相加会互相抵消。一条很差的直线，残差可能是 +10 和 −10，加起来是 0，看起来像完美。
  2. 平方会让大误差被重罚：误差 2 平方后是 4，误差 10 平方后是 100。

第二部分：误差指标

2.1 MAE、MSE、RMSE

先记住「总量版」的 SSE，其余指标都是在它基础上取平均、开方：

  • MAE（平均绝对误差）：残差取绝对值，再求平均。
  • SSE（残差平方和）：残差平方后直接相加，不除以 。
  • MSE（平均平方误差）：残差平方，再求平均，也就是 SSE ÷ 。
  • RMSE：MSE 开方，单位和 一样，比较好解释。

2.2 选 MAE 还是 MSE

MAE 随残差线性增长，残差翻倍，贡献也翻倍。MSE 随残差平方增长，残差翻倍，贡献变成 4 倍。

所以，如果有一个特别大的残差（比如一个离群点）：

  • 在 MSE 里，它会占据绝大部分，主导整个分数。
  • 在 MAE 里，它的影响小得多。

结论：想减少离群点的影响，用 MAE。如果大误差的代价特别高，想重罚它们，就用 MSE 或 RMSE。

SSE（残差平方和） 回归直线没解释的部分，也就是训练误差

第三部分：逻辑回归

3.1 为什么不能用线性回归做分类

假设要预测一个人是否患病（1 = 患病，0 = 不患病）。如果用线性回归，预测值可能是 1.3 或 −0.2，这不能当作概率，因为概率必须在 0 到 1 之间。

3.4 两个概念题常考的点

为什么叫「线性」模型：把公式变形，可以得到 。左边叫 log-odds（对数几率），它和 是直线关系。所以「线性」指的是对数几率是线性的，不是 本身。

系数怎么求：

  • 线性回归：让平方误差最小。
  • 逻辑回归：让似然最大（maximum likelihood）。意思是，找一组系数，让真实为 1 的样本算出的 尽量接近 1，真实为 0 的样本算出的 尽量接近 0。

第四部分：过拟合与正则化

4.1 过拟合和欠拟合

flowchart LR
  U["欠拟合<br/>训练差，测试也差"] -->|"模型变复杂"| S["刚好<br/>验证集表现最好"]
  S -->|"继续变复杂"| O["过拟合<br/>训练很好，测试很差"]
  O -->|"正则化 / 剪枝 / 提前停"| S
  • 过拟合：模型把训练数据「背」了下来，连其中的噪声也学进去了。表现是训练误差很小，测试误差很大（比如训练 RMSE 0.2，测试 RMSE 8.5）。原因通常是数据太少、噪声多、模型太复杂。
  • 欠拟合：模型太简单，连训练数据的规律都没学到，训练和测试都差。

我们要找的是在验证集上表现最好的复杂度，而不是训练集上最好的。

4.2 正则化：给「系数太大」加惩罚

模型过拟合时，系数往往变得很大，曲线扭来扭去去迎合每个点。正则化的做法是：在要最小化的目标里，再加一项惩罚系数大小的项。

  • 是各个系数（斜率）。
  • （读 alpha）控制惩罚有多重，是我们要选的超参数。
  • 目标 由两部分组成：MSE 要求「拟合得好」，惩罚项要求「系数要小」。模型要在两者之间找平衡。

变大会怎样：

  • 惩罚变重，系数被压得更小，模型更简单。
  • 训练误差通常会上升，但测试误差可能下降（不那么过拟合了）。
  • 非常大时，所有斜率都接近 0，模型对任何输入都预测平均值，变成欠拟合。
  • 时，没有惩罚，就是普通线性回归。

L1 和 L2 的关键区别（必考）：

  • L2（Ridge）：把系数压小，但一般不会压到正好是 0。
  • L1（Lasso）：能把一部分系数压到正好是 0。系数是 0，就等于这个特征被删掉了。所以 L1 会产生「稀疏」的系数，相当于自动做了特征选择。

容易错的地方：正则化不保证测试精度一定提高； 本身也要用验证集或交叉验证来选。

考点小结

  1. ★★★ 最小二乘手算：算平均值 → 算 、 → 斜率、截距 → 预测 → 残差 → MSE。
  2. ★★★ MAE、MSE 手算；对离群点不那么敏感的是 MAE。
  3. ★★ L1 能产生正好为 0 的系数；Ridge 加大 ，系数被压得更小。
  4. ★★ 逻辑回归输出的是正类的概率，0.83 大于 0.5 判为正类。
  5. ★ 判断题：回归线让残差平方和最小；单看 得不到 的正负号；衡量训练误差的是 SSE。

Q3（PE1 Q5） 回归模型有一个特别大的残差。怎样降低它对报告的误差的影响？

用 MAE 代替 MSE。 MAE 随残差线性增长，MSE 随残差平方增长，大残差在 MSE 里会被放大。

Q4（PE1 Q6） 用了 L1 惩罚后，好几个系数正好变成 0，这说明什么？

L1 惩罚能产生稀疏的系数（一部分正好为 0）。这不代表测试精度一定提高，惩罚强度也仍然需要选。

Q5（PE2 Q6） Ridge 回归中，把惩罚强度调大，对优化目标有什么直接影响？

把系数推向更小的压力变大了，因为系数平方和那一项的权重变大了。

Q6（PE2 Q5） 逻辑回归对某个样本输出 0.83，阈值是 0.5，怎么解释？

这个样本属于正类的估计概率是 0.83，大于 0.5，所以判为正类。 这不代表一定正确。
