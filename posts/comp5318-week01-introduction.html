COMP5318 Machine Learning and Data Mining Week 01 讲课总结，整理课程安排与 double pass 规则、数据爆炸与 raw data is useless、ML 与 DM 的区别、数据挖掘的交叉学科来源、监督 / 无监督 / 强化学习三大任务类型，以及 DM process 六步流程。

COMP5318 W01 考点速成：任务类型与 DM 流程

用时约 5 分钟。本周没有计算，考的是「给场景判断任务类型」。两套 Practice Exam 各 1 题（PE1 Q1、PE2 Q1）。 考试形式：2 小时 + 10 分钟阅读，闭卷，可用非编程计算器；30 道选择题 × 2 分 + 4 道计算题 × 10 分。Double pass：期末卷面必须 ≥ 40%。

一、知识点

1. 三类学习任务（必考）

flowchart TD
  S["拿到一个场景"] --> L{"有标签吗？"}
  L -->|"有"| T{"标签是类别还是数值？"}
  T -->|"类别"| C["监督 · 分类"]
  T -->|"数值"| R["监督 · 回归"]
  L -->|"没有，要分组"| K["无监督 · 聚类"]
  L -->|"没有，只有奖励"| RL["强化学习"]
任务 有没有标签 目标变量 例子
Supervised – classification 有 离散类别 spam / not spam；fraud / legitimate
Supervised – regression 有 连续数值 房价、温度、用电需求
Unsupervised – clustering 没有 无 客户分群、文档聚类、基因聚类
Reinforcement learning 没有标签，只有 reward 无 agent 与 environment 交互（W12）
  • Supervised：给定 ，学 ，用来预测没见过的样本。叫 supervised 是因为标签（正确答案）由 domain expert 提供。
  • Clustering 的目标：within-cluster distance 最小，between-cluster distance 最大。
  • 聚类训练不需要标签，但解释每个簇的含义仍需要 domain expert。

2. ML vs DM：ML 是 AI 的核心部分；DM = applied ML，处理大规模、多维数据，用的算法大多来自 ML。

3. 好 pattern 三条件：meaningful、useful、actionable。

4. DM process 六步（迭代，不是直线）

flowchart LR
  A["1 Business<br/>understanding"] --> B["2 Data<br/>understanding"] --> C["3 Data<br/>preparation"]
  C <--> D["4 Modelling"]
  D --> E["5 Evaluation"]
  E -->|"好"| F["6 Deployment"]
  E -->|"不好"| A

Business understanding → Data understanding → Data preparation → Modelling → Evaluation → Deployment

  • 第 3、4 步反复迭代；Evaluation 不好就回到第 1 步。
  • Data cleaning 三类问题：incomplete（缺失值）、noisy（错误、离群点）、inconsistent（NSW vs New South Wales）。

二、考点

  1. ★★★ 判断任务类型：先问「有没有标签」，再问「标签是类别还是数值」。没有标签、要分组 → clustering；靠奖励学序列决策 → RL。
  2. ★ 两个领域知识易错点：标签由 domain expert 引入；无监督也要 expert 解释簇。
  3. ★ DM 六步的顺序，以及某个动作属于哪一步。

三、题目

Q1（PE1 Q1） 用已知成交价的历史房屋数据预测新房售价，属于哪类任务？A. 监督回归 B. 监督分类 C. 强化学习 D. 无监督聚类

答 A。有标签（价格已知）→ 监督；目标是连续数值 → 回归。

Q2（PE2 Q1） 分析师按购买特征的相似度把无标签的客户记录分组。

答：无监督聚类。没有目标标签，目的是从输入特征里发现分组。

Q3（自拟） 判断类型：(a) 根据过去标注过的交易判断新交易是否欺诈；(b) 机器人通过「摔倒扣分、前进加分」学会走路；(c) 预测明天悉尼的用电量。

  1. 监督分类；(b) 强化学习；(c) 监督回归。

Q4（自拟） 「判断数据挖掘能否帮公司达成目标」和「把 NSW 与 New South Wales 统一」分别属于 DM process 的哪一步？

前者是 Business understanding；后者是 Data preparation（清洗 inconsistent 数据）。

Q5（自拟，判断） 聚类不需要标签，所以完全不需要领域专家。

错。训练不需要标签，但给簇命名、判断簇数是否合理仍需要 domain expert。
