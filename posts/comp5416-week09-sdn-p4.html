COMP5416 Week 09 流媒体 tutorial（Lab 7 Streaming）完整解答：播放时刻与按时到达的块数、播放时延与缓冲占用、最小播放时延、卡顿周期与缓冲变满的时间。

COMP5416 W09：流媒体播放与卡顿（知识点 + 题型）

这一周考什么：W09 的讲课（SDN / SKA 嘉宾讲座）不考（Ed #45）。要考的是 W9 tutorial 的流媒体题，W13 复习课也专门讲了播放缓冲。两类题：给出每块到达时间，判断从某时刻起播有几块按时、缓冲里最多几块、最小起播时延；HTTP 流的播放 / 卡顿时长和缓冲填满时间。

期末题型：全是选择题，有单选也有多选，多选题勾错一个会抵消勾对的一个。基础概念（为什么要缓冲、下溢、E(x) 和 r 的关系）在 W08 第三节。

读法：先看第一节的两个模型，再看 tutorial 两道题怎么套。

一、两个模型

1.1 按块播放模型（Exercise 1 用）

  • 视频固定码率编码，每块播放时长都是 Δ。
  • 服务器在 依次发出第 1、2、3… 块。
  • 网络时延会变，所以每块到达客户端的时间不规则。
  • 客户端开始播放后，每块在前一块之后 Δ 播放。

核心公式：从时刻 开始播第 1 块，第 k 块的播放时刻是

第 k 块按时 ⟺ 到达时间 ≤ 它的播放时刻。

三类问题的做法：

问题 做法
从 s 起播，几块按时 每块比较「到达时间」和「s + (k−1)Δ」
缓冲里最多几块 在每个时刻数「已经到达、但还没轮到播放」的块
最小起播时刻 对每块算「到达时间 − (k−1)Δ」，取最大值（最迟那块恰好赶上）

1.2 HTTP 流模型（Exercise 2 用）

符号 意思
B 客户端应用缓冲的总容量（bit）
Q 开始播放前要先缓冲的比特数（起播门槛，不是容量）
r 视频消耗速率（bps）
x 服务器发送速率（恒定，缓冲没满就一直发）

播放时缓冲的净变化率 = x − r：x < r 缓冲被抽干；x > r 缓冲被填满。

x < r：播放和卡顿交替

  • 播放期：缓冲从 Q 开始，以 r − x 的速度减少，减到 0 就卡。
  • 卡顿期：缓冲以 x 的速度重新攒到 Q，再开始播。
  • 播放时间占比 = ，和 Q 无关。加大 Q 只会让每次播放、每次卡顿都更长，比例不变。

x > r：缓冲迟早填满

  • 先以 x 攒到 Q：Q / x。
  • 开始播放后以 x − r 的净速度填剩下的 B − Q。
  • 填满后服务器停发（缓冲不满才发），实际发送速率降到 r。

三、Tutorial Exercise 2：卡顿（官方答案）

Q1：x < r，连续播放和卡顿各多久？

带你算一遍：Q = 1 Mb，r = 2 Mbps，x = 1.5 Mbps。

  • 播放 1 / 0.5 = 2 s
  • 卡顿 1 / 1.5 ≈ 0.67 s
  • 播放占比 = 1.5 / 2 = 75%

Q2：x > r，缓冲初始为空，什么时候填满？

带你算一遍：B = 4 Mb，Q = 1 Mb，x = 3 Mbps，r = 2 Mbps。

  • 攒到 Q：1 / 3 ≈ 0.33 s
  • 再填 3 Mb，净速度 1 Mbps：3 s
  • t_f ≈ 3.33 s

考点小结

  1. ★★★ 第 k 块播放时刻 = 起播时刻 + (k−1)Δ；按时 ⟺ 到达 ≤ 播放时刻。
  2. ★★★ 推迟起播能让更多块按时；最小起播时刻 = max（到达时间 − (k−1)Δ）。
  3. ★★ 缓冲里的块 = 已到达、还没播放的块。
  4. ★★★ x < r：播放 Q/(r−x)，卡顿 Q/x，播放占比 x/r 与 Q 无关。
  5. ★★ x > r：填满时间 Q/x + (B−Q)/(x−r)。
  6. ★ Q 是起播门槛，B 是缓冲容量，别混。

题目

格式照期末：大多是单选；标「（多选）」的可能不止一个对（真题靠题干的复数措辞提示），勾错倒扣，但每题最低 0 分。答题技巧见样卷解析：考试题型与答题技巧。

Q1（Tutorial） 块 1 一到（）就开始播放，哪些块能按时播放？
A. 只有块 1　B. 块 1、4、5、6　C. 块 1–6　D. 全部 7 块

B。

Q2（Tutorial） 推迟到 开始播放，几块能按时？
A. 4　B. 5　C. 6　D. 7

C。只有块 7 迟到。

Q3（Tutorial） 在 开播的情况下，缓冲里最多同时有几块在等待播放？
A. 1　B. 2　C. 3　D. 4

B。

Q4（Tutorial） 在 开播的情况下，块 5 的播放时刻是？
A. 　B. 　C. 　D.

B。 ，k = 5。

Q5（Tutorial） 关于推迟起播时刻，正确的是？（多选）
A. 能让更多的块按时播放
B. 缓冲里同时等待的块可能更多
C. 用户要等更久才开始看
D. 能让平均填充速率变大

A、B、C。网络送数据的速率不会因为起播晚而变。

Q6（Tutorial） HTTP 流，Q = 1 Mb，r = 2 Mbps，x = 1.5 Mbps。每次连续播放多久？
A. 0.5 s　B. 0.67 s　C. 2 s　D. 4 s

C。Q / (r − x)。

Q7（Tutorial） 同上，每次卡顿多久？
A. 0.5 s　B. 0.67 s　C. 1 s　D. 2 s

B。Q / x。

Q8（自拟） x < r 时，把起播门槛 Q 加倍，会怎样？（多选）
A. 每次连续播放时间加倍
B. 每次卡顿时间加倍
C. 播放时间占总时间的比例不变
D. 卡顿不再发生

A、B、C。比例是 x / r。

Q9（Tutorial） HTTP 流，B = 4 Mb，Q = 1 Mb，x = 3 Mbps，r = 2 Mbps，缓冲初始为空。缓冲什么时候填满？
A. 1.33 s　B. 2 s　C. 3.33 s　D. 4 s

C。1/3 + 3/1。

Q10（自拟） x < r 时，播放时间占比是？
A. r / x　B. x / r　C. (r − x) / r　D. Q / B

B。
