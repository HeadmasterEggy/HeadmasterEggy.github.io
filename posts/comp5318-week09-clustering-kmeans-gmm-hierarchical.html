一、什么是聚类

聚类：把数据对象分成若干组（簇 cluster），使得： - 同一簇内的对象彼此相似（类内距离小）； - 不同簇的对象彼此相异（类间距离大）。

相似度用距离度量计算。

聚类是无监督学习

有监督 无监督
标签 给定类别标签 没有标签
目标 建分类器，预测新样本的类 把相似样本分到一起

输入：一组无标签样本 + 期望的簇数 （不一定给出）。

PE2 Q1：「没有目标标签，目的是从输入特征中发现分组」⇒ 聚类。

用途与应用

  • 独立工具直接分组数据；其他算法的组成部分（如预处理：用簇中心代表簇内所有点，相当于降维）。
应用 说明
精准营销 按购买记录、浏览记录、人口统计数据把客户分群，做针对性营销（比群发便宜）
客户流失 找出可能转向其他保险/电力/电话公司的客户群
基因聚类 找结构和功能相似的基因（微阵列数据），帮助理解疾病
文档聚类 专利审查（把相似专利放一起）、个性化新闻推荐
饮食习惯 分析人群饮食模式，推动健康习惯和政策
颜色压缩 像素聚类后用簇中心颜色替换（1600 万色 → 16 色），见 Lab
图像分割 按相似颜色划分图像区域

好的聚类

  • 高内聚（cohesion）：簇内相似度高（距离小）；
  • 高分离（separation）：簇间相似度低（距离大）。

（如何评估聚类质量——讲义预告为下一讲的内容。）

二、距离度量

点与点之间（复习 Week 1–2）

余弦相似度衡量夹角：= 1 ⇒ 夹角 0°；= 0 ⇒ 夹角 90°。

PE2 Q3：差值 3 和 4 ⇒ 曼哈顿 7，欧氏 5。

质心与中心点

定义
质心（centroid） 簇的「中间」，即各点坐标的平均；通常不是真实的数据点
中心点（medoid） 簇中位置最居中的那个真实数据点

簇与簇之间

方法 簇间距离
Centroid 两个质心之间的距离
Medoid 两个中心点之间的距离
Single link（MIN） 两簇元素之间最小的成对距离
Complete link（MAX） 两簇元素之间最大的成对距离
Average link 两簇元素之间成对距离的平均
Ward 方法 合并两簇后 SSE 的增量

PE2 Q25 算例：两簇之间的 4 个跨簇距离为 6、8、4、6 ⇒ single link = 4（最小），average link = 24/4 = 6，complete link = 8。

三、聚类算法分类

类型 代表算法 特点
划分式（partitional） K-means、K-medoids 产生一组簇
基于模型（model-based） GMM 概率模型
层次式（hierarchical） 凝聚式、分裂式 产生嵌套的簇
基于密度（density-based） DBSCAN 高密度区域构成簇
基于网格（grid-based） CLIQUE 把空间划成网格，足够稠密的格子组成簇

本讲覆盖前三类；后两类和聚类评估在讲义中预告为 Clustering II。

四、K-means

算法

划分式、非常流行、需要事先指定 。

  1. 选 个样本作为初始质心（通常随机）；
  2. 把每个样本分配给最近的质心，形成 个簇；
  3. 每个 epoch 结束时：重新计算各簇质心（簇内点的均值）；检查停止条件——质心不再变化则停止，否则用新质心重复 2、3。

K-means 实际在最小化簇内误差平方和（SSE）：

PE1 Q24：分配固定、用平方欧氏距离时，算术平均使簇内平方距离和最小——这就是质心取均值的原因。

更多细节

  • 对初始质心敏感——不同初始化得到不同结果；
  • 「近」由距离度量定义；
  • 大部分收敛发生在最初几个 epoch；常把停止条件放宽为「只有很少的点改变所属簇」；
  • 复杂度 ： 点数、 簇数、 迭代数、 属性数。

对初始化敏感

讲义图示：同一份数据，初始化 1 经约 6 次迭代得到正确的 3 个簇；初始化 2 收敛到错误的划分（两个质心挤在一个自然簇里）。

对策： 1. 多次运行不同随机初始化，取 SSE 最小的（sklearn 的 n_init）； 2. K-means++； 3. 二分 K-means。

K-means++

只改初始质心的选法，其余与标准 K-means 相同：

  • 逐个选质心，直到选够 个；
  • 每一步，每个点被选为下一个质心的概率 ∝ 它到最近已选质心距离的平方：

  • ⇒ 倾向于选离现有质心最远的点 → 初始质心彼此分散；
  • 可能选到离群点，但离群点本来就少；实践中效果很好。sklearn 中 init='k-means++'（默认）。

空簇

分配步骤中没有任何点分给某个簇（只剩初始质心）。换一个初始质心： - 选离所有现有质心最远的点； - 用 K-means++ 的思路； - 从 SSE 最大的簇中选一个点——通常会把该簇一分为二，降低总 SSE； - 多个空簇则重复。

离群点

  • 离群点让质心不具代表性、SSE 变大；
  • 对策：聚类前去除离群点；
  • ⚠️ 有些应用中离群点很重要，不能删：数据压缩（每个点都要被聚类）、金融分析（异常高利润客户可能最有价值）；
  • 也可聚类后处理：记录每个点对 SSE 的贡献，剔除贡献异常大的点（尤其多次运行都如此的）。

二分 K-means（Bisecting K-means）

  • 要得到 个簇：先把数据分成 2 簇，选其中一个再分成 2 个……直到 个；
  • 选哪个簇来分：最大的、SSE 最大的、或综合两者；
  • 对初始化不那么敏感。

K-means 什么时候失效

K-means 适合：球形、密度相同、大小相同、分离良好的簇。

自然簇的情况 K-means 的表现
非球形 / 复杂形状（如两个月牙） 找不到自然簇
大小差异悬殊 把大簇劈开
密度不同 把稀疏的大簇劈开

原因（Lab 解释）：每个簇由中心定义 ⇒ 每个簇是凸的；簇之间的边界恰在两质心正中（Voronoi 图）。可以把 K-means 想成在每个簇中心放一个圆，半径到最远的点为止，圆外的点不属于该簇——硬分配，不考虑确定性。

K-means 小结

优点 缺点
简单、非常流行 对初始质心敏感
相对高效（即使要多次运行） 对非球形、不同大小、不同密度的簇效果差
对样本输入顺序不敏感 对离群点敏感，需预处理
必须事先指定

五、高斯混合模型（GMM）

思想

  • 概率聚类：假设数据由 个正态（高斯）分布的混合生成；
  • 一个分布 = 一个簇；
  • 每个分布的参数（、，多维时为均值向量和协方差矩阵）未知，从随机初值开始迭代估计；
  • 每次估计后算出每个样本属于每个分布的概率，再用这些概率重新估计参数，直到参数不再变化。

GMM 与 K-means 的对应

GMM K-means
E 步：算每个点属于每个簇的概率 分配步：每个点分给最近质心
M 步：重新估计分布参数 更新步：重新计算质心
软（概率）分配 硬（crisp）分配
椭圆形簇（有协方差） 圆形簇

GMM 可视为 K-means 的推广：更灵活——允许椭圆簇、概率隶属。

PE2 Q24：GMM 给出各分量的后验责任度；标准 K-means 和树状图切割给的都是硬分配。

讲义应用：基于 EEG 数据对失眠人群聚类。

六、层次聚类

概念

  • 产生一组嵌套的簇，组织成层次树；
  • 可视化为树状图（dendrogram）——记录合并顺序的树形图（纵轴是合并时的距离）。

优点： - 不需要事先指定簇数——在不同高度「切」树状图即可得到想要的簇数； - 树状图是可解释的聚类过程描述，可能揭示有意义的分类体系（taxonomy）。

两种方式

方式 方向 做法
凝聚式（agglomerative） 自底向上 每个点自成一簇，反复合并直到只剩一簇
分裂式（divisive） 自顶向下 所有点一簇，反复一分为二直到每点一簇；可基于最小生成树实现

凝聚式更常用，本课重点。

凝聚式算法

关键操作：计算簇间距离——single link / complete link / average link / Ward（合并后 SSE 的增量）。

讲义例子（6 个点，single link + 曼哈顿距离）

讲义的数据点和距离矩阵是图片，过程如下： 1. 计算曼哈顿距离矩阵，每点一簇； 2. 最小距离 1 出现在 (B, C) 和 (E, F) 两对，二者不冲突，都合并；用 single link 更新矩阵； 3. 合并 {A} 与 {B, C}； 4. 最小距离 4 出现两次：{A,B,C}–{E,F} 和 {D}–{E,F}，两者都涉及 {E,F}，需要平局规则；假设随机选，合并 {D} 与 {E,F}； 5. 最后合并 {A,B,C} 与 {D,E,F}（同样在距离 4）——最后两次合并都在高度 4； 6. 画出树状图。

手算题：complete link（PE2 Q33）

四个点的距离：AB = 3，AC = 8，AD = 10，BC = 5，BD = 7，CD = 2。

(a) Complete link： - 最小距离 CD = 2 ⇒ 先合并 {C, D}（高度 2）； - 更新： ； ；AB 仍为 3； - 最小为 AB = 3 ⇒ 第二次合并 {A, B}（高度 3）。

(b) 剩下 {A,B} 与 {C,D}，跨簇距离 AC=8、AD=10、BC=5、BD=7： - Single link = min = 5（由 B、C 决定）； - Complete link = max = 10（由 A、D 决定）。

链接 公式 倾向
Single（MIN） 容易形成长链；能发现非球形簇
Complete（MAX） 倾向紧凑、大小相近的簇
Average （ 为两簇点数） 介于两者之间
Ward 合并后 SSE 增量 与 K-means 目标一致

（「倾向」一栏是标准教材补充，讲义未展开。）

应用例子

用层次聚类对时间序列聚类，时间序列间的相似度可用相关系数等。

层次聚类的优缺点

优点 缺点
特别适合有天然嵌套关系的任务（分类体系、层级） 计算昂贵：空间 （存距离矩阵和树状图），时间 （ 层，每层搜索更新 矩阵）
不需要指定簇数 不是增量式的——假设全部数据都在
树状图可解释 对噪声和离群点敏感

离群点：对 Ward 方法问题更大（会增大 SSE），对 single/complete/average 影响小些；离群点往往自成小簇、很晚才合并，可以丢弃小簇来去除。

七、Lab（w9-solutions）要点

K-means

  • 决策边界即 Voronoi 图；
  • 演示 init="random", n_init=1, max_iter=1/2/3：第三次迭代质心几乎不再移动；
  • 不同随机种子 → 不同解；对策：n_init=10（跑 10 次取 SSE 最小）或 init="k-means++"、二分 K-means；
  • 选错（如 4 个自然簇设 ）K-means 也会照样返回结果，把自然簇劈开——选 的方法（肘部法、轮廓系数）在后续讲；
  • 拉伸后的非球形 blobs、moons 数据上 K-means 失败。

GMM

  • 在拉伸（椭圆）数据上效果好：四个簇权重都约 0.25；
  • Task：GMM 用于 moons —— 比 K-means 好但不完美，因为 GMM 适合椭圆形簇，月牙形不是。

颜色压缩（向量量化）

  • 图片 427×640×3 → 重塑为 273,280 × 3（每个像素是 RGB 空间中的一个点），除以 255；
  • MiniBatchKMeans(16)（大数据集用小批量版本更快），每个像素替换成所属簇中心的颜色；
  • 1600 万色 → 16 色，压缩约百万倍，图像仍不错；Task：flower 图压到 24、6、3 色比较。

八、本周考点速记 / 易错点

  1. 聚类 = 无监督；好聚类 = 高内聚 + 高分离。
  2. 质心（均值，常非真实点）vs 中心点（真实点）。
  3. 簇间距离：single = 最小，complete = 最大，average = 平均，Ward = SSE 增量。会从跨簇距离列表直接读出。
  4. K-means 三步：选初始质心 → 分配到最近质心 → 重算质心（均值）；质心不变则停。会用距离矩阵和坐标两种形式手算。
  5. 均值最小化平方距离和；复杂度 。
  6. 对初始化敏感 → 多次运行（n_init）、K-means++（按 概率选分散的初始点）、二分 K-means。
  7. 空簇（换质心）、离群点（预处理或后处理，但有时不能删）。
  8. K-means 失效：非球形、大小不同、密度不同；硬分配、凸簇、边界在两质心中点。
  9. GMM： 个高斯的混合，EM：E 步算责任度（先验 × 密度再归一化），M 步重估参数；软分配、椭圆簇，是 K-means 的推广。
  10. 层次聚类：凝聚（自底向上）/ 分裂（自顶向下）；树状图切割得任意簇数；不需要 。
  11. 凝聚算法：合并最近两簇 → 更新矩阵；平局要规则；会用 single / complete link 手算合并顺序。
  12. 层次聚类：空间 、时间 ，非增量，对离群点敏感（Ward 最敏感）。
