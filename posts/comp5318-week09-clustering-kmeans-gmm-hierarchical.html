COMP5318 W09：K-means、GMM 与层次聚类（讲解版）

这一周考试分量很重：K-means 一轮大题（PE1 第 33 题，10 分）；层次聚类大题（PE2 第 33 题，10 分）；GMM 隶属概率；簇间距离。对应 PE1 第 24、25、33 题，PE2 第 24、25、33 题。更多手算练习在 W10 聚类手算。
不考：基于密度、基于网格的聚类，以及聚类评估（Clustering II，Ed 帖 225）。
读法：从头往下读，两个大题的完整算法都在正文里。

第一部分：聚类是什么

1.1 目标

聚类是无监督学习：数据没有标签，算法自己把相似的样本分到同一组，每一组叫一个簇（cluster）。

好的聚类要满足两点：

  • 同一簇内的点彼此靠近（簇内距离小，叫高内聚）；
  • 不同簇的点彼此远离（簇间距离大，叫高分离）。

1.2 两个代表点

一个簇需要一个「代表」：

  • 质心（centroid）：簇内所有点的坐标平均值。通常不是某个真实存在的点。 例：簇 {(0,1), (2,1)} 的质心 。
  • 中心点（medoid）：簇里最「居中」的那个真实的点，也就是到其他点距离之和最小的那个。当数据是类别型、算不出平均值时用它。

1.3 三类算法

  • 划分式：一次把数据分成 组。代表是 K-means。
  • 基于模型：假设数据是由几个概率分布生成的，每个分布是一个簇。代表是 GMM。
  • 层次式：一层一层地合并（或拆分），最后得到一棵树。

第二部分：K-means

2.1 它要最小化什么

K-means 要把点分成 组，使每个点到自己所在簇的质心的距离平方，全部加起来最小。这个总和叫 SSE：

2.2 为什么代表点用平均值（PE1 第 24 题）

在「距离平方」这个标准下，能让一组点距离平方和最小的那个位置，正好是它们的平均值。

2.3 算法步骤

flowchart LR
  A["选 k 个初始质心"] --> B["每个点分给最近的质心"]
  B --> C["每个簇求坐标平均值，作为新质心"]
  C --> D{"质心变了吗？"}
  D -->|"变了"| B
  D -->|"没变"| E["结束"]
  1. 初始化：选 个点作为初始质心（题目一般会给你）。
  2. 分配：对每个点，算它到每个质心的距离，分给最近的那个。 重要：用当前的质心把所有点都分配完，中途不要更新质心。
  3. 更新：每个簇里的点，每个坐标分别求平均，得到新的质心。
  4. 判断：质心（或分配结果）和上一轮一样，就停止；否则回到第 2 步。

每一轮 SSE 都不会变大，所以算法一定会停下来。但它只能保证找到一个局部最优，不一定是全局最好的分法。

手算技巧：比较远近时，用距离的平方就够了，不用开方。因为开方不改变谁大谁小。

2.5 K-means 的弱点

1. 对初始质心很敏感。 初始质心选得不好，可能收敛到一个很差的结果。比如两个初始质心都落在同一个真实的簇里，那个簇就会被硬切成两半。

三种对策：

  • 多跑几次：每次用不同的随机初始质心，最后取 SSE 最小的那次（sklearn 里的 n_init 参数）。
  • K-means++：第 1 个质心随机选；之后每选一个，每个点被选中的概率和它到最近的已选质心的距离平方成正比。离已有质心越远的点越容易被选中，于是初始质心会分散开。
  • 二分 K-means：先把所有点分成 2 组，然后反复挑 SSE 最大的那组再一分为二，直到有 组。

2. 必须事先告诉它 是多少。

3. 对离群点敏感。 平均值会被一个极端的点拉偏。

4. 只适合「球形、大小差不多、密度差不多」的簇。 K-means 是硬分配（每个点只属于一个簇），两个质心之间的分界线是它们连线的垂直平分线。所以它分不出月牙形的簇，也分不好一大一小的簇。

5. 可能出现空簇：某个质心一个点都没分到。处理办法是换一个质心，比如选离现有质心最远的点，或者从 SSE 最大的簇里挑一个点。

复杂度：，即点数 × 簇数 × 迭代次数 × 维度。对大数据也很快。

第三部分：GMM（高斯混合模型）

3.1 想法

假设数据是由 个正态分布（钟形曲线）混合在一起生成的，每个正态分布就是一个簇。每个分布有三个参数：

  • 均值 ：钟形曲线的中心在哪里；
  • 方差 ：曲线有多宽；
  • 权重 ：这个簇占全部数据的比例。所有 加起来等于 1。

3.2 GMM 和 K-means 最大的区别：软分配

K-means 说：这个点属于簇 1。
GMM 说：这个点有 70% 的可能属于簇 1，30% 的可能属于簇 2。

这个「属于某个簇的概率」叫责任度（responsibility），也叫后验隶属概率。

3.3 责任度怎么算（PE1 第 25 题）

和朴素贝叶斯完全一样的思路：先验 × 似然，再除以总和。

  • ：簇 的权重（先验）。
  • ：点 在第 个钟形曲线下的高度（似然）。

  1. 分子：分量 1： ；分量 2： 。
  2. 总和： 。

容易错的选项：0.12 是没有除以总和的分子；0.538 是分量 2 的责任度。

再看一个直观的例子：两个分量，中心分别在 0 和 4，宽度都是 ，权重各一半。

  • 点 ：离 0 近，离 4 远。 ， 。分量 1 的责任度 ，几乎肯定属于分量 1。
  • 点 ：正好在 0 和 4 中间。 ，责任度各 0.5。K-means 会硬把它分给某一边，GMM 会说「一半一半」。

3.4 用 EM 算法估计参数

flowchart LR
  A["随机初始化 μ, σ, π"] --> E["E 步：算每个点对每个分量的责任度"]
  E --> M["M 步：用责任度当权重，重新估计 μ, σ, π"]
  M --> C{"收敛了吗？"}
  C -->|"没有"| E
  C -->|"是"| R["每个点得到属于各簇的概率"]

两步交替，和 K-means 的「分配、更新」很像：

  • E 步：用当前的参数，算每个点对每个分量的责任度。（对应 K-means 的分配，但是软的。）
  • M 步：用责任度当权重，重新算参数。比如新的 是所有点按它们对分量 的责任度加权求的平均；新的 是所有点对分量 的责任度的平均。（对应 K-means 的更新质心。）

3.5 和 K-means 对比

K-means GMM
分配方式 硬分配：每个点只属于一个簇 软分配：每个点对每个簇都有一个概率
簇的形状 圆形（球形） 可以是椭圆
两者关系 GMM 的一种特殊情况 K-means 的推广

PE2 第 24 题：想得到每个点属于每个分量的概率，而不只是一个硬分配，选 GMM。

第四部分：层次聚类

4.1 凝聚式层次聚类的步骤

flowchart LR
  A["每个点自成一簇，算好两两距离表"] --> B["合并距离最小的两个簇"]
  B --> C["更新距离表：single 取最小值，complete 取最大值"]
  C --> D{"只剩一个簇了吗？"}
  D -->|"没有"| B
  D -->|"是"| E["画成树状图，在任意高度切开"]
  1. 一开始，每个点自己是一个簇。算出所有点两两之间的距离，填成一张表。
  2. 在表里找最小的距离，把这两个簇合并成一个。记下合并时的距离（叫合并高度）。
  3. 算新簇到其他每个簇的距离，更新表格。
  4. 重复第 2、3 步，直到所有点合并成一个簇。

这叫凝聚式（自底向上，更常用）。反过来从一个大簇开始逐步拆分，叫分裂式（自顶向下）。

4.2 两个簇之间的距离怎么定义（必考）

一个簇里有多个点时，「两个簇之间的距离」有几种定义。先列出所有跨簇的点对（一个点来自簇 1，另一个来自簇 2），算出它们的距离，然后：

方法 取什么 特点
Single link（单链接） 所有跨簇点对距离的最小值 只要有一对点很近就合并，会一个点一个点地「链」上去，能找到细长的簇，但容易被一串噪声点连成一大片
Complete link（全链接） 所有跨簇点对距离的最大值 要求最远的一对也不太远才合并，簇比较紧凑、大小均衡
Average link（平均链接） 所有跨簇点对距离的平均值 介于两者之间
Ward 合并后 SSE 增加多少 和 K-means 的目标一致

例子（PE2 第 25 题）：一维的两个簇 A = {0, 2}，B = {6, 8}，用绝对距离。

跨簇点对：0 和 6（距离 6）、0 和 8（8）、2 和 6（4）、2 和 8（6）。

  • Single link 4
  • Complete link
  • Average link 6

4.3 带你完整算一遍（就是 PE2 第 33 题）

题目：一维的四个点 A = 0，B = 3，C = 8，D = 10。
(a) 用 complete link，给出第一次合并、合并后新簇到其余单点的距离、第二次合并；(b) 剩下的两个簇之间的 single-link 距离和 complete-link 距离分别是多少？各由哪一对点决定？

第 1 步：算两两距离。

A(0) B(3) C(8) D(10)
A — 3 8 10
B — 5 7
C — 2

(a) 第 2 步：第一次合并。 表里最小的是 C–D = 2，合并成 {C, D}，高度 2。

第 3 步：用 complete link 更新距离（取最大值）。

  • 到 A
  • 到 B
  • A 到 B 还是 3

第 4 步：第二次合并。 现在最小的是 A–B = 3，合并成 {A, B}，高度 3。

(b) 剩下两个簇 {A, B} 和 {C, D}。 跨簇点对的距离：A–C 8，A–D 10，B–C 5，B–D 7。

  • Single link 最小值 5，由 B 和 C 决定。
  • Complete link 最大值 10，由 A 和 D 决定。

4.4 树状图（dendrogram）

把每一次合并画成一个连接，竖直方向的高度是合并时的距离。上面的例子用 complete link：C、D 在高度 2 连起来；A、B 在高度 3 连起来；两大块在高度 10 连起来。

层次聚类不需要事先指定簇的个数。 想要几个簇，就在合适的高度横着切一刀：

  • 在高度 4 切：得到 {A, B} 和 {C, D} 两个簇。
  • 在高度 2.5 切：得到 {A}、{B}、{C, D} 三个簇。

4.5 容易错的地方

  • 更新距离时，一定要回到原始的点对距离去取最小值或最大值。
  • 距离出现平局时，按题目给的规则选。
  • 先合并的不一定是你直觉上的那一对，每一步都要在更新后的表里重新找最小值。

缺点：要存所有点两两之间的距离（空间 ），简单实现的时间是 ；合并了就不能撤销；对噪声和离群点敏感。

考点小结

  1. ★★★ K-means 一轮：列平方距离表 → 分配 → 求平均得新质心。先全部分配完再更新。
  2. ★★★ 层次聚类的合并顺序：找最小距离合并 → 按 single（最小）/ complete（最大）更新 → 再找最小。
  3. ★★★ 簇间距离：列出所有跨簇点对的距离，取最小 / 最大 / 平均。
  4. ★★ GMM 责任度 = 先验 × 似然，再除以总和；GMM 给出软分配。
  5. ★★ 平方距离下平均值最优；K-means 对初始化敏感；K-means++ 按距离平方的概率选初始质心。
