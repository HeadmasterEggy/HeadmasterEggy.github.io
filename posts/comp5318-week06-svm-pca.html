读法：从头往下读。SVM 先理解「马路」的比喻，后面的公式就都好懂了。

第一部分：线性 SVM

1.1 它要解决什么问题

平面上有两类点，比如红点和蓝点，可以用一条直线把它们分开。但能分开它们的直线有无数条，选哪一条？

SVM 的回答：选离两边最近的点都尽可能远的那条。

想象在红点和蓝点之间修一条马路：

  • 马路的中线就是分界线（决策边界）。
  • 马路的两条边线各自碰到至少一个点，马路里面不能有点。
  • 让马路尽量宽。

马路的宽度叫间隔（margin）。正好碰在边线上的那几个点叫支持向量（support vector），因为马路就是被它们「撑住」的。

为什么马路要宽：将来来的新数据，和训练数据不会一模一样，总会有些偏差。如果分界线紧贴着某个训练点，新点稍微偏一点就会被分错。马路越宽，留给偏差的空间越大，分类越稳。

2.3 C 的作用（必考）

决定「越界」被罚得有多重：

C 效果
C 很大 越界被罚得很重，模型会想尽办法不让点越界，马路就变窄，紧贴数据，容易过拟合。（但只要 C 是有限的数，仍然允许少数越界。）
C 很小 越界很便宜，模型宁可放几个点越界，也要把马路修宽。更简单，但可能欠拟合。

一句话：C 调大 = 对间隔违例的惩罚更重。

第四部分：PCA（主成分分析）

4.1 想法：换一组更好的坐标轴

例子：你有一群人的身高和体重数据，画在平面上。因为高的人一般也重，这些点大致沿着一条斜线分布。

用原来的坐标（横轴身高、纵轴体重）描述每个点，两个数都要。

现在把坐标轴转一下：

  • 新的第一根轴沿着那条斜线（「整体块头大小」的方向）；
  • 新的第二根轴和它垂直。

在新坐标下，点在第一根轴上分得很开（方差很大），在第二根轴上都挤在 0 附近（方差很小）。把第二根轴扔掉，只用第一个坐标，几乎没有损失信息。 两个数变成一个数，这就是降维。

PCA 就是自动找出这组新坐标轴的方法。

4.2 PCA 的定义

  • 新的坐标轴叫主成分（principal component，PC），它们两两垂直（正交）。
  • 第一主成分是数据方差最大的方向；第二主成分是和第一个垂直的方向里方差最大的；以此类推。
  • 每个主成分都是原始特征的线性组合，比如 PC1 。
  • PCA 是无监督的（不看标签），也是线性的。

为什么看方差：一个方向上数据分得越开，说明它包含的信息越多；所有点都挤在一起的方向，几乎不能区分样本，信息少。

容易错的地方（PE2 第 16 题）：PCA 不是从原始特征里挑几列。挑列是特征选择。PCA 是先把整个坐标系转一下，然后在新坐标系里保留前几个方向。每个新特征都混合了所有原始特征。

  C --> D["选最小的 k，使累计方差比例达到要求"]
  D --> E["把数据投影到前 k 个主成分上，作为新特征"]

4.4 PCA 前为什么要缩放（必考）

PCA 只看方差。如果身高用厘米（方差几百），收入用元（方差上亿），收入的方差大得多，第一主成分几乎就是「收入」这一个方向。这不是因为收入更重要，只是因为它的单位让数字更大。

换个单位（比如收入改用万元），方差就变了，主成分也跟着变。

所以要先标准化，让每个特征的方差都是 1，再做 PCA。缩放参数和 PCA 本身都只在训练集上算，然后用同样的参数变换测试集。

Q3（PE1 Q15） 核 SVM 为什么可以不显式存下每个映射后的特征向量？

因为它的训练和预测只用到点积，而核函数可以直接算出这些点积。

Q4（PE2 Q15） 软间隔 SVM 把 C 调大，目标函数有什么变化？

对间隔违例（越界）的惩罚更重了。 只要 C 是有限的，仍然允许一些违例。

Q5（PE1 Q16） 两个特征的单位差别很大。为什么 PCA 前做不做缩放，会改变第一主成分？

PCA 由方差决定，换单位会改变各特征方差的相对大小。 PCA 不用类别标签。

Q6（PE2 Q16） 有同学说「PCA 就是挑出几列原始特征」。最准确的纠正是什么？

PCA 是一次线性的坐标变换（转坐标轴）；降维是在新坐标系里保留其中一部分方向。
