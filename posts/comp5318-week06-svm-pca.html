第一部分：支持向量机（SVM）

一、用超平面分隔数据

二分类（方块 vs 圆点）。目标：找一个线性边界（2 维是直线，高维是超平面）把两类分开。

  • 若数据线性可分，能把它们分开的超平面有无穷多个（B1、B2……）。
  • 问题：选哪个？

二、间隔与支持向量

概念 定义
间隔（margin） 决策边界与最近的训练样本之间的距离；边界位于间隔正中
支持向量（support vectors） 离决策边界最近、恰好「顶住」间隔边缘的训练样本
  • 每个类可以有多个支持向量（讲义图中 5 个：方块 3 个、圆点 2 个）。
  • 为什么叫「向量」：训练样本本身就是输入向量（每一维是一个特征），支持向量是它们的一个子集。

最大间隔超平面

SVM 选择间隔最大的超平面（maximum margin hyperplane）——即离训练样本尽可能远的那个。

理由： - 间隔小 → 边界附近的样本或超平面稍有扰动就会改变分类结果，更容易过拟合； - 间隔大 → 对数据的小变化更有余地、更稳健，泛化更好； - 统计学习理论依据：结构风险最小化（structural risk minimization）原则。

五、软间隔 SVM

动机：硬间隔要求零训练错误。假设 B1 间隔更大，但新加入的 2 个样本被 B1 分错、被 B2 分对——这并不说明 B2 更好，那 2 个点可能是噪声；B1 间隔大，对过拟合和噪声更不敏感，仍应优先。

做法：允许一些误分类，在间隔宽度与误分类数量之间折中 ⇒ 即使数据线性不可分也能构造线性边界。

优化目标多了一个超参数 （标准形式，讲义只给了文字描述）：

侧重 效果
大 更重视最小化训练误差 间隔窄、边界弯向每个点，易过拟合
小 更重视最大化间隔 间隔宽、模型受限，可能欠拟合

PE2 Q15：大的有限 只是加大违例惩罚，并不会一般性地禁止所有违例。

六、非线性 SVM 与核技巧

思想

实际问题大多线性不可分。做法：

  1. 用映射 把数据从原特征空间变换到新空间（通常更高维）；
  2. 非线性变换到高维空间后，更可能找到线性边界；
  3. 新空间里学到的线性边界映射回原空间 → 原空间中的非线性边界。

讲义例： ，原本线性不可分的数据在新空间变得线性可分。

七、SVM 小结

三个关键概念： 1. 决策边界 = 最大间隔超平面，表述为优化问题； 2. 把数据变换到（通常更高维的）新空间，更可能线性可分； 3. 核技巧——计算在原空间完成，不在高维新空间。

其他： - 能形成任意（线性和非线性）边界； - 多分类：转化为多个二分类问题；回归：Support Vector Regression； - 核化可推广：任何能改写成只依赖点积的算法（如 kNN）都能把点积换成核函数； - 由 Cortes & Vapnik（1995）提出。

第二部分：降维与 PCA

八、为什么要降维

很多 ML 问题有成千上万个特征，高维带来的问题：

问题 说明
训练变慢 —
分类不可靠 高维数据非常稀疏，样本彼此都很远（维度灾难）
更易过拟合 —
难以构建可解释模型 希望得到紧凑、好理解的模型
无法可视化 人最多理解 3 维
并非所有特征都重要 希望找到充分且必要的小特征集

降维能去掉冗余和高度相关的特征、降低噪声。

九、PCA 的核心思想

  • 最流行的降维方法，也叫特征投影（feature projection）方法；
  • 找一组新的坐标轴，把数据投影上去；新空间维度 < 原空间维度；
  • 新轴捕捉数据的本质（变异性 / 方差）；
  • 投影后的数据可作为 ML 算法的输入——构造了数量更少的新特征。

直觉例子

  • 例 1：数据沿 X 方向拉得很长 ⇒ 最大变异在 X 轴。
  • 例 2：数据沿对角线分布 ⇒ 最大变异既不在 X 也不在 Y，而在新轴 上：

；主成分是原特征的线性组合。

定义

给定 个 维样本，找 个两两正交的新轴 ，使

  • ：方差最大的方向；
  • ：与 正交、方差第二大的方向；
  • ：与前两者都正交、方差第三大……

这些轴叫主成分（principal components），定义了一个新坐标系。

PE2 Q16：PCA 本质是一次线性坐标变换；降维是在新坐标系中只保留部分方向。

降维：只取前 个（ ）主成分，把数据投影上去。例 2 中只保留 ，每个点只需一个坐标。

十、选几个主成分

方法 做法
方法 1：方差阈值 设定要保留的最小方差比例（如 95%），选最小的 使前 个主成分累计达到它
方法 2：肘部法（Elbow） 画「维数 → 累计解释方差」曲线，在增长明显放缓的拐点处取（主观）

MNIST：95% 方差需要 153 维；肘部（主观）约 100 维。

PE1 Q17 / PE2 Q17 算例（特征值即各主成分方差）： - PE2：总方差 20，1 个主成分保留 12/20 = 60%，2 个保留 18/20 = 90%——阈值 90% 恰好达到，选 2。 - PE1：方差 9、5、4、2（总和 20），要保留 ≥ 85%：前两个 14/20 = 70%，前三个 18/20 = 90% ⇒ 至少选 3 个。

累计比例 = 前 个方差之和 / 全部方差之和。

十一、PCA 在 iris 上

  • 150 朵花、3 类、4 个原始特征 → 2 个主成分；
  • PC1 解释 92.5% 方差，PC2 解释 5.3% ⇒ 4 维降到 2 维几乎没丢信息；
  • setosa 与另两类分得很开；versicolor 与 virginica 靠近但也大致可分；
  • 用新特征训练分类器（kNN、NB…），若新表示更好，准确率甚至可能提升 ⇒ 这就是 PCA 用于特征提取。

十四、PCA 用于特征提取：人脸识别

LFW 数据集：3,023 张、62 人，每张 87×65 = 5,655 个像素特征；每人最多取 50 张。

为什么不给每个人建一个分类器？ 人多、每人图片极少，难以训练；新增照片还要重训。改用最近邻：找最相似的人脸，每人 1 张图也能工作。

表示 1-NN 测试准确率
随机猜 1/62 ≈ 1.6%
原始像素 27%
PCA 前 100 个主成分 36%

原始像素逐位置比较灰度：难以捕捉面部特征，对平移敏感（右移 1 像素就差很多）。PCA 提供了更好的表示。

可视化主成分：PC1 似乎编码人脸与背景的对比，PC2 编码左右两侧光照差异（并非总能解释）。

十五、PCA 小结

  • 无监督——不使用类别信息；
  • 把数据投影到低维空间，仍保留重要信息；
  • 新轴按捕获的方差排序，相互正交；
  • 只保留前几个主成分实现降维；
  • 用途：降维 / 特征提取 / 压缩 / 可视化。

十六、SVM 实践

内容 代码 / 结论
先归一化 SVM 对特征尺度敏感，breast cancer 数据先 MinMaxScaler（只在训练集上 fit）

C 与 gamma 对 RBF-SVM 决策边界的影响（moons 数据）：

超参数 小 大 过拟合时 欠拟合时
gamma（RBF 宽度的倒数） 钟形曲线宽、每个样本影响范围大 → 边界平滑，近乎直线 钟形窄、影响范围小 → 边界不规则，绕着单个样本弯曲 减小 gamma 增大 gamma
C（正则化） 模型受限、单点影响小 → 误分类点不影响边界 限制少、所有点影响大 → 边界弯曲去分对每个点 减小 C 增大 C

核选择经验：先试线性核，再试 RBF（通常效果好），然后才是其他核。
