CSYS5030 Week 06 Information-theoretic Estimators 讲课总结

Posted on 2026-09-17 Edited on 2026-09-29 In Course Notes , CSYS5030 Word count in article: 4.1k Reading time ≈ 15 mins.
CSYS5030 Module 6 讲课总结。正式定义估计量的 bias 与 variance；从离散化取极限推导 differential entropy，解释它为何会发散、为何可以为负、为何只在「比较」时有意义，以及为什么互信息在连续变量上依然保持非负与缩放不变； 三种连续值 MI 估计器（linear-Gaussian、box kernel、Kraskov/KSG）的原理、优缺点与 JIDT 实操， Gaussian 下 MI = -½ln(1-ρ²) 的推导，kernel width 与 k 的参数扫描结果，以及用 Gaussian + KSG 两个估计器组合解读关系类型的四象限框架和心跳-呼吸数据分析。

CSYS5030 W06：信息论估计器（知识点 + 题型）

这一周考什么：bias 和 variance；熵常被低估、MI 常被高估；binning 的问题；微分熵（为什么只在比较时有意义、可以为负）；三种连续 MI 估计器（Gaussian、box kernel、KSG）的原理、优缺点和参数怎么选（重点）；KSG 可以输出负值；同时跑 Gaussian 和 KSG 怎么解读。

期末题型：选择题常考「哪个估计器只能抓线性关系」「kernel width 变小 MI 估计怎么变」「KSG 给出负值说明什么」「相关系数 0.4 和 −0.4 的 MI 谁大」。Gaussian 估计器的公式不用背，知道 MI 和相关系数一一对应、它是 MI 的下界即可。简答第 3 题可能给 JIDT 参数扫描代码让你解读。

读法：从上往下读。每节先讲它要解决什么问题，再给结论和算例。

一、Bias 和 variance

1.1 定义

意思
Bias 固定样本数 ，估计值的期望和真值的差。取决于估计器类型和样本数，样本越多越小
Variance 很多组同样大小的样本分别估计，估计值之间的波动

好的估计器两者都小。

1.2 偏差的典型方向

量 有限样本下通常
熵 低估
MI 高估（现实中多数关系很弱，弱关系容易被高估）

不是绝对的：「硬币和它的拷贝」算 MI，结果是低估。

二、连续数据：先试 binning

做法：把取值范围切成几个区间，每个区间当一个符号，用离散估计器。可以等宽切（JIDT 默认），也可以让每个区间样本数相等（max-entropy binning）。

问题：

  1. 对箱数和切法敏感，3 个、4 个还是 5 个箱，答案都不一样，没有标准答案。
  2. 丢细节：两个挨得很近的点落在分界线两边，被当成完全不同；同一个箱里离得远的点被当成相同。

能用，但不是好办法。

3.4 MI 一切照旧

，发散项在和差里全部抵消。所以连续变量的 MI：

  • 非负；
  • 对缩放不变（缩放是一一映射，不改变共享信息）；
  • 等于离散化后 的极限；
  • 条件熵、CMI 的公式和离散版完全一样。

MI 比熵有用得多，熵只是通往 MI 的手段。

四、三种连续 MI 估计器（重点）

4.1 总览

估计器 思路 优点 缺点 JIDT 单位
Linear-Gaussian 假设多元高斯 快，数据需求少，模型对时最准 只抓线性关系，模型错就估错 nats
Box kernel 固定半径 内数邻居 model-free，能抓非线性 对 极敏感， 小时偏差大，慢 bits（例外）
KSG 第 近邻定盒子大小 + digamma 偏差修正 非线性 + 偏差修正 + 对 稳定，首选 比 Gaussian 慢，可输出负值 nats

单位：离散用 bits，连续用 nats，JIDT 的 kernel 估计器例外。1 nat = 1.443 bits。

4.2 Linear-Gaussian

  • 高斯分布由协方差矩阵完全决定，熵有闭式解 。
  • 两个变量时推出：

  • MI 和相关系数一一对应，只看 ： 和 的 MI 一样。信息论只说关系多强，不说方向（semantic free）。
  • 时 MI 。真实数据里 MI 爆到无穷，通常是哪里出错了（比如某一列被复制）。
  • 它在问「如果这是线性高斯关系，MI 是多少」，所以只抓线性分量，是真实 MI 的下界（证明不考）；对 CMI 不一定是下界。
  • 比相关系数强的地方：能推广到多变量，有链式法则。

4.3 Box kernel

对每个样本点，数半径 内有多少点来估计概率：

几何上： 数竖条里的点， 数横条里的点， 数方盒里的点。它问的是：知道 在 以内，能多大程度预测 在 以内。

JIDT 参数：KERNEL_WIDTH（默认 0.25），NORMALISE（默认开，先把每个变量标准化成均值 0、标准差 1）。

4.5 KSG

解决什么：kernel 用同一个 ，太小欠采样，太大丢细节。KSG 按每个点周围的数据密度动态定盒子。

  1. 每个点在联合空间 找第 个最近邻（max-norm），这个距离定盒子大小。
  2. 联合空间里永远正好 个邻居；在这个宽度下数边缘空间里有几个邻居 、。
  3. 代进 digamma 函数 ，自带偏差修正：

  • 数据稀疏处盒子自动变大，避免欠采样；密集处盒子变小，抓细节。
  • 默认 ，一般不改。
  • Alg. 1 方差小、偏差大，便于比较；Alg. 2 偏差小、方差大，更接近真值，本课默认用 Alg. 2。
  • JIDT 会给数据加一点随机噪声保持数值稳定，所以每次算结果略不同。

4.6 带你看一遍：k 扫描

同一数据，time difference = 1：

MI（nats，约） 0.42 0.40 0.38 0.34 0.31
  • 比 kernel 稳定得多：kernel 在 0.1–1.0 之间差近 5 倍，KSG 在 4–15 之间只差约 25%。
  • 越大，盒子越大，分辨率越粗，慢慢低估，和 kernel width 变大一样。

已知数据是线性高斯时，Gaussian 估计器最好：模型对时最准、最快、最省数据。

4.7 KSG 可以输出负值

同一数据 time difference = 0，KSG 给出 −0.05 nats。

  • 偏差修正的目标是让「没有关系时期望为 0」，单次估计仍在 0 附近波动。
  • 负值理解为「与 0 一致」，不是 misinformation。怎么判断「与 0 一致」见 W07 显著性检验。

4.8 常见考法

  • 「只能抓线性关系的是」→ Gaussian。
  • 「kernel width 变小 / KSG 的 变大，估计怎么变」→ 变大（高估）/ 慢慢变小。
  • 「 和 」→ MI 相同。
  • 「KSG 给出 −0.03 nats」→ 与 0 一致，不是错误。
  • 「已知线性高斯数据，选哪个估计器」→ Gaussian。

五、同时跑 Gaussian 和 KSG 怎么解读

KSG ≈ 0 KSG > 0
Gaussian ≈ 0 ① 没有关系，或太弱、现有样本测不出来 ② 只有非线性关系
Gaussian > 0 ④ 有线性关系，KSG 数据不够还没追上 ③ 有线性关系；KSG 更大的部分来自非线性
  • ①：测到 0 不等于没有关系，只是证据不够。关系越弱需要越多样本。
  • ④ 不矛盾：model-based 估计器很快锁定符合模型的关系；model-free 的 KSG 要考虑所有关系，又做了偏差修正，比较保守，需要更多数据。

5.1 带你看一遍：心率和呼吸

睡眠呼吸暂停病人的数据，心率 → 呼吸：

  • Gaussian：各个 lag 都只有千分之几 nats（峰值约 0.0033 nats），几乎为 0。只能说没有线性关系，不能说没有关系。
  • KSG：lag 0–15 大约 0.08–0.145 nats，高两个数量级，最大值在 lag 7 附近。
  • 落在 ② 区：心率和呼吸之间有非线性关系。
  • 用 local MI 给散点上色，高 local MI 集中在心率较高（约 85–92）的区域。

六、JIDT 连续估计器的代码要点

  1. 属性用字符串设置：calc.setProperty("KERNEL_WIDTH", str(width))。
  2. 属性要在 initialise() 时才生效，改完必须重新 initialise()。
  3. 循环复用：构造一次 → 循环里 setProperty → initialise → setObservations → compute。
  4. 一组数据用 setObservations()；多组用 startAddObservations() → 多次 addObservations() → finaliseAddObservations()。
  5. 默认参数不会出现在生成的代码里，先在 GUI 里改成非默认值再生成，才能看到那一行。
  6. local MI：calc.computeLocalOfPreviousObservations()。

时间序列有自相关时，KSG 还要设 dynamic correlation exclusion（Theiler window），见 W07。

考点小结

  1. ★★★ 三种估计器的优缺点和选择：Gaussian 只抓线性、是 MI 下界、模型对时最好；kernel 对 极敏感；KSG 动态宽度 + 偏差修正、对 稳定、首选。
  2. ★★★ 参数趋势：kernel width 小 → 高估，大 → 低估；KSG 大 → 缓慢低估，默认 。
  3. ★★★ KSG 可以输出负值 = 与 0 一致。
  4. ★★ MI 和相关系数一一对应，只看 ； 时 MI → ∞。
  5. ★★ Bias / variance；熵常低估，MI 常高估，不绝对。
  6. ★★ Gaussian + KSG 四象限：Gaussian ≈ 0 而 KSG > 0 → 非线性关系；Gaussian > 0 而 KSG ≈ 0 不矛盾。
  7. ★★ 微分熵：只在比较时有意义，可以为负，平移不变，缩放加 ；MI 非负、缩放不变。
  8. ★ binning 对箱数敏感、丢细节；plug-in 偏差可修正。
  9. ★ JIDT：属性用字符串，setProperty 后要 initialise；kernel 输出 bits，其余连续估计器输出 nats。

Q23（简答·概念，讲义） 解释 box kernel 估计器的 MI 为什么会随 kernel width 增大而单调下降，以及为什么很难选出「正确」的宽度。

宽度小时每个盒子里点很少，欠采样，偏差大，MI 被高估；宽度变大，欠采样缓解，但分辨率变粗，看不到分布的细节，又开始低估。曲线单调下降没有平台，只有中间某个宽度碰巧接近真值，而真值事先不知道，所以没有一个显然该用的宽度。KSG 用动态宽度解决这个问题。
