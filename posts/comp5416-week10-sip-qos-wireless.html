COMP5416 W10：SIP、QoS 与无线基础（知识点 + 题型）

这一周考什么：三块。SIP（呼叫建立、注册服务器和代理、带外信令）；网络对多媒体的支持（QoS 四原则、优先级 / 轮询 / WFQ 调度、令牌桶监管、DiffServ、呼叫准入）；无线基础（组成和分类、dB、SNR 和 BER 的权衡、隐藏终端、CDMA 编解码和正交性）。Sample exam Q4 就是 CDMA：两个码不正交，解不出来，答 n/a。

期末题型：全是选择题，有单选也有多选，多选题勾错一个会抵消勾对的一个。计算题有 WFQ 吞吐、令牌桶上界、dB 换算、CDMA 内积；tutorial 的四节点中继题考「每个时隙最多送几条消息」。

读法：从上往下读。每节先讲它要解决什么问题，再给结论和算例。

一、SIP：会话初始化协议

1.1 想做什么

  • 所有电话、视频会议都走互联网。
  • 用名字或 e-mail 地址找人，不用电话号码。
  • 不管对方漫游到哪、用什么设备，都能找到他（如果他愿意）。

1.2 提供的服务

类别 内容
呼叫建立 主叫告诉被叫想通话；双方协商媒体类型和编码；结束通话
找到被叫当前的 IP 把名字映射到当前 IP 地址
呼叫管理 通话中加媒体流、换编码、邀请别人、转接、保持

1.3 向已知 IP 呼叫（讲义例子）

Alice（167.180.112.24）呼叫 Bob（193.64.210.89）：

步 消息 内容
1 Alice → Bob：INVITE Alice 的 IP、端口 38060、想用的编码 PCM μ-law（RTP payload type 0）
2 Bob → Alice：200 OK Bob 的 IP、端口 48753、想用的编码 GSM（type 3）
3 Alice → Bob：ACK 呼叫建立
4 双向 RTP Alice 用 μ-law 发到 48753；Bob 用 GSM 发到 38060

要点：

  • SIP 默认端口 5060；SIP 消息可以走 TCP 或 UDP。
  • SIP 是带外（out-of-band）的：信令（5060）和媒体（RTP 的 38060 / 48753）走不同的端口。
  • 两个方向可以用不同编码。
  • INVITE 里描述媒体的那几行是 SDP；后面的数字就是 W08 讲的 RTP payload type。

1.4 编码不支持、拒绝通话

  • Bob 没有 μ-law 编码器：回 606 Not Acceptable，列出自己支持的编码，Alice 换编码再发 INVITE。
  • Bob 不想接：可以回 busy、gone、payment required、forbidden。

1.5 怎么找到被叫：注册服务器和代理

问题：主叫只知道被叫的名字，但被叫会移动、IP 由 DHCP 动态分配、一个人有多台设备。结果还可以按时间（上班 / 在家）、主叫是谁、被叫状态（忙就转语音信箱）而不同。

注册服务器（registrar）：Bob 启动 SIP 客户端时发 REGISTER，告诉注册服务器「bob@domain.com 现在在 193.64.210.89」，带有效期（如 Expires: 3600 秒）。

代理服务器（proxy）：

  • Alice 把 INVITE 发给她自己的代理，里面写 sip:bob@domain.com。
  • 代理负责把 SIP 消息路由到被叫，可能经过多个代理。
  • Bob 的响应沿同一组代理返回，里面带着 Bob 的 IP。
  • 讲义类比：SIP 代理 ≈ 本地 DNS 服务器。

1.6 完整例子：alice@umass.edu 呼叫 bob@poly.edu

步 动作
1 Alice 发 INVITE 给 UMass 的 SIP 代理
2 代理转给 Poly 的注册服务器
3 Poly 回重定向：去试 bob@eurecom.fr
4 UMass 代理转给 Eurecom 的注册服务器
5 Eurecom 把 INVITE 转给 197.87.54.21（Bob 的客户端正在这台机器上）
6–8 SIP 响应沿原路返回 Alice
9 媒体直接在两个客户端之间走，不经过代理

二、网络怎么支持多媒体：三种方式

方式 粒度 保证 机制 复杂度 部署
尽力而为做到最好 所有流量一样 无 网络不管，全靠应用（缓冲、FEC、CDN） 低 到处都是
区分服务 流量类 无或软保证 标记、调度、监管 中 部分
每连接 QoS 每条连接（流） 软或硬保证（流被准入后） 标记、调度、监管 + 呼叫准入 高 很少

多类服务：把流量分成几类，网络按类区别对待（像机场 VIP 通道）。粒度是「类」，不是单个连接。用 IP 首部的 ToS 位标记。

三、QoS 四条原则（常考）

场景：H1、H2 经 R1 → 1.5 Mbps 链路 → R2 到 H3、H4。

# 遇到的问题 原则
1 1 Mbps 的 VoIP 和 HTTP 共享链路，HTTP 一突发就让语音丢包 → 想让语音优先 分组标记，让路由器能区分不同类；路由器要有新的策略区别对待
2 应用不守规矩（VoIP 发得比声明的多） 类之间要隔离保护：用监管（policing）强制源遵守分配的带宽
3 给每个流分固定、不共享的带宽（VoIP 1 Mbps、HTTP 0.5 Mbps），流不用满时就浪费了 提供隔离的同时，尽量高效使用资源
4 两个 1 Mbps 电话都要走 1.5 Mbps 的链路 呼叫准入：流先声明需求，网络满足不了就拒绝（忙音）

记法：标记（区分）→ 监管（隔离）→ 高效（别浪费）→ 准入（别超载）。

四、调度：下一个发哪个分组

4.1 FIFO

按到达顺序发。队列满了来新分组时丢谁：

策略 做法
tail drop 丢新来的
priority 按优先级丢
random 随机丢

4.2 优先级调度

  • 发队列里优先级最高的分组。
  • 分类可以按标记，也可以按 IP 地址、端口等首部信息。
  • 非抢占：正在发的低优先级分组不会被打断。

讲义例子：分组 1、2、3、4、5 依次到达，1、3、4 高优先级，2、5 低优先级。服务顺序 1、3、2、4、5。

为什么 2 在 4 前面：3 发完时 4 还没到，队列里只有 2，就发 2；4 到的时候 2 正在发，不打断。

4.3 轮询（Round Robin）

多个类、优先级相同。轮流扫描每一类的队列，每类发一个完整分组（有的话）。讲义例子的顺序也是 1、3、2、4、5。

4.4 加权公平排队（WFQ）

广义的轮询：每类每轮得到「加权」份额的服务。 类 i 权重 。类 i 有分组要发时，保证得到的服务比例和吞吐：

求和只算当前有分组的类。

带你算一遍（讲义）：1 Mbps 链路，三条流要保证 0.5、0.25、0.25 Mbps → 权重 2、1、1。

情况 流 1 流 2 流 3
三条都有数据 2/4 = 0.5 1/4 = 0.25 0.25
流 3 没数据 2/3 ≈ 0.667 1/3 ≈ 0.333 0
  • 空闲类的份额按权重分给其他类，不浪费（原则 3）。每类至少拿到保证的份额（原则 2）。
  • 权重全相等时 WFQ 就是轮询。

五、监管和令牌桶

5.1 监管限制什么

目标：让流量不超过声明的参数。三个标准，时间尺度不同：

标准 意思 讲义例子
长期平均速率 长时间平均每单位时间发多少分组 每分钟 6000 个
峰值速率 较短时间内的上限 平均 6000 个/分钟，但每 5 秒最多 3000 个
最大突发 「一瞬间」最多连发多少个 1500 个

时间尺度很重要：每秒 100 个和每分钟 6000 个长期平均一样，但后者允许某一秒发 6000 个。

5.2 令牌桶

同时限制突发大小和平均速率。

  • 桶最多装 b 个令牌。
  • 令牌以 r 个/秒生成，桶满了新令牌就扔掉。
  • 分组要拿走一个令牌才能进网络。

任意长度 t 的时间内，进入网络的分组数：

时间尺度 结论
t → 0 最多 b 个（最大突发）
t → ∞ (rt + b)/t → r（长期平均速率）

带你算一遍：r = 100 个/秒，b = 50。任意 2 秒内最多 100 × 2 + 50 = 250 个分组。

六、DiffServ（区分服务）

要的是定性的服务类（白金、金、银），相对区分。

可扩展的关键：网络核心只做简单的事，复杂的放到边缘。

位置 做什么
边缘路由器 每流流量管理；给分组打标记（比如 Alice、Bob 标 high，Chris 标 low）
核心路由器 每类流量管理；按边缘打的标记做缓冲和调度

边缘标记：

  • 用户和网络事先约定 profile（速率 r、桶大小 b）。
  • 类间标记：不同类打不同标记。
  • 类内标记：流里符合 profile 的部分和不符合的部分打不同标记。

讲义例子 1：Bob 约定 1 Mbps，实际发 2 Mbps → 符合的一半标绿，超出的标红（低优先级）或丢弃。

讲义例子 2（三色）：优先级 绿 > 黄 > 红，链路 2 Mbps。Bob 打电话，约定 1 Mbps，用令牌桶，符合标绿、超出标红；Chris 上网标黄；核心用优先级队列。

情况 结果
Bob 发 ≤ 1 Mbps Bob 保证拿到 1 Mbps
Bob 发 > 1 Mbps，Chris 发满 1 Mbps 红色全被丢，Bob 正好 1 Mbps
Bob 发 > 1 Mbps，Chris 发不满 1 Mbps 一部分红色还能过去

分类和调节：流量被计量（metered），和约定的 profile 比较；不符合的分组由管理员决定重新标记、转发、延迟（整形）还是丢弃。

每连接 QoS 和呼叫准入：网络支持不了超过链路容量的需求。两个 1 Mbps 电话、1.5 Mbps 链路 → 第二个被拒绝。

七、无线网络的组成和分类

7.1 三个组成部分

部分 说明
无线主机 笔记本、手机、IoT；可能静止也可能移动。无线不等于移动
基站 一般连着有线网络；负责在有线网络和它覆盖范围内的无线主机之间中继分组。例：蜂窝基站、802.11 AP
无线链路 一般连接移动设备和基站，也可以做骨干；多路访问协议协调谁来用；速率、距离、频段各不相同

常见无线链路：802.11ax 约 14 Gbps（室内 10–30 m）；5G 约 10 Gbps；802.11ac 3.5 Gbps；802.11n 600 Mbps；4G LTE 中远距离（200 m–15 km）；802.11g / b 54 / 11 Mbps；蓝牙 2 Mbps（短距）。

7.2 两种模式

模式 说明
基础设施模式 基站把移动设备接入有线网络；切换（handoff）：移动设备换一个基站接入
自组织（ad hoc）模式 没有基站；节点只能发给覆盖范围内的其他节点；节点自己组网、互相路由

7.3 2 × 2 分类

单跳 多跳
有基础设施 主机连基站，基站连互联网（WiFi、蜂窝） 要经过几个无线节点中继才能上网（mesh 网）
无基础设施 没有基站，不连互联网（蓝牙、ad hoc） 没有基站，可能要中继才能到某个节点（MANET、VANET）

八、无线链路的特点

8.1 和有线链路的区别

特点 说明
信号衰减 无线电穿过物体会变弱（路径损耗）
其他源的干扰 标准频段（如 2.4 GHz）和别的设备共用（无绳电话、微波炉）
多径传播 信号被物体、地面反射，在稍有不同的时间到达

所以无线通信（哪怕点到点）比有线难得多。

8.2 分贝（dB）

对数单位，表示两个功率的比：。

10 100 1000 10000 2
dB 10 20 30 40 ≈ 3

每多一个 0 加 10 dB；3 dB ≈ 2 倍。

8.3 SNR 和 BER 的权衡

  • SNR（信噪比）：越大越容易从噪声里提取信号。
  • BER（误码率）：收到的比特出错的概率。

讲义图有三条 BER–SNR 曲线：BPSK（1 Mbps）、QAM16（4 Mbps）、QAM256（8 Mbps）。

角度 规律
同一种调制 加大功率 → SNR 升高 → BER 降低
不同调制 速率越高 → 同一 SNR 下 BER 越高
给定 SNR 和 BER 要求 选满足 BER 要求的、速率最高的调制

讲义例题：SNR = 15 dB，要求 BER ≤ 10⁻³ → QAM16。QAM256 在 15 dB 时 BER 太高；BPSK 满足但只有 1 Mbps；QAM16 满足且 4 Mbps 最快。这就是 W11 的 802.11 速率自适应。

8.4 隐藏终端

  • A 和 B 能互相听到，B 和 C 能互相听到，A 和 C 听不到对方。
  • 成因：障碍物，或信号衰减（各自的信号到 B 还够强，到对方那里就太弱了）。
  • 后果：A 侦听信道觉得空闲（听不到 C），就发；C 也一样 → 在 B 处碰撞，A、C 都不知道。W11 用 RTS / CTS 解决。

九、Tutorial：四节点无线中继（官方答案）

A — B — C — D 排成一行，同一频率。

谁发 谁听得到
A 只有 B
B A 和 C
C B 和 D
D 只有 C

规则：时间分时隙，一条消息占一个时隙；节点每个时隙可以发、收（恰好一条发给它的消息）或不动；节点同时听到 ≥ 2 个发送者就碰撞，都收不到；节点不能同时发和收；非邻居要中继（A→D 走 A→B→C→D）。

做这类题的关键：看接收者同时听到几个发送者。

问题 无线 有线（点到点） 为什么
Q1：C → A 的最大速率（无其他流量） 1 条 / 2 时隙 1 条 / 时隙 无线：C→B、B→A 各一个时隙；B 在发给 A 时不能同时收 C 的下一条。有线可以流水线
Q2：A → B 和 D → C 同时 2 条 / 时隙 2 条 / 时隙 B 只听到 A，C 只听到 D，不冲突
Q3：A → B 和 C → D 同时 1 条 / 时隙 2 条 / 时隙 无线：C 发时 B 也听得到，A、C 同时发会在 B 处碰撞（隐藏终端）。有线没有广播干扰

Q5：无线，每条数据都要回 ACK（占一个时隙）

问题 官方答案 调度
C → A 1 条 / 4 时隙 C→B、B→A、A→B（ACK）、B→C（ACK），四步只能串行
A → B + D → C 2 条 / 3 时隙 时隙 1：两条数据同时；时隙 2：B→A 的 ACK；时隙 3：C→D 的 ACK
A → B + C → D 2 条 / 3 时隙 时隙 1：C→D；时隙 2：D→C 的 ACK 和 A→B 同时；时隙 3：B→A 的 ACK

第 2 行官方答案偏保守：B→A 和 C→D 两个 ACK 同时发其实不会碰撞（A 只听得到 B，D 只听得到 C），可以做到 2 条 / 2 时隙。选择题按官方答案 2 条 / 3 时隙选。

10.3 带你算一遍：两个发送方叠加

发送方 1 用 c₁ 发 1，发送方 2 用 c₂ 发 −1：

  • 用 c₁ 解：2 + 2 + 0 + 0 + 2 + 0 + 2 + 0 = 8，8 / 8 = 1 ✓
  • 用 c₂ 解：−2 − 2 + 0 + 0 − 2 + 0 − 2 + 0 = −8，−8 / 8 = −1 ✓

10.4 Sample exam Q4：码不正交就解不出来

发送方 1 的码 (1, −1, 1, −1, −1, −1, −1)，发送方 2 的码 (1, −1, −1, −1, −1, −1, −1)，合成信号 (2, −2, 0, −2, −2, −2, −2)。

  1. 先查正交：内积 = 1 + 1 − 1 + 1 + 1 + 1 + 1 = 5 ≠ 0，不正交。
  2. 硬解：接收方 1 得 (2 + 2 + 0 + 2 + 2 + 2 + 2) / 7 = 12/7 ≈ 1.71，不是 ±1；接收方 2 也是 12/7。多出来的 5/7 就是对方信号漏进来的干扰。
  3. 官方答案：两个接收方都是 n/a。

做 CDMA 题的第一步永远是先检查码是否正交。

10.5 Tutorial：M = 7 的编解码

码 c = (1, −1, 1, 1, −1, −1, −1)。

  • d = 1 的编码输出：(1, −1, 1, 1, −1, −1, −1)（就是 c 本身）。
  • 收到 (1, −1, 1, 1, −1, −1, −1)，解码：(1 + 1 + 1 + 1 + 1 + 1 + 1) / 7 = 1。
  • d = −1 时输出 −c = (−1, 1, −1, −1, 1, 1, 1)，解码得 −1。

考点小结

  1. ★★★ CDMA：编码 d × c，信道相加，解码内积 ÷ M；先查正交，不正交答 n/a（sample exam）。
  2. ★★★ WFQ：，只对有数据的类求和；权重相等就是轮询。
  3. ★★ 优先级调度非抢占；讲义例子顺序 1、3、2、4、5。
  4. ★★ 令牌桶：任意 t 内 ≤ rt + b；短期限突发 b，长期限速率 r。
  5. ★★ QoS 四原则：标记、隔离（监管）、高效、准入。
  6. ★★ DiffServ：边缘每流标记，核心每类转发；符合标绿、超出标红。
  7. ★★ SIP：端口 5060，TCP / UDP，带外；注册服务器（REGISTER）、代理（≈ 本地 DNS）；媒体不经过代理；606 Not Acceptable。
  8. ★★ SNR / BER：同调制加功率 BER 降；高速率调制 BER 高；选满足 BER 的最快调制。
  9. ★★ 隐藏终端：A、C 听不到对方，在 B 处碰撞；中继题看接收者听到几个发送者。
  10. ★ dB = 10 log₁₀(比值)；无线 ≠ 移动；2 × 2 分类。

Q1（Sample Exam） 发送方 1 的 CDMA 码 (1, −1, 1, −1, −1, −1, −1)，发送方 2 的码 (1, −1, −1, −1, −1, −1, −1)，合成输出 (2, −2, 0, −2, −2, −2, −2)。接收方 1 解出的比特是？
A. −1　B. 1　C. n/a

C。两码内积为 5，不正交，干扰无法消除。

Q2（讲义） 码 c₁ = (−1, −1, −1, 1, −1, 1, 1, 1)，c₂ = (1, 1, −1, 1, 1, 1, −1, 1)。发送方 1 发 1、发送方 2 发 −1，信号相加。接收方用 c₂ 解码得到？
A. 1　B. −1　C. 0　D. n/a

B。两码正交，c₁ − c₂ 与 c₂ 的内积为 −8，÷ 8。

Q3（讲义） 关于 CDMA，正确的是？（多选）
A. 所有用户同时使用同一频率
B. 不同用户的码内积为 0 时，干扰可以消除
C. 解码时用收到的信号和自己的码做内积，再除以码长
D. 每个用户分到不同的时隙

A、B、C。D 是 TDMA。

Q4（Tutorial） CDMA 码 (1, −1, 1, 1, −1, −1, −1)，收到 (1, −1, 1, 1, −1, −1, −1)，解出的比特是？

Q5（讲义） 1 Mbps 链路上用 WFQ，三条流权重 2、1、1。流 3 没有数据时，流 1 的吞吐量是？

Q6（讲义） 关于调度，正确的是？（多选）

A、B、D。轮询各类优先级相同。

Q7（讲义） 分组 1、2、3、4、5 依次到达，1、3、4 是高优先级，2、5 是低优先级，非抢占优先级调度。服务顺序是？

Q8（自拟） 令牌桶 r = 100 个/秒，b = 50。任意 2 秒内最多能进入网络多少个分组？
