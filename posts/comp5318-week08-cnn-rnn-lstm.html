第一部分：卷积神经网络（CNN）

一、背景

  • 由 Yann LeCun 等人于 1989 年提出；
  • 2012 年 AlexNet（Krizhevsky 等）赢得 ImageNet 比赛，把错误率从 26% 降到 15%，CNN 由此走红；
  • 本质是一种特殊的多层神经网络，同样用反向传播训练；
  • 设计目标：直接从像素图像识别视觉模式，几乎不需要预处理；能识别高变异性的模式（如手写字符），对失真和几何变换（如平移）鲁棒；
  • 应用：图像和语音识别、手写数字分类、人脸检测、图像分类。

图像的表示

  • 黑白（灰度）图：1 个矩阵，像素值 0（黑）到 255（白）；
  • 彩色图：3 个通道（R、G、B），即 3 个矩阵。

二、为什么普通 MLP 不适合图像

问题 说明
忽略空间结构 MLP 把图像拉平成向量，相邻像素之间的关系丢失
对物体位置敏感 物体只平移 2 个像素，输入向量就大不相同，已学到的权重几乎没用；而平移是图像和声音数据最主要的失真来源之一
参数爆炸（Lab 补充） 每个像素都要与下一层每个神经元相连，图像一大参数量就暴涨

CNN 用两种新的层——卷积层和池化层——解决这些问题。

三、CNN 的整体结构

层 作用
INPUT 图像像素值
CONV 卷积层：提取特征
RELU 非线性激活（ReLU / Leaky ReLU 等）
POOL 池化层：汇总、降维
FC 全连接层，输出层用 softmax 给出各类概率

例：3 个 CONV-RELU-POOL 块 + 2 个 FC 层 → Cat (0.72)、Lion (0.28)。

CNN 和上周的全连接网络本质相同：由带可学习权重的神经元组成，每个神经元做点积再过非线性激活；整个网络是从像素到类别分数的一个可微函数，用反向传播训练。上周学的都适用。

四、卷积层

卷积运算

卷积就像在矩阵上滑动一个窗口：窗口（滤波器 filter / 卷积核 kernel）与图像对应位置的元素逐个相乘再求和，得到一个数；窗口从左到右、再往下移动，所有结果组成特征图（feature map / activation map）。

讲义例：5×5 的 0/1 图像，3×3 滤波器

左上角的图像块为 ，第一个卷积特征：

5×5 图像、3×3 滤波器、步长 1 → 3×3 特征图。

感受野（receptive field）：当前正与滤波器做卷积的那块图像区域。

滤波器 = 特征检测器

  • 高层视角：每个滤波器是一个特征检测器。例如一个「曲线检测器」：放到图像中有相似曲线的位置，乘积和很大（检测到了）；放到没有曲线的位置，结果接近 0（没检测到）。
  • 因此特征图显示图像中哪些区域有该特征：值高 = 有，值低 = 无。
  • 用多个滤波器检测不同特征 → 多张特征图（滤波器 1 → 特征图 1，滤波器 2 → 特征图 2……）。
  • 关键：CNN 中的滤波器不是人为设计的，它们的值（权重）由反向传播在训练中学出来。

权重共享（weight sharing）：同一个滤波器在整张图上滑动，所有位置共用同一组权重。PE1 Q20：一个检测器在整张图像上复用，不需要每个空间位置各学一个独立的滤波器——这是 CNN 参数少、且对平移鲁棒的根本原因。

步长（Stride）

  • 上例中滤波器每次横向移 1 个像素，到行尾回到最左并下移 1 像素：水平步长 、垂直步长 ；
  • 也可以用更大步长；步长越大，特征图越小。
  • 例：7×7 图像、3×3 滤波器：步长 1 → 5×5；步长 2 → 3×3。

填充（Padding）

  • 动机：在行/列末尾，滤波器可能「伸出」图像边界；
  • 做法：在边界外补 0；
  • 填充大小是超参数；填充让图像边缘区域得到更好的覆盖和特征提取。

ReLU

对特征图施加激活函数，通常是 ReLU： - 比 sigmoid / tanh 更简单 → 计算更快； - 简化梯度下降的计算； - 无上界、输出不饱和 → 梯度消失更少（Week 7）。

五、池化层

  • 动机：特征的精确位置不重要，只需知道它大致在哪、和其他特征的相对关系；
  • 池化层（也叫下采样层 sub-sampling）「汇总」上一层的输入；
  • 作用：减少参数（2×2 池化减少 75%）、帮助防止过拟合、提高对感受野内平移的鲁棒性。
类型 做法 适用
最大池化（max pool） 取区域内最大值 选最亮的像素 → 适合暗背景、关注亮像素的图像，如 MNIST（黑底白字）
平均池化（ave pool） 取区域内平均值 平滑图像

哪种更好？取决于任务。

PE2 Q20：最大池化在每个空间窗口内取最大值，标准池化操作本身没有可训练的权重。

六、全连接层

  • CNN 末尾接 1 个或多个全连接（FC）层；
  • 第一个 FC 层接收最后一个卷积或池化层的输出（卷积层后不一定都跟池化），先展平（flatten）成向量；
  • 最后一个 FC 层输出 维向量（ = 类别数），通常用 softmax 给出各类概率，和为 1；
    • 例：数字分类输出 [0, 0, 0, 0.1, 0, 0, 0.7, 0, 0, 0.2] → 「3」10%、「6」70%、「9」20%；
  • 本质：FC 层把卷积层提取的特征组合起来，输出各类概率。

七、多通道输入

  • 彩色图有 3 个通道：输入为 32×32×3；
  • 滤波器也要变成 3 维，第三维（深度）必须与输入通道数相同（3 通道 → 3×3×3 滤波器）；
  • 一个 3 维滤波器在各通道上分别卷积，结果相加（再加偏置）得到一张 2 维特征图。

参数量计算（补充，考试常考）

（ 是每个滤波器一个偏置。）与输入图像的宽高无关——这正是权重共享的体现。

八、CNN 架构设计问题

  • 怎么组合各组件？几个卷积层？每层几个滤波器？
  • 滤波器多大（3×3 还是 5×5）？
  • 池化多频繁？每个卷积层后都池化，还是更少？
  • 池化窗口多大（2×2、3×3）？用最大还是平均？

经典架构

架构 年份 要点
LeNet-5 1998 LeCun 等；手写数字识别；2 个卷积、2 个最大池化、3 个全连接
AlexNet 2012 Krizhevsky, Sutskever, Hinton；ImageNet 120 万张、1000 类；输入 227×227；5 个卷积、3 个最大池化、3 个全连接
VGG 2014 Simonyan & Zisserman；AlexNet 的改进：更深、设计更简单——卷积全用 3×3、步长 1、填充 1；最大池化 2×2、步长 2
GoogLeNet 2014 Szegedy 等；ILSVRC'14 分类冠军，错误率 6.7%；22 层但仅 500 万参数（比 AlexNet 少 12 倍、比 VGG-16 少 27 倍）；高效的 Inception 模块；没有 FC 层

（Lab 还提到 ResNet，可作为深层 CNN 的起点。）

九、CNN 小结

  • 为图像设计，但也可用于其他数据；
  • 三个核心：卷积、池化、全连接；
  • 卷积层提取特征；池化层汇总信息、减少参数防过拟合、提高平移鲁棒性；全连接层组合特征、输出各类概率；
  • 在图像处理和计算机视觉中非常成功。

第二部分：循环神经网络（RNN）

十、序列数据与 RNN

RNN 用于序列数据。文本就是典型：

  • 句子是词的序列，一个接一个；
  • 每个句子长度不同；
  • 可能含长距离依赖：
    • The dog in that house is aggressive
    • The dogs in that house are aggressive
    谓语形式取决于前面隔了好几个词的主语。

⇒ 需要一个能记住序列早期相关信息（有记忆）的模型。

一次一个元素

  • RNN 每个时间点从序列取一个元素（如一个词）：: the， : dog， : in……
  • 叫「循环」是因为有反馈连接：某神经元在一个时间点的输出反馈给下一时间点的同一神经元；
  • 前馈网络是有向无环图；RNN 是有向有环图；
  • 结果：RNN 对过去的激活（以及产生这些激活的过去输入）有记忆 ⇒ 能捕捉长距离依赖。

本课讲两种：简单 RNN（Elman 网络）和 LSTM。

十一、简单 RNN（Elman 网络）

结构

  • 一个隐藏层的前馈网络 + 记忆缓冲区（memory buffer），存储上一时间步的隐藏层状态；
  • 每个时间步，记忆中的信息与新的输入拼接后送入每个隐藏神经元。
符号 含义
时刻输入向量
时刻隐藏层激活（状态）
时刻输出（如给定 时刻的词，预测 时刻的词）

三个权重矩阵

矩阵 连接
输入层 → 隐藏层
隐藏层 → 输出层
记忆缓冲区 → 隐藏层（循环连接，隐藏层回到隐藏层）

前向计算

（偏置略；通常用 tanh，输出在 −1 到 1 之间。）

具体例子（2 输入、3 隐藏、2 输出）：每个隐藏神经元 ① 同时接收输入向量和记忆中的上一状态；② 处理后产生激活，既送到输出层，也写回记忆缓冲区；下一时间步记忆再与新输入一起送回隐藏层。

PE1 Q21：隐藏状态由当前输入和上一时刻隐藏状态共同更新；循环权重在各时间步共享。

展开（Unrolling）

  • 环形连接难以理解多步信息流 → 沿时间步展开，图中不再有环；
  • 3 个时间步展开： ， 是记忆缓冲区的初始状态；
  • 关键：展开后各时间步是同一个网络——权重不变。RNN 只有 3 个权重矩阵，而不是 3×3 = 9 个。

训练：随时间反向传播（BPTT）

  • RNN = 前馈网络 + 记忆，多了矩阵 ；
  • 用反向传播的变体 Backpropagation Through Time（BPTT）训练；
  • 时刻的误差反向传播到所有对它有贡献的参数，即沿网络的过去状态往回传——「回到过去」，故名；
  • 每处理一个元素就计算一次网络各「位置」的权重更新；epoch 结束时，同一位置的更新求和，用总和更新整个网络。

十二、例子：预测下一个字符

  • 任务：给定前面的字符，预测下一个（可用于逐字符生成文本）；
  • 词表只有 4 个字母 {h, e, l, o}，在 "hello" 上训练 ⇒ 4 个训练样本：
    • h → e，he → l，hel → l，hell → o
  • one-hot 编码：h = 1000，e = 0100…；输入 4 维、输出 4 维（每个字母一个值，激活最大者即预测）；3 个隐藏神经元；每次喂一个字符。

训练初期（讲义中的一次前向结果）：

时间步 已输入 目标 最高分 结果
1 h e 4.1 → "o" ✗
2 he l 1.2 → "o" ✗
3 hel l 1.9 → "l" ✓
4 hell o 2.2 → "o" ✓

注意第 3、4 步当前输入的字符都是 "l"，目标却不同（第 3 步要预测 l，第 4 步要预测 o）——同一个字符后面接什么，取决于记忆中的上下文（已经见过一个还是两个 l），这正是需要隐藏状态的原因；普通前馈网络对相同输入只能给出相同输出。

反复反向传播直到收敛（如所有字符都分对）。生成文本：喂一个字符 → 预测下一个 → 把预测的字符再喂进去 → ……

十三、RNN 的灵活形式

形式 例子
一对一（无序列） 图像分类
一对多（序列输出） 图像描述（image captioning）：图像 → 词序列
多对一（序列输入） 情感分析：文本 → 正/负
多对多（异步） 机器翻译：英文句子 → 意大利文句子
多对多（同步） 视频分类：给每一帧打标签

RNN 不必每个元素都输出：情感分析中读完整句后才输出一个值（Lab 就做这个）。

十四、简单 RNN 的缺陷：梯度消失与长程依赖

  • 反向传播时误差梯度每个时间步都乘一次 ；
  • 权重偏小时，反复相乘导致梯度消失；
  • ⇒ 理论上 RNN 能学长程依赖，实践中很有限。
依赖 例子
短距离 The clouds are in the sky——相关信息就在附近
长距离 I grew up in Italy … I speak fluent Italian——需要很靠前的 Italy 作上下文

另一个比喻：翻译一个长句，读完时已忘了开头。

（Lab 补充：反复相乘也可能让梯度爆炸。）

十五、LSTM（Long Short-Term Memory）

  • Hochreiter & Schmidhuber，1997；专门为提高 RNN 建模长程依赖的能力而设计；
  • 核心思想：网络能学会存什么、丢什么、读什么；
  • 一个 LSTM 单元有 3 个门：遗忘门、输入门、输出门；
  • 两种状态：长期状态（cell state） 和短期状态（hidden state）。

结构

当前输入 与上一短期状态 被送入 4 个全连接层（简单 RNN 只有 1 个）： - 3 个是门控层，用 sigmoid ，输出 0~1；其输出与其他向量逐元素相乘：0 = 关门，1 = 开门； - 1 个是候选状态层，用 tanh（与简单 RNN 相同）。

四步（标准公式，对应讲义各页）

① 遗忘门——决定长期状态 中哪些丢弃、哪些保留：

接近 0 = 忘掉，接近 1 = 保留。例：cell state 里存着当前主语的性别（用于选 he/she），遇到新主语时要忘掉旧主语的性别。

② 输入门——决定存入哪些新信息：

sigmoid 层决定更新哪些值，tanh 层产生候选值。例：把新主语的性别加进去。

③ 更新长期状态：

旧状态乘遗忘门（忘掉该忘的），再加上按输入门缩放的候选值。

④ 输出门——决定输出什么（cell state 的过滤版本）：

例：刚看到主语，接下来可能是动词，于是输出主语是单数还是复数的信息，以便选择正确的动词形式。

为什么 LSTM 能缓解梯度消失

  • LSTM 能识别重要输入（输入门）、存入长期状态并按需保留（遗忘门）、需要时提取（输出门）；
  • 同样用 BPTT 训练，但长期状态 的更新是加法路径，误差回传时不再反复乘 ，梯度消失问题大大缓解（讲义说法是「没有梯度消失问题」）。

PE2 Q21：LSTM 门控调节存什么、留什么、露出什么，有助于长程依赖，但不保证完美记忆——答题时别说得太绝对。

其他 RNN 架构

GRU（Cho et al., 2014）、IRNN（Le et al., 2015）。

LSTM 在机器翻译、语音识别、手写识别、语音合成、视频分析等任务上取得过 state-of-the-art 结果。

二十、本周考点速记 / 易错点

CNN

  1. MLP 处理图像的问题：忽略空间结构、对平移敏感、参数爆炸。
  2. 结构 INPUT–[CONV–RELU–POOL]×n–FC(softmax)。
  3. 卷积手算：对应元素相乘求和（例：结果 4）。
  4. 滤波器 = 特征检测器，权重由反向传播学出；权重共享 → 参数少、平移鲁棒。
  5. 步长大 → 特征图小；填充补零，大小是超参数；输出边长 。
  6. 参数量 ，与图像宽高无关（PE1：76）。
  7. 池化：最大 / 平均；无可训练参数；减少参数、防过拟合、平移鲁棒；MNIST 适合最大池化。
  8. 多通道：滤波器深度 = 输入通道数。
  9. 经典架构：LeNet-5（2 conv + 2 pool + 3 FC）、AlexNet（2012，5 conv）、VGG（3×3 小卷积、更深）、GoogLeNet（Inception、无 FC、500 万参数）。

RNN / LSTM

  1. RNN 用于序列；有反馈连接（有环）→ 有记忆。
  2. 三个权重矩阵 ； 。
  3. 展开后各时间步共享权重（3 个矩阵，不是 9 个）。
  4. BPTT：误差沿过去状态往回传；同一位置的更新在 epoch 末求和。
  5. RNN 形式：一对多（图像描述）、多对一（情感分析）、多对多（翻译、视频逐帧）。
  6. 简单 RNN 的梯度消失：反复乘 → 长程依赖学不好。
  7. LSTM 三个门：遗忘（丢什么）、输入（存什么）、输出（读什么）；4 个全连接层（3 个 sigmoid 门 + 1 个 tanh）； 。
