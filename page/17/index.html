每日科技速递 - 2026-06-03

本日焦点：① 微软发布 MAI-Code-1-Flash（5B）与 MAI-Thinking-1（35B）两款全新小参数模型，专为 GitHub Copilot 打造；② Vitalik 提出基于期权的合成资产方案，旨在消除链上清算风险并减少对实时预言机的依赖；③ Holo3.1 发布量化版本，首次支持本地部署计算机操控 Agent；④ Coinbase 战略投资 Ethena，将面向 1 亿用户推出链上储蓄产品；⑤ NVIDIA 与微软联合推出从本地到云的统一 Agentic AI 部署技术栈。

🧠 LLM / 大模型

• 🔥7 | 微软发布全新 MAI 系列模型 —— Simon Willison 详细解读微软凌晨发布的两款新模型：MAI-Thinking-1（推理专用，35B 参数，面向「特定早期合作伙伴」）和 MAI-Code-1-Flash（5B 参数，专为 GitHub Copilot 和 VS Code 打造，已向 Copilot 个人用户推送）。Willison 特别指出，微软此次以如此低参数量的模型挑战高质量代码生成市场颇具深意，尤其是在大模型 Token 成本持续高企的当下 https://simonwillison.net/2026/Jun/2/microsofts-new-models/#atom-everything

• 🔥7 | NVIDIA NemoClaw：工业级安全自主 AI 工程师 —— NVIDIA 推出 NemoClaw 平台，让工业企业构建安全、自主的 AI 工程师。安川电机、西门子等工业软件巨头已采用该方案，为企业级 AI 工程自动化铺路 https://blogs.nvidia.com/blog/industrial-software-leaders-secure-autonomous-ai-engineers-nemoclaw/

• 🔥7 | NVIDIA 携手微软推出统一 Agentic AI 部署栈 —— 从 Windows 设备到云端再到本地部署，双方在 Microsoft Build 大会上宣布全栈统一方案，让 Agentic AI 工作负载可在任意环境下无缝运行 https://blogs.nvidia.com/blog/microsoft-build-windows-local-cloud-devices/

• 🔥7 | 金融机构齐聚「交易基础模型」赛道 —— NVIDIA 观察发现，银行、保险、支付等金融机构正加速构建专属交易基础模型（Transaction Foundation Models），利用大规模交易数据训练领域专用 AI，以取代传统规则引擎 https://blogs.nvidia.com/blog/financial-institutions-transaction-foundation-models/

🤖 AI Agent

• 🔥7 | Holo3.1 发布：快速、本地化的计算机操控 Agent —— HCompany 发布 Holo3.1 系列，相比前代 Holo3 重点提升了三大维度：多环境（Web/桌面/移动端）、多 Agent 框架兼容，以及部署灵活性。首次发布 FP8、Q4 GGUF、NVFP4 三种量化检查点，支持从云端到终端设备的全本地推理，向「通用计算机操控 Agent」迈出重要一步 https://huggingface.co/blog/Hcompany/holo31

• 🔥7 | OpenAI Codex 面向全角色、全工具、全工作流 —— OpenAI 发布 Codex 通用化战略，将 Codex 从单纯的代码助手扩展为企业级 AI 代理平台，覆盖研发、运维、安全、产品等全角色，支持 VS Code、JetBrains、终端等全工具链 https://openai.com/index/codex-for-every-role-tool-workflow
